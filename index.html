Agent Skills 生态与 Rust 全栈框架同台

今天榜单被 Agent Skills 占据：Anthropic 官方技能库和 addyosmani 的工程化技能包同时上榜，说明“教 AI 按流程干活”正从提示词变成可分发资产。另一个值得看的是 tokio-rs/topcoat，Rust 全栈框架开始补“开箱即用”这一课。

1
meta/astryx ★ 23,290
TypeScript

Meta 内部用了八年的设计系统开源，150+ 组件、品牌主题和暗色模式打包成一套，还宣称对 AI 助手友好。

它基于 React 19+ 和 StyleX，导入预构建 CSS 即可用，不需要额外构建插件。真正特别的是“开放内部”：组件可逐层组合，swizzle 能把源码弹出到项目里自己改。目前处于 Beta，且 StyleX 生态本身仍在早期，迁移前得掂量。

2
anthropics/skills ★ 192,483
Python

Anthropic 官方放出的 Claude 技能示例库，每个技能一个文件夹加 SKILL.md，从写文档到测试 Web 应用都有。

技能本质是“指令+脚本+资源”的动态加载包，让 Claude 按固定流程完成专项任务。这个仓库的价值在于示范技能该怎么组织，而不是直接拿来当产品用；想定制自己的技能，得先理解 SKILL.md 的元数据约定。

3
addyosmani/agent-skills ★ 115,276
JavaScript

把高级工程师的工作流拆成 9 个斜杠命令，从写规格、拆任务到测试、审查、上线，让 AI 编码代理按节奏走。

每个命令对应开发生命周期的一个阶段，比如 /spec 强调先写规格再写代码，/test 把测试当证明。它面向 Claude Code、Cursor、Codex 等代理，安装为插件命令；但技能本身不保证代理会严格执行，质量仍取决于模型和项目约束。

4
anthropics/claude-quickstarts ★ 20,568
Python

Claude API 的起步项目合集，客服代理、财务数据分析、电脑操作演示各给一个可跑的基础。

每个 quickstart 都围绕一个具体场景展示 Claude 的能力边界，比如客服代理接知识库、财务分析做交互图表。适合拿来改造成自己的原型，但代码是演示级，离生产部署还有距离。

5
google-deepmind/mujoco ★ 17,437
C++

DeepMind 维护的通用物理引擎，专攻关节结构与接触模拟，机器人、生物力学和动画研究的老牌基础设施。

C API 加预分配数据结构追求运行时性能，自带桌面和浏览器可视化，还有 Python 绑定和 Unity 插件。它面向需要快速且准确模拟的研究者，不是游戏引擎，上手门槛在物理建模而非渲染。

6
we-promise/sure ★ 12,130
Ruby

Maybe Finance 被放弃后的社区分叉，一个可自托管的个人财务应用，带着近百万美元开发投入的遗产继续跑。

原团队 2023 年停止开发后开源，社区接手维护。它适合想自己掌控财务数据、又愿意折腾 Ruby 部署的人；但作为分叉项目，功能迭代和托管服务的可持续性仍需观察。

7
homeassistant-ai/ha-mcp ★ 6,763
Python

把 Home Assistant 接进 Claude、ChatGPT 等助手的 MCP 集成，装进 HACS 就能用自然语言配自动化。

推荐方式是通过 HACS 安装集成，服务器在进程内运行，覆盖 HA OS、Supervised、Container 和 Core 全安装类型。注意 v7.3.0 起 ha_config_set_yaml 被移到 beta，且需要 HA 2026.8.0 以上，老版本升级前得看兼容说明。

8
vercel-labs/agent-browser ★ 49,347
Rust

Rust 写的浏览器自动化 CLI，把页面读成带 @e1 引用的紧凑文本，让 AI 代理一条命令一步地操作网页。

代理先 snapshot 拿元素引用，再对引用执行动作，然后重新读页面确认结果，浏览器在命令之间保持打开。它适合 shell 驱动的代理流程，但页面一变引用就失效，必须重新快照，步骤多时调用次数会涨。
