Agent 技能生态开始补基础设施

今天榜单几乎被 Agent 技能包和配套工具占满：从 AG-UI 把 Agent 输出标准化成事件流，到 NVIDIA 给技能做质量评估，再到 Plannotator 补上人类审阅层。最值得先看的是 AG-UI 1.0 冻结规范，以及 last30days 用真实互动数据做搜索的取巧思路。

1
ag-ui-protocol/ag-ui ★ 19,369
TypeScript

把 Agent 的流式输出、工具调用、状态更新统一成双向事件流，让前端不用为每个框架重写接线。

Agent 不是请求-响应模型，它会中途调工具、暂停等人、派生子 Agent，各家框架事件格式又不同。AG-UI 用一份 JSON Schema 生成 TypeScript、Python、.NET SDK，1.0 还保证与 0.x 双向兼容，适合想一次接入多框架 Agent 的前端团队。

2
backnotprop/plannotator ★ 12,738
TypeScript

本地浏览器里的 Agent 审阅台，把计划、HTML 原型和代码 diff 摊开让你批注，再一键把反馈送回 Agent。

多 Agent 并行工作时，决策和产出散落在终端里很难追踪。Plannotator 通过插件和 hooks 接入 Claude Code、Codex 等编码 Agent，在浏览器里做标注和评论，适合需要人工把关计划与 PR 的团队，但前提是你愿意多开一个审阅窗口。

3
dream-num/univer ★ 27,919
TypeScript

开源表格和文档编辑器内核，想让你在自己的产品里拼出一个能给人也给 Agent 用的 Office。

它提供 Sheets、Docs 的编辑、计算和协作能力，并通过 Facade API 和事件让应用与 Agent 接入。适合想把电子表格能力嵌进自家产品的开发者，但完整 Office 套件和 AI 能力在商业 SDK 里，开源核心只是起点。

4
tradermonty/claude-trading-skills ★ 6,509
Python

给个人投资者的一套 Claude 技能，把市场复盘、风控、交易计划和日志变成可重复的流程。

作者明确说目标不是让 AI 替你做买卖决策，而是把交易前的检查和交易后的复盘结构化。适合有长期投资和波段交易习惯、又愿意写日志的人，但它不是信号服务，也不承诺盈利。

5
elementalsouls/Claude-BugHunter ★ 7,677
Python

把 82 个漏洞狩猎技能和 681 条公开报告模式塞进 Claude Code，让它按红队流程干活。

它覆盖 24 类漏洞、企业身份和基础设施攻击矩阵，还带 Burp MCP 集成和交战文件夹脚手架。适合授权测试和 Bug Bounty 场景，但技能包再全也替代不了对目标业务的理解，且必须严格守住授权范围。

6
getarcaneapp/arcane ★ 8,886
Go

Go 写的 Docker 管理面板，主打自托管和 Compose 容器管理，界面比命令行友好。

适合在家庭服务器或小团队环境里管容器，提供 Compose 支持和自托管部署。main 分支已是 v3，功能请求迁到 Discussions，说明项目在收紧 issue 通道、优先修 bug，用之前留意版本分支。

7
DeanChensj/jiangshan-map ★ 7,166
JavaScript

从战国到当代的中国历史交互地图，198 个疆域快照加上古今地名沿革和诗词路线。

读史或读诗时想查建康、黄州、蓝关今天在哪，可以直接在时间轴上刷。适合数字人文爱好者和历史读者，但疆域数据的精度和边界定义需要自己判断，别把它当学术地图集用。

8
google-labs-code/stitch-skills ★ 9,818
TypeScript

Google Stitch 的 Agent 技能库，按 Agent Skills 开放标准打包，设计、构建、工具三类插件分开装。

它通过插件市场接入 Codex、Gemini CLI、Claude Code、Cursor 等编码 Agent，让 Stitch 的设计能力进入编码流程。适合已经在用 Stitch 做 UI 的团队，但 OpenCode 需要手动安装，插件生态还在早期。

9
mvanhorn/last30days-skill ★ 68,316
Python

让 Agent 并行搜 Reddit、X、YouTube、HN 和 Polymarket，按点赞和真金白银的赔率排序，而不是编辑推荐。

零配置就能跑 Reddit、HN、Polymarket 和 GitHub，跑一次向导再解锁 X、YouTube、TikTok 等源。适合做话题快速调研，但排序逻辑偏向互动热度，冷门但重要的信息可能被淹没。

Agent 技能从“堆数量”进入“建标准、做评估、补审阅”的阶段，今天这几个项目正好各占一环，值得按这个顺序看一遍。
