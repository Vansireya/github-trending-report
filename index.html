Agent 技能包与工具链集中爆发

今天榜单几乎被 Agent 技能包和配套工具占满，从安全测试到开发方法论再到图表生成，都在把 Claude Code 这类宿主变成专业工作台。最值得看的是 Claude-BugHunter 把 681 份公开漏洞报告拆成可审计的技能模式，以及 superpowers 试图给编码 Agent 立一套完整开发流程。

1
elementalsouls/Claude-BugHunter ★ 21,826
Python

把 84 个技能、15 个斜杠命令和 681 份公开漏洞报告模式打包成 Claude Code 的漏洞狩猎外挂。

它面向授权红队和漏洞赏金场景，按方法论、Web 应用狩猎、企业身份与基础设施攻击矩阵分层组织，并集成 Burp MCP。亮点是 433 份报告模式单独引用可审计，但 README 也强调需在授权范围内使用，实际效果取决于使用者对目标的理解。

2
obra/superpowers ★ 325,998
Shell

一套让编码 Agent 先问清需求、再拆规格、最后按计划写代码的完整软件开发方法论。

它不直接写代码，而是用可组合技能约束 Agent 的工作流：先逼出规格，分块确认设计，再生成连“没品味的初级工程师”都能执行的实施计划。支持 Claude Code、Codex、Cursor 等十余种宿主，适合想给 Agent 加流程纪律的团队。

3
HKUDS/CLI-Anything ★ 65,062
Python

给任意软件套一层 CLI，让 AI Agent 能像人一样操作 CAD、3D 场景和图表工具。

项目提供 CLI-Hub 包管理，社区可提交和安装各类软件的命令行封装，Agent 通过生成 CLI 调用来产出真实工件。思路是把 Agent 原生接口做成 CLI 生态，但具体软件覆盖度和生成质量取决于社区贡献。

4
jingyaogong/minimind ★ 70,474
Python

用 3 块钱 GPU 租金和 2 小时，从零训出一个 64M 参数的超小语言模型。

它把预训练、SFT、LoRA、DPO、PPO/GRPO 到 Agentic RL 的全链路代码用原生 PyTorch 写了一遍，不依赖高层抽象，适合当 LLM 入门教材。注意“2 小时”指单张 3090 跑完 SFT 一个 epoch，不是完整训练全流程。

5
cursor/plugins ★ 19,320
TypeScript

Cursor 官方插件规范与首批官方插件，把教学、持续学习、团队工具包做成可安装的 Agent 插件。

每个插件是根目录下的独立目录，带自己的 plugin.json 清单。目前能看到教学技能映射、基于对话记录增量更新 AGENTS.md、CI 与代码审查工作流等。它更像生态基础设施，插件数量还少，价值取决于后续社区供给。

6
firecrawl/firecrawl ★ 209,178
TypeScript

把网站抓成干净 Markdown 的知识基础设施，本地单二进制即可跑，也能接 550+ 数据源。

三种用法清晰：本地单二进制带 MCP 服务、云端托管、完整自托管。本地版不需要数据库和队列，适合给 Agent 喂网页；云端额外提供搜索和 Alexandria 数据源。自托管则要自己管队列、worker 和数据库，运维成本不低。

7
nginx/nginx ★ 33,267
C

NGINX 官方开源仓库，Web 服务器、负载均衡、反向代理和内容缓存的老牌底座。

README 本身是面向新手的结构化入门，覆盖模块、配置、运行时、安装和从源码构建。它不靠新概念上榜，而是作为基础设施常青树被反复查看。真正要调优仍得翻完整文档，README 只是入口。

8
openvinotoolkit/openvino ★ 12,518
C++

Intel 主导的推理优化工具包，把 PyTorch、TensorFlow、ONNX 等模型压到 CPU、GPU 和 NPU 上跑。

支持从边缘到云的部署，覆盖计算机视觉、语音、生成式 AI 和大语言模型，还能通过 Optimum Intel 直接接 Hugging Face 模型。它的现实约束是硬件偏向 Intel 平台，非 Intel 加速器用户收益有限。

cathrynlavery/diagram-design ★ 72,320
HTML

让 Agent 用自然语言画架构图、象限图和时序图，输出单个自包含 HTML+SVG 文件，拒绝 Mermaid 味。

内置 52 种图表类型，能抓取你网站的配色和字体让图表匹配品牌，双击 HTML 即可查看。它明确反对阴影和 Mermaid 的粗糙感，适合对视觉有要求的汇报场景，但复杂图表仍可能需要手动调整 SVG。

今日结论

今天真正值得留意的不是单个项目，而是“Agent 技能包”正在形成独立品类：安全、开发流程、图表、调研都在被封装成可安装的技能。选型时先看它约束了什么流程，而不是数技能个数。
