给编码代理立规矩：技能、记忆与设计约束

今天榜单几乎被同一件事占满：怎么让编码代理按人的意图工作，而不是一上来就写代码。obra/superpowers 用一套可组合技能把开发流程塞进代理，thedotmack/claude-mem 则试图让代理跨会话记住上下文，两者分别从流程和记忆两端补课。

1
HKUDS/DeepTutor ★ 50,466
Python

港大团队做的终身个性化辅导代理，带 CLI、多代理系统和交互式学习工作区。

从 README 看，它把学习路径、评估、视频课程和检索对比都做进了同一套工作区，更新节奏很密。但功能面铺得很宽，实际辅导质量是否跟得上模块数量，仅凭简介无法判断。

2
obra/superpowers ★ 308,707
Shell

给编码代理装上一套完整开发方法论：先问清目标，再拆规格、写计划，最后才动手。

它不直接写代码，而是用可组合技能约束代理的行为顺序，覆盖 Claude Code、Codex、Cursor 等一长串工具。真正有意思的是把“先想清楚再写”做成了代理必须遵守的流程，而不是靠人自觉。

3
pbakaus/impeccable ★ 95,657
Rust

给编码代理一套设计词汇：polish、bolder、critique、audit，专门拦截 AI 味的界面。

README 举的例子很具体：同样的模型和需求，没有它就会产出奶油色页面、细衬线、胶囊按钮这类默认审美。它把设计评审变成代理可调用的命令，但效果依赖代理是否真的执行这些技能。

4
JetBrains/thinkrail ★ 6,101
TypeScript

JetBrains 出的轻量代理 IDE，围绕 pi 编码代理做隔离工作区和活规格。

每个工作区是独立的 git worktree，代理可以并行干活、互不碰主检出，合并好的分支、删掉其余。思路务实，但扩展系统还在“下一步”阶段，现在更像一个围绕 pi 的精致外壳。

5
milind-soni/OpenMausBot ★ 7,595
TypeScript

开源版 Grok Bot 替代品：聊天应用里每个联系人都是一个带虚拟机的真实代理。

每个 bot 背后是本地跑的 Claude 或 Codex，有自己的性格、模型、云电脑和连接应用，像联系人一样对话、旁观、审批。本地优先、自带代理是卖点，但“云电脑”和本地执行的边界需要自己厘清。

6
nightly-labs/openbot ★ 3,959
TypeScript

本地优先的桌面工作区，给每个 AI 队友独立空间、任务队列和浏览器。

支持 Codex、Claude、Grok、OpenCode 等多套代理，带代理间消息和嵌入式浏览器。README 自己警告：代理以完全访问权限运行、不逐动作确认，只适合跑你信任的任务，这是开发预览阶段的真实代价。

7
elayadesign/ai-design-skills ★ 12,330

面向 AI 编码工具的设计技能合集，每个技能一个自包含文件夹，按需安装。

目前主打落地页设计：从需求提问、页面结构、转化文案到字体间距圆角动效一整套视觉系统。形式是 markdown 规则文件，Claude Code、Cursor、Codex 都能读，但技能数量还少，覆盖面有限。

8
thedotmack/claude-mem ★ 104,948
TypeScript

给编码代理做跨会话记忆：自动捕获操作、压缩成摘要，下次会话再注入。

解决的是代理关掉就失忆的老问题，支持 Claude Code、Codex、Gemini 等一长串工具。默认走托管记忆服务，本地观察者需要显式开启，隐私敏感的场景要留意这个默认值。

9
CopilotKit/OpenBot ★ 8,240
TypeScript

CopilotKit 的开源 AI 同事模板：每个同事一台电脑，动作先决策后记录。

通过 AG-UI 接入任意代理栈，每个同事有独立浏览器、登录态、文件和授权工具，回答用组件而非纯文本。定位是模板而非产品，没有托管版，需要克隆下来改成自己的租户包。

今日结论

今天最值得看的是 superpowers 和 impeccable 代表的转向：不再比谁生成得快，而是比谁能让代理先想清楚、按规矩来。记忆和隔离工作区是配套基础设施，缺了它们，流程约束很难落地。
