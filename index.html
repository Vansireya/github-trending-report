Agent 技能生态正在成型

今天榜单上最显眼的是 Agent 技能与插件的基础设施化：Cursor 发布官方插件规范，NVIDIA 推出技能评估框架，Google 则把 Stitch 的设计能力拆成技能包。另一个值得注意的信号是 HKUDS/CLI-Anything 已冲到近 6 万星，试图用 CLI 把任意软件改造成 Agent 可调用的接口。

1
cursor/plugins ★ 17,302
TypeScript

Cursor 官方插件规范与示例合集，每个插件独立目录并带 manifest，相当于给 Agent 扩展能力定了个标准抽屉。

仓库里既有教学、持续学习这类通用技能，也有 Thermos 这种做深度安全审计和并行子代理的复杂插件。它更像规范样板而非开箱即用的市场，想直接拿来干活还得自己挑和配。

2
HKUDS/CLI-Anything ★ 59,943
Python

给任意软件套一层 CLI，让 AI Agent 能像人一样敲命令操作 CAD、3D 场景、字幕等工具。

思路是把软件能力封装成 Agent 可调用的命令行接口，再通过 CLI-Hub 分发社区构建的 CLI。覆盖面听起来很广，但实际效果取决于每个 CLI 封装的质量，目前更像一个正在快速铺开的生态倡议。

3
mvanhorn/last30days-skill ★ 70,205
Python

一个 Agent 技能，并行搜索 Reddit、X、YouTube、HN、Polymarket 等平台，用点赞和真金白银的赔率而非编辑偏好来排序信息。

适合快速摸清某个话题最近 30 天的舆论和资金信号。零配置就能跑 Reddit、HN、Polymarket 和 GitHub，但 X、YouTube、TikTok 等需要跑一次设置向导解锁，且摘要质量依赖各平台数据的可获取性。

4
getarcaneapp/arcane ★ 9,902
Go

用 Go 写的现代 Docker 管理面板，面向自托管场景，把容器和 Compose 的日常操作收进一个界面。

README 本身信息偏少，主要指向官方文档和 SBOM。从 topics 看它覆盖 compose、容器管理和自托管，适合不想纯靠命令行管 Docker 的人，但具体功能深度需要翻文档才能判断。

5
NVIDIA/SkillEvaluator ★ 3,832
Python

给 Agent 技能做质检的多层框架：静态规则、安全扫描、语义重叠检测，再到真实 Agent 运行对比，一条龙卡在合并前。

第一层靠 500 多条静态规则和检测模式，不需要 LLM key 就能跑；后两层才引入去重和实时 Agent 评估来量化技能带来的提升。它提供可复用的 CI 模板，适合想把技能质量门禁自动化的团队，但完整评估需要接 NVIDIA Build。

6
nvm-sh/nvm ★ 96,176
Shell

老牌 Node 版本管理器，POSIX 兼容的 bash 脚本，靠 .nvmrc 和 shell 集成在多个 Node 版本间切换。

近 10 万星说明它仍是 Node 多版本场景的默认答案。功能列表很长，从 Docker 安装到离线安装、镜像加速都覆盖，但本质仍是 shell 脚本方案，Windows 原生支持不在其范围内。

7
astral-sh/uv ★ 92,284
Rust

Rust 写的 Python 包和项目管理器，号称一个工具替代 pip、pip-tools、pipx、poetry、pyenv 等一串。

亮点是 10 到 100 倍于 pip 的速度、通用锁文件、内联依赖脚本和 Cargo 风格 workspace。它已经不只是包安装器，而是在收拢整个 Python 项目工作流，对现有工具链的替代意图非常明显。

8
google-research/paper-orchestra ★ 4,475
Python

Google Research 的多 Agent 论文写作框架，把想法和实验日志变成带文献综述和图表的 LaTeX 投稿稿。

流水线拆成大纲、文献综述、章节写作、内容精炼和绘图几个专职 Agent，覆盖从原始材料到成稿的完整链路。适合探索自动化写作的边界，但“投稿就绪”和实际学术质量之间还有很长的路。

9
google-labs-code/stitch-skills ★ 10,474
TypeScript

Google Stitch 的 Agent 技能库，按开放标准拆成设计、构建、工具三组插件，可装进 Codex、Claude Code、Cursor 等。

安装方式以插件市场为主，Codex 支持 CLI 和 UI 两种路径，Claude Code 和 Cursor 也有对应说明，但 OpenCode 需要手动安装。它把设计工具能力模块化，方便按需组合，不过目前更像配套生态而非独立产品。

今日结论

今天榜单的主线不是某个爆款应用，而是 Agent 技能从“能跑”走向“可评估、可分发、可组合”的基础设施层。值得留意的是，评估和规范类项目开始与技能本身同台竞争注意力。
