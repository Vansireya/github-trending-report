今日 GitHub 狠活：有人把 PS5 游戏搬上了 PC，有人把阿波罗登月代码挖出来了

今天的榜单堪称"考古+科幻"混合双打——一边是 1969 年的登月代码，一边是 2025 年的 AI 逆向工程。人类的本质就是：既要仰望星空，也要破解你的二进制。

1
morluto/rea ★ 112,422
TypeScript

用 AI Agent 逆向工程一切，从 App 行为一路扒到原生二进制。

这玩意儿就是给&quot;我想知道这个软件到底在干嘛&quot;星人准备的。以前逆向工程是安全研究员的专属手艺，现在它把 Agent 塞进来，让 AI 帮你自动分析——App 怎么跑的、二进制里藏了什么，统统给你翻出来。112k Star 说明什么？说明大家都想看看别人的代码里到底写了什么脏东西。

2
boykopovar/AnyPS5 ★ 30,503
C++

自动把 PS5 可执行文件移植到 Linux 和 Windows 的工具。

索尼看了想打人系列。PS5 独占游戏一直是 PC 玩家的心头刺，这个项目直接冲着&quot;自动化移植&quot;去的——你不需要是逆向大佬，工具帮你把 PS5 的可执行文件往 PC 上搬。当然，法律风险请自行评估，我只能说：技术是中立的，律师函也是。

3
storytold/artcraft ★ 18,476
Rust

给艺术家、设计师和电影人用的&quot;有意为之&quot;的创作引擎。

市面上的创作工具要么太工程化（Blender 劝退），要么太玩具化（Canva 不够用）。ArtCraft 的定位是&quot;intentional crafting&quot;——让创作者把精力花在创意上，而不是跟工具搏斗。Rust 写的，性能不用担心，崩溃也不用担心（大概）。

4
cathrynlavery/diagram-design ★ 50,661
HTML

给 AI 编程助手用的编辑级图表设计系统，44 种图表类型，纯 HTML+SVG。

作者在简介里直接开骂&quot;Mermaid slop&quot;——翻译过来就是&quot;受够了 Mermaid 生成的丑图&quot;。这个项目给 Claude Code、Copilot、Cursor 等 AI 编程工具提供了一套高质量的图表设计规范：没有阴影、没有花里胡哨、纯 HTML+SVG 自包含。简单说就是：让你的 AI 画出的图终于能见人了。

5
bilawalsidhu/gods-eye-view ★ 51,936
JavaScript

浏览器里的间谍卫星模拟器，但数据是真的。

你坐在家里，打开浏览器，就能在一个逼真的 3D 地球上查看实时开源空间情报。不是游戏，不是模拟——数据是真实的。这玩意儿让你体验一把&quot;上帝视角&quot;的感觉，同时也提醒你：在这个时代，隐私是个奢侈品。50k Star 说明大家对&quot;偷窥世界&quot;这件事有着天然的热情。

6
pytorch/pytorch ★ 104,578
Python

Python 里的张量和动态神经网络，GPU 加速拉满。

还需要介绍吗？这是深度学习界的空气和水。你用的每一个 AI 模型，背后大概率都有 PyTorch 的影子。104k Star 不是因为它营销做得好，而是因为全世界的研究员和工程师都在用它。如果你还没用过，那你可能不是做 AI 的——或者你刚从 TensorFlow 1.x 的噩梦里醒来。

7
lyogavin/airllm ★ 36,633
Jupyter Notebook

单张 4GB 显卡跑 70B 大模型推理。

以前跑 70B 模型是什么概念？你得有 A100，或者至少 40GB 显存。AirLLM 说：不，你只需要 4GB。原理是分层加载，把模型拆开慢慢喂给 GPU——速度当然会慢一些，但&quot;能跑&quot;和&quot;跑不了&quot;之间，差的就是一个 AirLLM。对于消费级显卡用户来说，这是从&quot;望模型兴叹&quot;到&quot;我也能玩&quot;的质变。

8
chrislgarry/Apollo-11 ★ 74,319
Assembly

阿波罗 11 号制导计算机的原始源代码，指令舱和登月舱都在。

1969 年，人类用汇编写了一个程序，把两个人送上了月球。现在这个代码在 GitHub 上，你可以随便看。74k Star 说明什么？说明大家对&quot;人类历史上最重要的代码之一&quot;还是有敬畏之心的。建议每个程序员都去读一读——不是为了学汇编，是为了提醒自己：你写的 bug，至少不会让宇航员回不了地球。

今日总结： 有人在破解 PS5，有人在模拟间谍卫星，有人在用 4GB 显卡跑 70B 模型，还有人把 1969 年的登月代码挖出来供着。GitHub 的多样性，就是人类多样性的缩影——只不过这里的人都会写代码。
