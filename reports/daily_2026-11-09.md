# AI 代理工具链继续膨胀，从浏览器到设计系统

今天榜单几乎被 AI 代理的基础设施占满：Vercel 的浏览器自动化 CLI、Anthropic 的技能仓库和 quickstarts、Meta 的设计系统，都在回答同一个问题——代理怎么真正干活。最值得先看的是 agent-browser，它把浏览器拆成一条条 shell 命令，思路干净；另一个意外是 billion-context，用压缩插件把上下文窗口的账算得很细。


### sherlock-project/sherlock

**一句话概括**：用同一个用户名在各大社交网络里顺藤摸瓜，老牌 OSINT 命令行工具。

**详细介绍**：适合安全取证和公开信息收集，输入一个用户名就能批量探测账号是否存在。它只做发现不做验证，结果依赖各平台页面结构，误报和失效需要人工复核。

**项目网址**：https://github.com/sherlock-project/sherlock

**Star 数量**：104,288


### dsx-ai-factory/nvke

**一句话概括**：在自家裸金属 GPU 上搭一套类似托管 K8s 的管理平面，每个租户集群独立控制面。

**详细介绍**：平台团队安装 NVKE 管理平面，客户通过 kubectl 使用各自的工作负载集群。目前是预览版，API 和行为可能变，官方明确不建议上生产；没有 GPU 硬件时可以用模拟机器先跑通流程。

**项目网址**：https://github.com/dsx-ai-factory/nvke

**Star 数量**：906


### milind-soni/OpenMausBot

**一句话概括**：把 Claude 或 Codex 包装成聊天列表里的“联系人”，每个 bot 有自己的性格和云电脑。

**详细介绍**：本地优先，模型自带，侧边栏里每个 bot 都是真实代理，可以看它工作、在关键步骤审批。定位是 Grok Bot 的开源替代，但项目明确与 xAI 等无关联，也提醒没有代币。

**项目网址**：https://github.com/milind-soni/OpenMausBot

**Star 数量**：18,556


### anthropics/claude-quickstarts

**一句话概括**：Anthropic 官方给的 Claude API 起步模板，客服、金融分析、电脑操作各有一个可跑示例。

**详细介绍**：适合想快速验证 Claude 能力边界的开发者，每个 quickstart 都留了可定制的骨架。它偏教学和演示，不是生产级脚手架，真正部署还得自己补工程化。

**项目网址**：https://github.com/anthropics/claude-quickstarts

**Star 数量**：19,526


### vercel-labs/agent-browser

**一句话概括**：Rust 写的浏览器 CLI，把页面压成带 @e1 引用的可访问性树，代理一步一条命令地操作。

**详细介绍**：代理先 snapshot 拿元素引用，再点击或输入，浏览器在命令之间保持打开。引用会随 DOM 变化失效，需要重新快照；点击失败会直接报错而不是假装成功，这点对代理很关键。

**项目网址**：https://github.com/vercel-labs/agent-browser

**Star 数量**：47,778


### meta/astryx

**一句话概括**：Meta 内部用了八年的设计系统开源，150+ 组件，强调人和 AI 用同一套工具构建。

**详细介绍**：基于 React 19 和 StyleX，导入预构建 CSS 即可用，不绑定额外样式库。组件内部开放，可以 swizzle 把源码 eject 出来自己改；目前是 Beta，适合想研究大厂设计系统结构的团队。

**项目网址**：https://github.com/meta/astryx

**Star 数量**：17,264


### anthropics/skills

**一句话概括**：Claude 的技能仓库，每个技能是一个带 SKILL.md 的文件夹，教模型按固定流程做事。

**详细介绍**：技能覆盖创意、技术、企业工作流，Claude 按需动态加载。它展示的是技能系统的可能性，不是开箱即用的产品；想定制得自己写 SKILL.md 和配套脚本。

**项目网址**：https://github.com/anthropics/skills

**Star 数量**：189,802


### google-deepmind/mujoco

**一句话概括**：DeepMind 维护的物理引擎，专攻多关节动力学和接触仿真，机器人研究的常客。

**详细介绍**：C API 面向研究者和开发者，运行时针对性能调优，数据结构和 XML 编译器预分配绑定。提供 Python 绑定和 Unity 插件，浏览器里也能直接试；上手门槛在物理建模本身。

**项目网址**：https://github.com/google-deepmind/mujoco

**Star 数量**：16,502


### ranxianglei/billion-context

**一句话概括**：上下文压缩插件，号称 100K 窗口就够用，token 省五倍，单会话能撑一个月。

**详细介绍**：面向长寿命编码代理，靠增量分层压缩维持前缀缓存 95% 以上的命中率。压缩本身成本声称不超过 2%，但缓存命中率下降时要靠 /acp 排查上游 TTL、模型切换等原因。

**项目网址**：https://github.com/ranxianglei/billion-context

**Star 数量**：5,296


**今日总结**：代理要落地，缺的不是更聪明的模型，而是浏览器、技能、上下文这些脏活累活的基础件。今天这几个项目都在补这一层，值得挑一个动手试试。
