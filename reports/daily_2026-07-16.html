今日 GitHub 狠活：剪映平替、AI 老婆、防手贱神器，还有让你变卷王的秘籍

各位摸鱼界的朋友们，早上好！今天的热门仓库又是神仙打架的一天。从能让你抛弃剪映的开源替代品，到能陪你打《我的世界》的 AI 老婆，再到专门收拾那些“手贱”AI Agent 的护身符…… 别眨眼，往下看。

OpenCut

🎯 一句话概括: 开源界的“剪映”，让你彻底告别付费视频编辑的烦恼。
💡 详细介绍: 剪映（CapCut）确实好用，但它是闭源的，而且指不定哪天就给你整出个会员制。OpenCut 就是来截胡的。它用 TypeScript 重写了核心功能，主打一个“我全都要”且“免费”。虽然目前还在早期阶段，但凭这势头，未来让视频创作者们省下一笔订阅费不是梦。适合那些既想白嫖，又不想用盗版的正经人。
🔗 项目网址: https://github.com/OpenCut-app/OpenCut
✨ Star 数量: 71,897
⭐ 推荐指数: ⭐⭐⭐⭐（潜力股，但别指望它现在就能完全替代剪映的专业特效）

Nutlope/hallmark

🎯 一句话概括: 给 AI 代码助手（Claude Code、Cursor 等）上的“反 AI 味”课程。
💡 详细介绍: 你是不是也觉得现在的 AI 写代码一股“罐头味”？生成的代码虽然能用，但就像流水线出来的螺丝，毫无灵魂。Hallmark 就是干这个的——它是一个设计规范集合，告诉 Claude 和 Cursor 们：“别给我整那些花里胡哨的、千篇一律的玩意儿，给我写出有‘人味儿’、有设计感的代码。” 简单说，就是给 AI 补了一堂审美课。
🔗 项目网址: https://github.com/Nutlope/hallmark
✨ Star 数量: 8,645
⭐ 推荐指数: ⭐⭐⭐（适合那些对代码有洁癖，且喜欢调教 AI 的工程师）

mattpocock/skills

🎯 一句话概括: 一个 TypeScript 大佬的“.claude 目录”，里面全是让工程师变强的硬核技能。
💡 详细介绍: 别被它 172k 的 Star 数吓到，这哥们是真有点东西。他把自己的 `.claude` 文件夹（对，就是那个 AI 助手 Claude 的配置目录）直接开源了。里面全是他在实战中总结的 Shell 脚本、TypeScript 技巧和工程实践。相当于你把一个顶级工程师的“武功秘籍”直接拷回了家。想从“熟练工”变成“真·大佬”？跟着这个仓库练就完了。
🔗 项目网址: https://github.com/mattpocock/skills
✨ Star 数量: 172,372
⭐ 推荐指数: ⭐⭐⭐⭐⭐（不吹不黑，这 Star 数已经说明了一切，是真正的宝藏）

moeru-ai/airi

🎯 一句话概括: 一个能自托管、能语音聊天、还能陪你打《我的世界》和《幸福工厂》的 AI 老婆。
💡 详细介绍: 醒醒吧，别整天对着二次元纸片人傻笑了。Airi 让你把“老婆”变成现实。这是一个完全自托管的 AI 伴侣项目，灵感来自那个著名的虚拟主播 Neuro-sama。它不仅能实时语音聊天，还能直接接入游戏，在 Minecraft 里帮你挖矿，在 Factorio 里帮你铺传送带。支持 Web、macOS 和 Windows。虽然目前还是个“容器里的灵魂”，但技术宅们，你们离“人机恋”只差一个 `git clone` 了。
🔗 项目网址: https://github.com/moeru-ai/airi
✨ Star 数量: 42,533
⭐ 推荐指数: ⭐⭐⭐⭐（技术含量高，但需要一定的部署能力，且功能还在完善中）

Dicklesworthstone/destructive_command_guard

🎯 一句话概括: AI Agent 的“狗绳”，专门防止它们手贱执行 rm -rf / 这种毁天灭地的命令。
💡 详细介绍: 现在的 AI Agent 越来越聪明了，但聪明过头就容易出事。比如你让它“清理一下项目”，它可能直接给你来个 `git push --force` 或者 `rm -rf *`。这个用 Rust 写的守护程序就是干这个的——它会实时监控 Git 和 Shell 命令，一旦发现危险操作，直接拦截并报警。相当于给那些“莽撞”的 AI 助手戴上了一个防咬嘴套。对于所有在玩 AI 编程助手的人来说，这玩意儿就是护身符。
🔗 项目网址: https://github.com/Dicklesworthstone/destructive_command_guard
✨ Star 数量: 4,785
⭐ 推荐指数: ⭐⭐⭐⭐（虽然小众，但属于“可以不用，但不能没有”的类型，尤其适合那些喜欢把 AI 当小白鼠的人）

HKUDS/Vibe-Trading

🎯 一句话概括: 你的个人 AI 交易员，帮你“凭感觉”炒股。
💡 详细介绍: 别被名字里的“Vibe”骗了，它不是让你靠玄学交易。这是一个基于 Python 的个人交易智能体，它会分析市场情绪（Vibe），然后给你提供交易建议。它能接入各种数据源，帮你做决策。当然，它不会保证你赚钱（毕竟要是真能稳赚，作者早自己闷声发大财了），但至少能让你在亏钱的时候，有个 AI 给你背锅（不是）。适合那些想用 AI 辅助投资，但又不想写一堆量化策略代码的散户。
🔗 项目网址: https://github.com/HKUDS/Vibe-Trading
✨ Star 数量: 23,739
⭐ 推荐指数: ⭐⭐⭐（好用，但投资有风险，别把家底都压上去）

openinterpreter/openinterpreter

🎯 一句话概括: 最便宜的 AI 编程助手，专门为低成本的模型设计。
💡 详细介绍: OpenAI 的 Code Interpreter 好用，但贵啊。OpenInterpreter 就是它的开源平替，而且更狠——它主要针对那些低成本的模型（比如 Llama 3、Mistral 等）做了优化。你可以在本地跑，用便宜的 API，就能实现让 AI 帮你写代码、分析数据、甚至操作电脑。对于预算有限的学生党或者不想被大厂 API 绑架的独立开发者来说，这玩意儿就是救星。
🔗 项目网址: https://github.com/openinterpreter/openinterpreter
✨ Star 数量: 65,516
⭐ 推荐指数: ⭐⭐⭐⭐⭐（成熟、稳定、实用，开源界的良心之作）
