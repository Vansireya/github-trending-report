# 今日 GitHub 狠活：代码变知识图谱，AI 卷出新高度

大家好，我是你们的毒舌技术博主。今天的 GitHub 热门项目列表堪称“AI 插件大乱斗”——从代码知识图谱到网络安全技能包，再到让 AI 乖乖听话的配置文件，简直是开发者版的“复仇者联盟”。废话少说，直接开喷。

### Understand-Anything
- **一句话概括**：把代码变成可以“问问题”的知识图谱，让 AI 工具（Claude、Copilot 等）不再瞎猜你的意图。
- **详细介绍**：你是不是经常被 AI 代码助手搞得血压飙升？它总是误解你的代码结构，然后给出一些“看起来像那么回事但实际是狗屎”的建议。这个项目直接把你的代码库变成一个交互式知识图谱，你可以搜索、探索，甚至直接问“这个函数的父类是谁？”——相当于给 AI 装了个“代码地图”，让它不再迷路。支持 Claude Code、Codex、Cursor 等主流工具，简直是“AI 助手们的 GPS”。
- **项目网址**：https://github.com/Lum1104/Understand-Anything
- **Star 数量**：31,575
- **推荐指数**：★★★★☆（四星半，减半星是因为配置起来可能比写代码还复杂）

### knowledge-work-plugins
- **一句话概括**：Anthropic 官方出品的“知识工作者”插件合集，让 Claude 变成你的全能打工人。
- **详细介绍**：如果你觉得 Claude 只是个聊天机器人，那你就错了。这个仓库提供了一堆插件，让 Claude 能帮你处理文档、管理项目、甚至做数据分析——相当于给 Claude 穿上了“西装领带”，让它从“程序员”变成“项目经理”。适合那些想用 AI 摸鱼但又要看起来在认真工作的人。注意：只支持 Claude Cowork 环境，别想着在别的 AI 上偷用。
- **项目网址**：https://github.com/anthropics/knowledge-work-plugins
- **Star 数量**：15,593
- **推荐指数**：★★★★☆（四星，因为官方出品，稳定性和质量有保证，但生态封闭扣一星）

### codegraph
- **一句话概括**：本地运行的代码知识图谱，让 AI 少花 token 多干活。
- **详细介绍**：你是不是被 AI 工具的 token 消耗搞得肉疼？这个项目在本地预索引你的代码库，生成知识图谱，让 AI 可以直接“查表”而不是从头读代码——相当于给 AI 配了个“索引卡片”，省 token 又省时间。支持 Claude Code、Codex、Cursor 等，而且 100% 本地运行，不用担心隐私泄露。适合那些代码库巨大、AI 经常跑偏的团队。
- **项目网址**：https://github.com/colbymchenry/codegraph
- **Star 数量**：25,406
- **推荐指数**：★★★★★（五星，实用、省 token、本地化，完美）
