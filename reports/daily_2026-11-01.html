Agent 技能与记忆层集中爆发

今天榜单几乎被 coding agent 的周边设施占满：记忆持久化、技能框架、多 agent 编排、控制面板各占一块。最值得看的是 claude-mem 和 superpowers——前者试图解决 agent 跨会话失忆，后者把开发方法论拆成可组合的技能包，两者都在给 agent 补“长期工作”的底子。

1
thedotmack/claude-mem ★ 108,009
TypeScript

给 Claude Code 做持久记忆：自动捕获工具调用观察，用 AI 压缩成语义摘要，再注入后续会话。

适合长时间跨会话推进同一项目的场景，让 agent 不必每次从零重建上下文。局限在于摘要压缩本身依赖模型判断，关键细节可能在压缩中丢失，且目前主要围绕 Claude Code 生态。

2
mattpocock/skills ★ 308,520
Shell

作者日常工程用的 agent 技能集，主打小而可组合，不接管流程，也不绑定模型。

针对 GSD、BMAD、Spec-Kit 这类“替你管流程”的方案，反其道强调保留控制权。技能以 Shell 文件分发，可手动改；代价是没有统一编排，需要自己判断何时调用哪个。

3
Donchitos/Claude-Code-Game-Studios ★ 31,265
Shell

把单个 Claude Code 会话改造成 49 个 agent 的游戏工作室，带层级、升级路径和质量门禁。

用工作室组织结构约束 AI 开发游戏：总监守愿景、部门主管管领域、专员干活，试图拦住硬编码魔数和跳过设计文档。实际效果取决于 agent 间协调开销，小项目可能觉得流程过重。

4
pingdotgg/t3code ★ 35,810
TypeScript

agent harness 控制面板，用移动端、Web 和 Electron 桌面端统一操控本机已装的多种 coding agent。

面向多 agent 并用的开发者，支持 Claude Code、Codex、Cursor 等，前提是各 CLI 已安装并登录。定位是控制面而非新 agent，价值在远程和跨端体验，但依赖上游工具的认证与接口稳定性。

5
Renhuai123/ziwei-doushu ★ 12,390
TypeScript

基于倪海厦《天纪》体系的紫微斗数开源排盘引擎，含四化、格局知识库和古籍原文数据。

把传统排盘算法和解读数据开放出来，附 67.5 万张命盘的解读数据集。README 自己注明六亲判断是斗数弱项，相关维度仅供参考——这种把局限写进文档的做法比算法本身更值得注意。

6
milind-soni/OpenMausBot ★ 9,758
TypeScript

开源版 Grok Bot 替代：聊天应用里每个 bot 都是本地跑的真 agent，各有性格、模型和云电脑。

bring-your-own-agent、本地优先，底层是 Claude 或 Codex，带虚拟机供 bot 操作。适合想要“联系人式”多 agent 界面的人，但项目明确与 xAI、Meta、OpenAI 无关联，生态位仍属跟随。

7
pbakaus/impeccable ★ 98,411
Rust

给 coding agent 的设计词汇表：用 polish、bolder 调方向，用 critique、audit 做审查，专治 AI 味界面。

针对 agent 默认产出的奶油底、细衬线、紫蓝渐变、卡片套卡片等套路，提供可调用的设计指令。思路聪明，但效果取决于 agent 对词汇的理解，且需要接入支持的十几种工具之一。

8
obra/superpowers ★ 310,131
Shell

一套完整的 agent 开发方法论：先逼出 spec，再分块确认设计，最后生成连“没品味的初级工程师”都能执行的计划。

核心是不让 agent 一上来就写代码，而是退一步问清目标。技能可组合，覆盖从头脑风暴到 SDLC 的流程。限制是流程本身需要用户持续参与确认，想全自动的人会觉得啰嗦。

9
lightpanda-io/browser ★ 39,327
Zig

用 Zig 从零写的无头浏览器，不是 Chromium 分支，宣称比 Chromium 轻 16 倍、快 9 倍。

为 AI 和自动化场景设计，支持 CDP，可接 Playwright、Puppeteer。基准是 933 个真实页面、100 页并发下的内存与耗时对比。注意 Linux 二进制依赖 glibc，Alpine 等 musl 发行版直接跑不起来。

今日结论

今天的关键词不是新模型，而是给 agent 补基础设施：记忆、技能、编排、控制面。热闹之下，真正稀缺的是像 impeccable 那样敢对 AI 默认审美说不，以及像 ziwei-doushu 那样把局限写进文档的诚实。
