# Agent 技能、记忆与浏览器操控成为主线

今天榜单几乎被 Agent 基础设施占满：Anthropic 把 Claude 的技能体系公开成可拆解的文件夹，Vercel 则用 Rust CLI 给 Agent 一个能逐步操作的浏览器。两者都指向同一件事——让 Agent 从聊天框里走出来，真正动手。


### anthropics/skills

**一句话概括**：Claude 技能系统的官方示例库，每个技能是一个带 SKILL.md 的自包含文件夹，从艺术创作到企业工作流都有。

**详细介绍**：它把“教 Claude 做重复任务”这件事拆成可读的指令、脚本和资源，方便你照着改自己的技能。局限在于这些是演示性质，不是开箱即用的生产模块，且绑定 Claude 的加载机制。

**项目网址**：https://github.com/anthropics/skills

**Star 数量**：191,301


### meta/astryx

**一句话概括**：Meta 内部用了八年的设计系统开源，150+ 组件、品牌主题和 CLI 打包成一个 React 19 + StyleX 的整体。

**详细介绍**：卖点是不锁死样式：组件内部结构开放，swizzle 能把源码 eject 出来自己改。目前仍是 Beta，且 StyleX 的采用门槛需要团队自己掂量。

**项目网址**：https://github.com/meta/astryx

**Star 数量**：20,684


### sherlock-project/sherlock

**一句话概括**：按用户名跨社交网络追查账号的 Python CLI，老牌信息收集工具，常年挂在安全类榜单上。

**详细介绍**：适合渗透测试前的信息搜集或数字取证，一条命令扫多个平台。但平台反爬和账号隐私边界是现实限制，结果需要人工复核，不能当定论。

**项目网址**：https://github.com/sherlock-project/sherlock

**Star 数量**：107,582


### google-deepmind/mujoco

**一句话概括**：DeepMind 维护的通用物理引擎，专攻多关节动力学与接触仿真，机器人、生物力学和动画研究的老朋友。

**详细介绍**：C API 加 Python 绑定，运行时针对低层预分配数据结构调优，适合需要快速准确仿真的研究场景。上手曲线不低，浏览器里能先试再决定是否本地部署。

**项目网址**：https://github.com/google-deepmind/mujoco

**Star 数量**：17,021


### anthropics/claude-quickstarts

**一句话概括**：Claude API 的可部署应用起点集合，客服 Agent、金融数据分析、电脑操控演示各占一个样板间。

**详细介绍**：每个 quickstart 给的是可改可扩的骨架，不是成品。适合想快速验证 API 能力边界的开发者，但生产化仍需自己补鉴权、日志和错误处理。

**项目网址**：https://github.com/anthropics/claude-quickstarts

**Star 数量**：20,131


### garrytan/gbrain

**一句话概括**：给已有 Agent 加一层可自控的记忆：显式存事实、带来源、支持更正和撤回，跨 Agent 共享。

**详细介绍**：从无密钥的关键词检索起步，需要时再加语义搜索和后台 enrichment。MIT 许可可自托管，托管版是可选付费项，适合在意记忆数据归属的人。

**项目网址**：https://github.com/garrytan/gbrain

**Star 数量**：32,274


### vercel-labs/agent-browser

**一句话概括**：Rust 写的浏览器自动化 CLI，把页面读成带 @e1 引用的紧凑文本，Agent 一次一条命令地操作。

**详细介绍**：浏览器在命令之间保持打开，每步只是一次短 shell 调用，快照后 DOM 一变就得重新取引用。这种“看一步走一步”的节奏比一次性脚本更贴近 Agent 的实际工作方式。

**项目网址**：https://github.com/vercel-labs/agent-browser

**Star 数量**：48,663


### ruvnet/RuView

**一句话概括**：用普通 WiFi 信号做空间感知：穿墙检测存在、测呼吸心率、追踪移动，不碰摄像头。

**详细介绍**：原生对接 Home Assistant、Apple Home、Google Home 和 Alexa，每个节点出 21 个实体。想法很野，但 WiFi 感知的精度和误报在真实家居环境里仍需验证，别急着替代传统传感器。

**项目网址**：https://github.com/ruvnet/RuView

**Star 数量**：103,618


### ZhuLinsen/daily_stock_analysis

**一句话概括**：LLM 驱动的多市场股票分析系统，每日自动生成决策仪表盘并推送到企微、飞书、Telegram 等渠道。

**详细介绍**：覆盖 A 股到美股、日股、韩股，带 15 种内置策略和多轮追问。零成本定时运行靠 GitHub Actions，但 AI 给出的买卖点位和评分只能当参考，不是投资建议。

**项目网址**：https://github.com/ZhuLinsen/daily_stock_analysis

**Star 数量**：69,147


### homeassistant-ai/ha-mcp

**一句话概括**：让 Claude、ChatGPT 通过 MCP 配置和自动化 Home Assistant，推荐以 HACS 集成方式在进程内跑完整服务器。

**详细介绍**：覆盖 HA OS、Supervised、Container 和 Core 全安装类型，v7.3.0 起 ha_config_set_yaml 移入 beta。对想用自然语言管智能家居的人是捷径，但管理员令牌的权限边界要自己收紧。

**项目网址**：https://github.com/homeassistant-ai/ha-mcp

**Star 数量**：6,129


**今日总结**：Agent 生态正在从“能聊”转向“能记、能看、能动手”，但今天这批项目大多还在 Beta 或演示阶段，真正落地前先想清楚权限和数据归属。
