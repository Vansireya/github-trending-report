# AI 代码审查与代理协作工具集中出现

今天榜单几乎被 AI 辅助开发工具占满，从阿里内部打磨两年的代码审查 CLI 到 OpenAI 的安全扫描工具，都在把大模型塞进工程流程。最值得看的是 alibaba/open-code-review：它用确定性管道加 LLM Agent 做行级评论，token 消耗只有通用代理的九分之一，说明工程化约束比模型本身更关键。


### alibaba/open-code-review

**一句话概括**：阿里内部跑了两年的 AI 代码审查 CLI，用确定性管道加 LLM Agent 做行级评论，token 消耗只有通用代理的九分之一。

**详细介绍**：它读取 Git diff，让 Agent 能读完整文件、搜索代码库、参考其他变更文件来生成深度评论，而不是只看 diff 表面。内置多语言规则集覆盖 NPE、线程安全、XSS、SQL 注入，还能用 ocr scan 审查整个文件。限制是必须配置模型端点，效果依赖所选 LLM。

**项目网址**：https://github.com/alibaba/open-code-review

**Star 数量**：50,768


### GoogleChrome/modern-web-guidance-src

**一句话概括**：Chrome、Edge、Firefox 和 MDN 团队共同维护的编码代理技能包，把现代 Web 平台最佳实践和兼容性数据直接喂给代理。

**详细介绍**：编码代理常因训练数据里大量遗留代码而默认生成旧模式，这个项目用技能包把代理往原生、高性能的现代 Web 方案上引。仓库本身是内容编写、校准和评估的源码库，不是直接安装的成品，需要按文档走安装向导。

**项目网址**：https://github.com/GoogleChrome/modern-web-guidance-src

**Star 数量**：5,002


### openai/codex-security

**一句话概括**：OpenAI 的安全扫描 CLI 和 TypeScript SDK，能找漏洞、验证候选发现、生成补丁并验证修复。

**详细介绍**：支持扫描仓库、指定路径或 Git 变更，深度扫描会重复标准扫描并去重结果。还能起草 SECURITY.md、保存威胁模型、按自定义标准评估严重性、从 Git 历史推荐负责人，并把发现同步到 Linear、Jira 或 GitHub。适合 DevSecOps 流程，但依赖 Codex 生态。

**项目网址**：https://github.com/openai/codex-security

**Star 数量**：13,214


### ZhuLinsen/daily_stock_analysis

**一句话概括**：LLM 驱动的多市场股票分析系统，每日自动生成决策仪表盘并推送到企业微信、飞书、Telegram 等渠道。

**详细介绍**：覆盖 A 股、港股、美股、日股、韩股、台股和 ETF，聚合行情、K 线、技术指标、新闻、公告和基本面数据。支持 15 种内置策略的多轮追问，以及图片、CSV、Excel 导入。数据源和 AI 模型都可配置，但不同市场的数据源能力边界需要看文档确认。

**项目网址**：https://github.com/ZhuLinsen/daily_stock_analysis

**Star 数量**：71,770


### we-promise/sure

**一句话概括**：Maybe Finance 被放弃后的社区分叉，一个可自托管的个人财务应用，继承了原项目近百万美元开发投入的代码库。

**详细介绍**：原团队 2021 到 2022 年做了完整功能的个人财务和财富管理应用，商业失败后开源，社区接手维护。适合想自己托管财务数据、不信任 SaaS 的用户。但作为分叉项目，长期维护节奏和功能演进方向需要观察。

**项目网址**：https://github.com/we-promise/sure

**Star 数量**：14,835


### backnotprop/plannotator

**一句话概括**：本地浏览器里的 AI 编码代理审查界面，把计划、规格、HTML 等产物标注后一键把反馈发回代理。

**详细介绍**：通过插件、钩子和命令接入 Claude Code、Codex、Copilot CLI、Gemini CLI 等代理，代理提出决策或完成工作时自动在浏览器打开，用户标注评论后直接回传。适合多代理并行工作时保持人在回路，但需要代理侧支持相应的钩子机制。

**项目网址**：https://github.com/backnotprop/plannotator

**Star 数量**：10,525


### louislam/uptime-kuma

**一句话概括**：老牌自托管监控工具，界面花哨反应快，支持 HTTP、TCP、Ping、DNS、Docker 容器等十几种监控类型和 90 多个通知渠道。

**详细介绍**：20 秒间隔、多语言、多状态页、证书信息、代理和 2FA 都齐了，Docker Compose 一条命令就能跑。注意官方明确不支持 NFS 文件系统，必须映射到本地目录，另外 Google 搜索结果里的 uptimekuma.co 不是官方站。

**项目网址**：https://github.com/louislam/uptime-kuma

**Star 数量**：93,921


### block/buzz

**一句话概括**：Block 出的自托管协作空间，人和 AI 代理共享同一批房间，底层是 Nostr 中继，每条消息和操作都是签名事件。

**详细介绍**：代理进入房间后能开仓库、发补丁、参与评审，所有状态对人和进程用同一套身份模型和审计轨迹。当前单中继部署下一个 URL 对应一个社区，适合想要数据主权、又想让代理深度参与开发流程的团队。Rust 实现，生态还在早期。

**项目网址**：https://github.com/block/buzz

**Star 数量**：37,331


### tradermonty/claude-trading-skills

**一句话概括**：给个人投资者用的 Claude Code 技能包，把市场复盘、风险管理、交易计划和日志变成结构化工作流。

**详细介绍**：定位不是让 AI 替你做买卖决策，而是用清单和流程约束交易纪律，核心是长期投资和 ETF，波段交易作为卫星策略。作者明确说这不是信号服务，也不承诺盈利，适合想改善决策过程而非找代码抄作业的人。

**项目网址**：https://github.com/tradermonty/claude-trading-skills

**Star 数量**：4,254


### tailscale/tailcat

**一句话概括**：Tailscale 官方用自家开源组件做的 netcat 替代品，走 Tailscale 数据平面但不碰控制平面，不需要账号。

**详细介绍**：一端跑监听拿到短地址，另一端用该地址连接，元数据通过任意带外方式交换。流量端到端 WireGuard 加密，先经 DERP 引导再尝试 NAT 打洞升级为直连 UDP。适合临时点对点传数据又不想注册 Tailscale 的场景，但需要自己解决地址交换。

**项目网址**：https://github.com/tailscale/tailcat

**Star 数量**：9,528


**今日总结**：今天最值得琢磨的是阿里和 OpenAI 不约而同把重点放在工程约束而非模型能力上，代码审查和安全扫描正在从通用代理手里抢回精度和成本。自托管协作和监控工具则提醒，数据主权仍是长期需求。
