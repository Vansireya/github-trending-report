# 今日 GitHub 狠活：AI 当保安、特工用插件、原始人写代码

大家好，我是你们的毒舌技术博主。今天这份榜单很有意思：有 AI 帮你找漏洞的、有让 Claude 变特工的、还有教你像原始人一样说话的。别急，一个一个来。

## 1. usestrix/strix

- **一句话概括**：开源 AI 渗透测试工具，帮你把 App 的漏洞挖出来并修好。
- **详细介绍**：还在手动测安全？太慢了。Strix 就像个 AI 保安，自动扫描你的代码，找出那些连你自己都懒得看的漏洞，然后还能给出修复建议。别问它能不能防住黑客，至少能让你的代码看起来像那么回事。
- **项目网址**：https://github.com/usestrix/strix
- **Star 数量**：34,728
- **推荐指数**：★★★★☆（4.5 星，少半星是因为它可能让你觉得自己写的代码太烂）

## 2. openai/codex-plugin-cc

- **一句话概括**：让 Claude Code 也能用上 OpenAI 的 Codex 来审查代码或委派任务。
- **详细介绍**：OpenAI 终于想通了，不能光让自家 AI 干活，也得让 Claude 来打工。这个插件让 Claude Code 能调用 Codex 来审代码，或者把任务甩给 Codex。相当于你雇了两个 AI 互相卷，你只需要在旁边喝咖啡。
- **项目网址**：https://github.com/openai/codex-plugin-cc
- **Star 数量**：23,255
- **推荐指数**：★★★★☆（4 星，毕竟 OpenAI 出品，但别指望它帮你写情书）

## 3. JuliusBrussee/caveman

- **一句话概括**：一个让 Claude Code 像原始人一样说话的技能，能砍掉 65% 的 token 消耗。
- **详细介绍**：你还在用复杂的长句跟 AI 聊天？太奢侈了！这个项目教你用原始人的方式跟 AI 交流，比如“修 bug”改成“坏修”。结果呢？Token 消耗直接砍掉 65%。省下的钱够你买杯奶茶了，而且 AI 还听得懂，毕竟它也是石头里蹦出来的。
- **项目网址**：https://github.com/JuliusBrussee/caveman
- **Star 数量**：82,989
- **推荐指数**：★★★★★（5 星，省钱又能装 X，谁不爱？）

## 4. elastic/elasticsearch

- **一句话概括**：免费开源的分布式搜索引擎，RESTful 接口。
- **详细介绍**：这玩意儿还用介绍？Elasticsearch 就是搜索界的瑞士军刀，从日志分析到电商搜索都能干。你写的每一行代码、每一条日志，它都能给你翻出来。但别用它搜“我昨天去哪吃晚饭了”，它只会告诉你“你昨天没写代码”。
- **项目网址**：https://github.com/elastic/elasticsearch
- **Star 数量**：77,347
- **推荐指数**：★★★★★（5 星，经典永不过时，但别装太多插件把自己搞崩了）

## 5. actions/checkout

- **一句话概括**：GitHub Actions 里拉取仓库的官方动作。
- **详细介绍**：这是 GitHub Actions 里最基础、最无聊但也最重要的动作。没有它，你的 CI/CD 流程连代码都拿不到。就像你做饭之前得先买菜一样，虽然没人会夸你买菜厉害，但没菜你只能喝西北风。
- **项目网址**：https://github.com/actions/checkout
- **Star 数量**：8,268
- **推荐指数**：★★★☆☆（3 星，功能单一但不可或缺，就像盐）

## 6. ChromeDevTools/chrome-devtools-mcp

- **一句话概括**：让编程代理也能用 Chrome 开发者工具。
- **详细介绍**：以前只有人类才能点开 F12 调试网页，现在 AI 也能了。这个项目让 AI 代理能像人类一样操作 Chrome DevTools，看网络请求、改样式、查性能。以后 AI 帮你改个 CSS 颜色，都不用你动手了——虽然它可能会给你改成死亡芭比粉。
- **项目网址**：https://github.com/ChromeDevTools/chrome-devtools-mcp
- **Star 数量**：45,504
- **推荐指数**：★★★★☆（4 星，AI 调试利器，但小心它把你网站搞崩）

## 7. ansible/ansible

- **一句话概括**：极其简单的 IT 自动化平台，用 SSH 就能部署应用和管理系统。
- **详细介绍**：Ansible 就是运维界的“傻瓜相机”。你不需要在远程机器上装任何代理，只要会写 YAML 配置文件，就能一键部署几百台服务器。它用接近英语的语法，让你从“部署”变成“写个剧本”。但注意，别写个“rm -rf /”的剧本，否则你的老板会让你亲自去修服务器。
- **项目网址**：https://github.com/ansible/ansible
- **Star 数量**：69,216
- **推荐指数**：★★★★★（5 星，运维神器，但学起来需要点耐心）

## 8. facebook/astryx

- **一句话概括**：Facebook 开源的、完全可定制的设计系统，且支持 AI 代理。
- **详细介绍**：Facebook 终于意识到设计系统不能只给人类看。Astryx 是一个设计系统，你不仅可以改颜色、改字体，还能让 AI 代理自动用它来生成 UI。以后你写代码时，AI 可能直接帮你把按钮样式调好了——虽然它可能会把按钮做成蓝色加圆角，跟 Facebook 一模一样。
- **项目网址**：https://github.com/facebook/astryx
- **Star 数量**：4,698
- **推荐指数**：★★★☆☆（3.5 星，新项目，前景不错但还没火起来）

## 9. rommapp/romm

- **一句话概括**：好看又强大的自托管 ROM 管理器与模拟器。
- **详细介绍**：怀旧游戏玩家福音！这个项目让你自己搭建一个 ROM 管理平台，支持上传、分类、甚至在线游玩。再也不用担心你的 GBA 游戏文件散落在各个硬盘里了。但注意，别把盗版 ROM 传上去，否则任天堂律师函警告。
- **项目网址**：https://github.com/rommapp/romm
- **Star 数量**：9,824
- **推荐指数**：★★★★☆（4 星，情怀加分，但需要你会折腾 Docker）

## 10. harvard-edge/cs249r_book

- **一句话概括**：哈佛大学《机器学习系统》课程的开源教材。
- **详细介绍**：想学 ML 系统设计？别去报天价培训班了，哈佛直接把教材开源了。这本书讲的是如何设计、训练和部署机器学习系统，从硬件到软件全都有。读完之后，你可能会发现自己之前写的 ML 代码就像用算盘算微积分。
- **项目网址**：https://github.com/harvard-edge/cs249r_book
- **Star 数量**：26,196
- **推荐指数**：★★★★★（5 星，免费、高质量、哈佛出品，还要啥自行车？）
