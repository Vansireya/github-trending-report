今日 GitHub 狠活：AI 科学家、代码间谍卫星、还有能拍大片的开源神器！

各位码农朋友们，早上好！今天的 GitHub Trending 榜单又是神仙打架的一天。从能把截图变成代码的老牌神器，到号称能让你家浏览器变成“上帝视角”间谍卫星的玩意儿，还有让 AI 直接变身科学家的技能库……话不多说，咱们直接开冲！

tt-a1i/archify

🎯 一句话概括: 让 AI 画出漂亮又严谨的架构图，还能动起来。
💡 详细介绍: 是不是每次写技术文档画架构图都想砸电脑？Visio 太笨重，Draw.io 又不够好看。Archify 就是一个专门给 AI Agent 用的“画图技能包”。它能生成自包含的 HTML 图表，包括架构图、流程图、时序图、数据流图等。关键是输出是单个 HTML 文件，可以直接分享，还带交互动效，导出 PDF 或图片非常清晰。对于有“文档洁癖”的程序员来说，这玩意儿简直是救星。
🔗 项目网址: https://github.com/tt-a1i/archify
✨ Star 数量: 28,112
⭐ 推荐指数: ★★★★☆（画图苦手必备，但刚需程度看个人）

K-Dense-AI/scientific-agent-skills

🎯 一句话概括: 把任何 AI 助手变成“科研狗”的超级技能库。
💡 详细介绍: 这个项目有点东西，它号称有 163 个经过验证的科学技能，覆盖生物、化学、医学和药物发现领域，还有 100 多个科学数据库的接口。简单说，如果你用 Cursor 或 Claude Code 写代码，装上这个库，你的 AI 就能帮你查文献、分析蛋白质结构、甚至设计实验方案。对于科研工作者来说，这相当于给 AI 装了一个“博士学位”。不过对于普通程序员来说，可能有点过于硬核。
🔗 项目网址: https://github.com/K-Dense-AI/scientific-agent-skills
✨ Star 数量: 36,850
⭐ 推荐指数: ★★★★☆（科研党五星，普通码农三星）

anthropics/claude-plugins-official

🎯 一句话概括: Anthropic 官方出品的 Claude Code 插件商店。
💡 详细介绍: 这是官方“亲儿子”目录，专门收录高质量 Claude Code 插件。就像 VS Code 的插件市场一样，但这里全是 Anthropic 官方认证过的，质量有保障。如果你想给 Claude Code 加点新功能，又怕装到不靠谱的第三方插件，直接来这里翻牌子准没错。目前还是早期阶段，但潜力巨大。
🔗 项目网址: https://github.com/anthropics/claude-plugins-official
✨ Star 数量: 35,098
⭐ 推荐指数: ★★★★☆（Claude Code 用户必看）

bilawalsidhu/gods-eye-view

🎯 一句话概括: 在浏览器里开一个“上帝视角”的实时卫星地图。
💡 详细介绍: 这名字起得霸气，但功能确实不虚。它不是一个简单的 3D 地球，而是一个实时的开源空间情报工具。你可以看到真实的卫星数据、飞机轨迹、船舶位置等，全部呈现在一个逼真的 3D 星球上。对于喜欢折腾地图可视化、或者想看看“世界实时动态”的极客来说，这绝对是个玩具级神器。不过别想歪了，它用的是公开数据，不是真的间谍卫星。
🔗 项目网址: https://github.com/bilawalsidhu/gods-eye-view
✨ Star 数量: 11,335
⭐ 推荐指数: ★★★★☆（可视化爱好者狂喜）

abhigyanpatwari/GitNexus

🎯 一句话概括: 纯浏览器端的代码知识图谱生成器，还自带 RAG 问答。
💡 详细介绍: 想象一下，你扔给它一个 GitHub 仓库链接，它就在你浏览器里生成一个可视化的代码知识图谱。这不仅仅是画个依赖关系图，它内置了 Graph RAG Agent，你可以直接问它“这个模块的异常处理逻辑是什么？”或者“这个函数被谁调用了？”。对于接手老项目或者阅读大型开源代码库来说，这比在 IDE 里逐层跳转效率高多了。而且零服务器，隐私友好。
🔗 项目网址: https://github.com/abhigyanpatwari/GitNexus
✨ Star 数量: 46,202
⭐ 推荐指数: ★★★★★（代码阅读困难症患者的福音）

JetBrains/go-modern-guidelines

🎯 一句话概括: 教 AI 写“现代 Go 代码”的官方指南。
💡 详细介绍: JetBrains 官方下场，专门给 AI 编程助手看的 Go 语言规范。如果你发现 AI 写的 Go 代码总是带着一股 Java 味或者老掉牙的写法，这个项目就是用来“调教”它的。里面涵盖了 Go 社区的最佳实践、惯用写法、性能陷阱等。虽然 Star 数不高，但胜在权威，属于“小而美”的实用工具。
🔗 项目网址: https://github.com/JetBrains/go-modern-guidelines
✨ Star 数量: 2,647
⭐ 推荐指数: ★★★☆☆（Go 程序员可以看看）

calesthio/OpenMontage

🎯 一句话概括: 开源界的“电影梦工厂”，让 AI 帮你剪片子。
💡 详细介绍: 这可能是今天最唬人的项目。它号称是全球首个开源“智能体视频制作系统”，包含 12 条生产流水线、100 多个工具和 700 多个技能文件。简单来说，你只要把你的 AI 编程助手（比如 Cursor）变成你的导演，它就能指挥 AI 工具帮你完成从脚本、分镜、素材生成到剪辑的全流程。虽然不知道实际效果如何，但光看这配置和 53k 的 Star 数，就值得关注。
🔗 项目网址: https://github.com/calesthio/OpenMontage
✨ Star 数量: 53,440
⭐ 推荐指数: ★★★★☆（视频创作者潜力巨大，但可能上手复杂）

abi/screenshot-to-code

🎯 一句话概括: 截图秒变前端代码，老牌神器依旧能打。
💡 详细介绍: 这个项目已经火了好几年了，但热度不减。它的功能简单粗暴：你把网页截图或者设计稿拖进去，它就能生成对应的 HTML/Tailwind/React/Vue 代码。虽然现在很多工具都能做类似的事，但它的生态和社区支持最好，而且支持多种框架。对于前端开发者和设计师来说，这是提效的“老伙计”了。
🔗 项目网址: https://github.com/abi/screenshot-to-code
✨ Star 数量: 75,648
⭐ 推荐指数: ★★★★★（经典永流传，效率神器）

cursor/plugins

🎯 一句话概括: Cursor 编辑器的官方插件规范和插件库。
💡 详细介绍: 作为当下最火的 AI 编辑器，Cursor 也开始搞插件生态了。这个仓库定义了 Cursor 插件的规范，并收录了官方插件。如果你在用 Cursor，可以看看这里有没有能提升你开发体验的插件。虽然现在插件数量还不多，但毕竟是官方主导，未来可期。
🔗 项目网址: https://github.com/cursor/plugins
✨ Star 数量: 6,009
⭐ 推荐指数: ★★★☆☆（Cursor 用户关注一下）

freestylefly/awesome-gpt-image-2

🎯 一句话概括: GPT-Image2 的“工业级”提示词模板库，专治“AI 画图手残党”。
💡 详细介绍: 这名字起得直白，就是一个针对 GPT-Image2 的提示词工程指南。它逆向分析了 530+ 个案例，提炼出 20+ 套工业级模板，甚至把提示词做成了“代码”来管理。如果你用 AI 画图总是感觉“差点意思”，或者想生成高质量、风格统一的图片，这个库能帮你少走很多弯路。它不只是给几个 Prompt 例子，更是提供了一套方法论。
🔗 项目网址: https://github.com/freestylefly/awesome-gpt-image-2
✨ Star 数量: 24,417
⭐ 推荐指数: ★★★★☆（AI 绘画爱好者的“武功秘籍”）

今日总结：今天的榜单充分体现了 AI 正在“入侵”各个领域——从画图、写代码到搞科研、剪视频。GitNexus 和 OpenMontage 是潜力股，screenshot-to-code 是常青树。各位按需取用，明天见！
