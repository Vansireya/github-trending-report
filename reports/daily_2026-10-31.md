# Agent 记忆、技能与工作台同日升温

今天榜单几乎被 Agent 周边工具占满：从跨会话记忆、设计词汇到技能包，都在补 Agent 落地时最缺的那几块。最值得看的是 claude-mem 和 impeccable，一个解决上下文断裂，一个试图把“审美”变成可调用的指令。


### thedotmack/claude-mem

**一句话概括**：给 Claude Code 等 Agent 做持久记忆：自动抓取工具调用观察，压缩成语义摘要，下次会话再注入。

**详细介绍**：它面向多会话开发场景，解决 Agent 每次重连后“失忆”的问题。做法是记录工具使用观察并生成摘要，但摘要质量取决于压缩策略，且默认走托管记忆服务，本地观察需显式切换。

**项目网址**：https://github.com/thedotmack/claude-mem

**Star 数量**：106,454


### milind-soni/OpenMausBot

**一句话概括**：把 Claude、Codex 等本地 Agent 包装成聊天应用里的“联系人”，每个 Bot 配独立人格、模型和云电脑。

**详细介绍**：适合想自托管多 Agent 协作的个人或小团队。每个 Bot 有独立浏览器和文件环境，可旁观工作并审批关键动作；但依赖本地已装好的 Agent CLI，且项目明确与 xAI、Meta 等无关联。

**项目网址**：https://github.com/milind-soni/OpenMausBot

**Star 数量**：8,784


### pbakaus/impeccable

**一句话概括**：给编码 Agent 一套设计词汇：用 polish、bolder 调方向，用 critique、audit 做审查，专治 AI 生成的套路化界面。

**详细介绍**：它不生成页面，而是通过斜杠命令把“品味”拆成可执行指令，让 Agent 避开奶油底、紫蓝渐变、卡片套卡片这类默认审美。效果仍取决于模型理解，但至少把模糊的“好看”变成了可操作的词。

**项目网址**：https://github.com/pbakaus/impeccable

**Star 数量**：97,205


### CopilotKit/OpenBot

**一句话概括**：开源自托管的 AI 同事模板：每个同事有独立浏览器、文件和工具权限，动作先决策后记录。

**详细介绍**：面向想完全掌控 Agent 基础设施的团队，通过 AG-UI 接入任意 Agent 栈。它强调可审计和人工接管，但定位是模板而非产品，没有托管版，需要自己替换示例租户包来用。

**项目网址**：https://github.com/CopilotKit/OpenBot

**Star 数量**：8,863


### Renhuai123/ziwei-doushu

**一句话概括**：紫微斗数开源排盘引擎，基于倪海厦《天纪》体系，带完整算法、四化系统和古籍原文数据。

**详细介绍**：适合想研究或二次开发传统命理排盘的人。项目还发布了 67.5 万张命盘、877 万段解读的数据集，体量惊人；但 README 自己也注明六亲判断存在局限，相关分析仅供参考。

**项目网址**：https://github.com/Renhuai123/ziwei-doushu

**Star 数量**：11,377


### expo/skills

**一句话概括**：Expo 官方出的 Agent 技能包，教 AI 在 Expo 项目里正确使用 API、EAS 和移动端约束。

**详细介绍**：解决 Agent 写 Expo 代码时凭感觉猜 API 的问题。技能通过插件市场或 skills CLI 安装，覆盖构建、部署、升级、调试；官方强调文档和 CLI 仍是事实来源，技能只是帮 Agent 用对。

**项目网址**：https://github.com/expo/skills

**Star 数量**：3,914


### macro-inc/macro

**一句话概括**：把邮件、聊天、文档、任务、Agent 和 CRM 塞进一个界面的团队工作台，所有内容 @ 链接并共享 AI 记忆。

**详细介绍**：瞄准小团队工具碎片化：Slack、Notion、Linear、HubSpot 各管一摊，靠 Zapier 缝合。Macro 用 SolidJS 和 Rust 重做成单一系统，团队自用两年；但“全都要”也意味着迁移成本和功能深度取舍。

**项目网址**：https://github.com/macro-inc/macro

**Star 数量**：5,902


### mattpocock/skills

**一句话概括**：Matt Pocock 从自己 .agents 目录掏出来的日常工程技能，主打小而可组合，不接管流程。

**详细介绍**：针对 GSD、BMAD、Spec-Kit 这类“拥有流程”的方案，作者认为它们让 bug 更难修。这些技能保持小份、可改、跨模型，适合想保留控制权的工程师；但需要自己挑着装，装两套会重复。

**项目网址**：https://github.com/mattpocock/skills

**Star 数量**：307,567


### pingdotgg/t3code

**一句话概括**：Agent 控制台：用移动端、Web 和 Electron 桌面端远程操控本机上的 Claude Code、Codex、Cursor 等 Agent。

**详细介绍**：适合想让 Agent 在电脑上跑、自己用手机盯进度的人。它不卖服务，支持已有订阅，强调性能和可 fork；前提是本机已安装并登录至少一个受支持的 Agent CLI。

**项目网址**：https://github.com/pingdotgg/t3code

**Star 数量**：32,870


### HKUDS/DeepTutor

**一句话概括**：港大数据智能实验室的终身个性化辅导系统，带多 Agent、深度研究和交互式学习工作区。

**详细介绍**：面向想搭 AI 家教或自学工具的人，功能铺得很开：学习路径、题库、视频课、语音、插件。更新节奏快，但模块多也意味着部署和配置门槛不低，适合愿意折腾的开发者。

**项目网址**：https://github.com/HKUDS/DeepTutor

**Star 数量**：51,873


**今日总结**：今天最明显的信号是 Agent 生态在补“记忆”和“技能”两块短板，但多数项目仍要求你已有 Agent CLI 并愿意自己接线。先挑一个解决你真实断点的，别一次装全套。
