# Agent 技能包与工具链密集登场

今天榜单几乎被 Agent 技能包和配套工具占据：Claude-BugHunter 把漏洞挖掘经验打包成 85 个技能，superpowers 则试图给编码 Agent 立一套开发方法论。另一边，minimind 继续用极低成本训练小模型，提醒人们底层复现仍有独立价值。


### elementalsouls/Claude-BugHunter

**一句话概括**：把 85 个漏洞挖掘技能、16 个斜杠命令和 681 条公开报告模式塞进 Claude Code 的技能包。

**详细介绍**：面向授权红队和漏洞赏金场景，按方法论、Web 应用狩猎、企业身份与基础设施攻击矩阵分层组织，并集成 Burp MCP。局限在于它依赖 Claude Code 技能系统，且 README 强调需在授权范围内使用，不能当作自动化攻击工具。

**项目网址**：https://github.com/elementalsouls/Claude-BugHunter

**Star 数量**：26,356


### obra/superpowers

**一句话概括**：一套给编码 Agent 用的完整软件开发方法论，由可组合技能和初始指令构成。

**详细介绍**：它让 Agent 先追问需求、拆出规格，再分块确认设计，最后生成连“没品味、没判断力”的初级工程师也能执行的计划。覆盖 Claude Code、Codex、Cursor 等多种宿主，但本质是流程约束，效果取决于 Agent 是否遵守技能指令。

**项目网址**：https://github.com/obra/superpowers

**Star 数量**：328,476


### HKUDS/CLI-Anything

**一句话概括**：试图把各类软件包装成 Agent 可直接调用的 CLI，并配一个社区 CLI-Hub 做分发。

**详细介绍**：通过 pip 安装 cli-anything-hub 后，可浏览和安装社区构建的 CLI，让 Agent 操作 CAD、3D 场景、图表等软件。思路是把“Agent 原生”落到命令行接口层，但实际覆盖度和各 CLI 的稳定性取决于社区贡献。

**项目网址**：https://github.com/HKUDS/CLI-Anything

**Star 数量**：67,105


### jingyaogong/minimind

**一句话概括**：用约 3 块钱 GPU 租用成本和 2 小时 SFT，从零训出 64M 参数的超小语言模型。

**详细介绍**：项目开源了极简模型结构及预训练、SFT、LoRA、RLHF、Agentic RL 等全链路代码，核心算法用原生 PyTorch 实现。适合想理解大模型内部机制的个人开发者，但 64M 规模的能力边界有限，不能替代实用级模型。

**项目网址**：https://github.com/jingyaogong/minimind

**Star 数量**：72,300


### cursor/plugins

**一句话概括**：Cursor 官方插件规范与官方插件集合，每个插件是带独立 manifest 的目录。

**详细介绍**：仓库列出教学、持续学习、团队工具包、分支审查等插件，其中 thermos 做深度安全与正确性审计，ralph-loop 做自引用迭代循环。它定义了插件如何组织，但生态尚在早期，插件质量和维护取决于各自作者。

**项目网址**：https://github.com/cursor/plugins

**Star 数量**：20,048


### firecrawl/firecrawl

**一句话概括**：把网站抓取成干净 Markdown 的知识基础设施，支持本地单二进制、云服务和自托管三种形态。

**详细介绍**：Firecrawl Local 无需数据库和队列，可作为 MCP 服务器接入 AI Agent；云服务额外提供搜索和 550+ 数据提供商。适合给 Agent 补充网页知识，但本地版需要 Rust 和 C 编译器，自托管则要自己维护队列与数据库。

**项目网址**：https://github.com/firecrawl/firecrawl

**Star 数量**：211,816


### nginx/nginx

**一句话概括**：NGINX 官方开源仓库，Web 服务器、反向代理、负载均衡和内容缓存的经典实现。

**详细介绍**：README 面向新手提供结构化入门，覆盖模块、配置、运行时、SSL、限流和缓存等基础主题。它本身不是新项目，上榜更多说明基础设施常青；实际部署仍需参考完整文档，不能只靠 README 上手。

**项目网址**：https://github.com/nginx/nginx

**Star 数量**：33,691


### openvinotoolkit/openvino

**一句话概括**：英特尔主导的深度学习推理优化与部署工具包，覆盖 CPU、GPU 和 NPU。

**详细介绍**：支持 PyTorch、TensorFlow、ONNX、JAX 等框架模型转换，并可通过 Optimum Intel 直接接入 Hugging Face 模型。适合在边缘到云端的英特尔硬件上压缩和部署推理，但硬件绑定较明显，非英特尔平台收益有限。

**项目网址**：https://github.com/openvinotoolkit/openvino

**Star 数量**：12,973


### cathrynlavery/diagram-design

**一句话概括**：给编码 Agent 用的图表设计技能，输出自包含 HTML + SVG，提供 52 种图表类型。

**详细介绍**：用户用自然语言描述架构图、象限图或时序图，Agent 选型并生成单个可双击打开的 HTML 文件，还能抓取网站配色和字体来匹配品牌。它明确反对 Mermaid 式粗糙输出，但图表质量仍取决于 Agent 对描述的理解。

**项目网址**：https://github.com/cathrynlavery/diagram-design

**Star 数量**：74,548


### mvanhorn/last30days-skill

**一句话概括**：让 Agent 跨 Reddit、X、YouTube、HN、Polymarket 和网页做近 30 天主题研究并合成摘要。

**详细介绍**：按 upvote、点赞和真金白银的赔率排序信息，零配置即可用 Reddit、HN、Polymarket 和 GitHub，再通过向导解锁 X、YouTube、TikTok 等来源。适合快速摸清话题热度，但摘要质量受各平台数据可及性和排序偏差影响。

**项目网址**：https://github.com/mvanhorn/last30days-skill

**Star 数量**：76,458


**今日总结**：今天最值得看的是 Agent 技能包开始分层：有人做方法论，有人做垂直领域经验封装，也有人做 CLI 和图表这类具体产出。热闹之下，真正稀缺的仍是可验证的效果和清晰的授权边界。
