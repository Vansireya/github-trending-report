今日 GitHub 狠活：Anthropic 悄悄搞金融，Google 又来抢 Agent 饭碗了

今天的榜单，一半是 AI Agent 在卷生卷死，一半是安全工具在默默守护。话不多说，开整。

anthropics/financial-services

一句话概括： Anthropic 官方下场的金融行业解决方案，大概率是把 Claude 塞进银行和券商的后台。

详细介绍： 这个项目连个像样的 description 都没写，但 36k 的 Star 摆在那里，属于"我不说话你也得看我"的类型。Anthropic 亲自出手做金融垂直领域，说明大模型落地金融不再是 PPT 里的概念了——合规、风控、投研、客服，这些场景可能都在射程范围内。痛点？金融行业数据敏感、流程复杂、监管严格，通用模型直接上容易出事，这套东西大概就是来解决"怎么让 Claude 在金融场景里既好用又不闯祸"的问题。没描述反而更让人好奇，建议关注后续更新。

项目网址： https://github.com/anthropics/financial-services

Star 数量： 36,411

推荐指数： ⭐⭐⭐⭐（官方出品，金融从业者必看，但没文档先扣一星）

agent-substrate/substrate

一句话概括： 一个用 Go 写的 Agent 底层运行时，给智能体提供"地基"。

详细介绍： 现在做 Agent 的人越来越多，但大多数都在重复造轮子——调度、状态管理、工具调用、并发控制，每个项目都得自己撸一遍。Substrate 想做的就是把这层地基抽象出来，让你专注写业务逻辑而不是底层管道。Go 语言加持意味着性能和并发是它的强项，适合对吞吐有要求的场景。痛点很明确：Agent 生态碎片化严重，缺一个大家都认的"操作系统层"。不过目前 Star 数还不算高，生态能不能起来是关键。

项目网址： https://github.com/agent-substrate/substrate

Star 数量： 3,020

推荐指数： ⭐⭐⭐（方向对，但早期项目，谨慎入坑）

dream-num/univer

一句话概括： 把表格、文档、幻灯片、画布、关系表和 PDF 全塞进一个运行时，专门伺候 AI Agent 的"Office 全家桶"。

详细介绍： 传统 Office 套件是给人用的，但 AI Agent 要操作这些格式就很痛苦——API 不统一、格式各玩各的、解析起来一堆坑。Univer 的思路是：既然 Agent 要干活，那就给它一套统一的运行时，表格、文档、PPT、PDF 全部打通。你可以理解为"给 AI 用的在线 Office 引擎"。痛点在于，现在让 Agent 处理复杂文档，要么调一堆第三方 API，要么自己写解析器，Univer 想一锅端。TypeScript 写的，前端集成友好。

项目网址： https://github.com/dream-num/univer

Star 数量： 15,548

推荐指数： ⭐⭐⭐⭐（文档处理 + Agent 是刚需，值得研究）

davila7/claude-code-templates

一句话概括： 给 Claude Code 做配置和监控的 CLI 工具，懒人福音。

详细介绍： Claude Code 很强，但配置起来也不是省油的灯——环境变量、项目模板、权限设置、调用监控，手动搞容易出错。这个工具就是把这些琐事打包成命令行操作，让你一条命令搞定配置，顺便还能监控 Claude Code 的运行状态。痛点很真实：AI 编程工具越来越复杂，配套的 DevOps 工具却跟不上，这个项目算是填了个空。31k Star 说明 Claude Code 用户基数确实大，且大家都想省事。

项目网址： https://github.com/davila7/claude-code-templates

Star 数量： 31,164

推荐指数： ⭐⭐⭐⭐（Claude Code 重度用户必备）

google/ax

一句话概括： Google 开源的 Agent 编排运行时，翻译过来就是"Google 版的 Agent 调度中心"。

详细介绍： Google 在 Agent 领域一直没闲着，AX 就是他们给出的编排答案。所谓"agentic orchestration runtime"，说白了就是管理一堆 Agent 怎么协作、怎么调度、怎么传递任务。痛点在于，单个 Agent 好做，多个 Agent 协同就乱套了——谁先谁后、失败了怎么办、状态怎么同步，全是坑。Google 用 Go 写这个，明显是冲着生产环境去的。7k Star 不算爆款，但 Google 背书 + Go 性能，企业级场景可以关注。

项目网址： https://github.com/google/ax

Star 数量： 7,737

推荐指数： ⭐⭐⭐⭐（大厂出品，Agent 基础设施赛道值得押注）

mvt-project/mvt

一句话概括： 移动设备取证工具，专门查你的手机有没有被入侵。

详细介绍： 这是今天榜单里最"正经"的项目——不是 AI，不是 Agent，是实打实的安全工具。MVT 由 Amnesty International 等机构推动，用来分析 iPhone 和 Android 设备，找出间谍软件或入侵痕迹。痛点极其硬核：记者、律师、活动人士的手机被 Pegasus 之类的间谍软件盯上时，普通人根本发现不了，MVT 就是给这些人用的"体检仪"。14k Star 说明安全社区认可度很高。如果你关心隐私安全，这个项目值得了解。

项目网址： https://github.com/mvt-project/mvt

Star 数量： 14,153

推荐指数： ⭐⭐⭐⭐⭐（安全刚需，救人于水火，必须五星）

superdesigndev/treg

一句话概括： "Agent 工具界的 OpenRouter"，想让工具调用也搞统一路由。

详细介绍： OpenRouter 解决了大模型 API 碎片化的问题，Treg 想干同样的事——只不过对象换成了 Agent 的工具。现在每个 Agent 框架都有自己的工具定义格式，换个框架就得重写一遍，烦不胜烦。Treg 的思路是做一个统一层，让工具可以在不同 Agent 之间复用。痛点很准：Agent 生态越繁荣，工具碎片化越严重。不过 2k Star 说明还在早期，能不能成为标准得看社区买不买账。

项目网址： https://github.com/superdesigndev/treg

Star 数量： 2,270

推荐指数： ⭐⭐⭐（想法很好，但早期项目，观望为主）

browser-use/video-use

一句话概括： 用写代码的方式剪视频，让 AI Agent 帮你干剪辑的活。

详细介绍： browser-use 团队之前做浏览器自动化，现在把手伸向了视频剪辑。Video-use 的核心理念是：既然 Agent 能写代码操作浏览器，那也能写代码操作视频——切割、拼接、加字幕、调色，全部用代码描述，Agent 来执行。痛点在于，传统剪辑软件是给人眼和手用的，批量处理或自动化极其痛苦；而视频创作者现在都想让 AI 帮忙干活，这个项目就是那座桥。25k Star 说明需求真实且旺盛。

项目网址： https://github.com/browser-use/video-use

Star 数量： 25,908

推荐指数： ⭐⭐⭐⭐⭐（视频 + Agent 是今年大热点，这个方向很有搞头）

今日总结

今天的榜单基本被 AI Agent 基础设施 承包了：Anthropic 搞金融垂直、Google 搞编排运行时、Univer 搞文档运行时、Treg 搞工具路由、Video-use 搞视频自动化。唯一非 AI 的 MVT 反而是最"救命"的项目。一句话：Agent 生态正在从"能跑"往"好跑"进化，基础设施的军备竞赛已经打响了。
