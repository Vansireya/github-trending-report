# 今日 GitHub 狠活：当 AI 学会说人话之前，先学会了说“石头话”

> 今天的榜单弥漫着一股浓烈的“Agent 焦虑”——不是让 Agent 更聪明，就是让 Agent 更省 token，要么就是让 Agent 去当科学家。唯一正常点的是一位 NSA 老同志，默默在后面磨着逆向工程的刀。

### morluto/rea

**一句话概括**：让 AI Agent 帮你逆向工程，从 App 行为一路扒到原生二进制。

**详细介绍**：以前逆向工程是安全研究员戴着耳机、盯着 IDA Pro、靠咖啡续命的活儿。现在 rea 想让 Agent 替你干——你告诉它“这个 App 在干嘛”，它自己往下挖，挖到汇编层都不带喘的。痛点很明确：逆向门槛高、耗时长、人才贵。当然，Agent 逆向出来的结果你敢不敢直接信，那是另一个哲学问题。

**项目网址**：https://github.com/morluto/rea

**Star 数量**：272,932

**推荐指数**：⭐⭐⭐⭐⭐（安全圈和 Agent 圈的双重狂欢，虽然实际用起来可能一半时间在 debug Agent 本身）

### JuliusBrussee/caveman

**一句话概括**：让 AI 用“原始人语”说话，省下 65% 的 token。

**详细介绍**：🪨 为什么用很多 token，当很少 token 可以做事？这个项目的逻辑简单粗暴：LLM 的 token 是要花钱的，而很多废话是不必要的。于是它搞了个代理 + 技能，让 Agent 像山顶洞人一样交流——“我，要，查，数据库。返回，结果。” 结果 token 直接砍掉 65%。省钱的快乐，原始人也懂。

**项目网址**：https://github.com/JuliusBrussee/caveman

**Star 数量**：112,629

**推荐指数**：⭐⭐⭐⭐⭐（如果你每个月 API 账单让你想住山洞，这个项目就是你的火种）

### debpalash/VoiceStudio

**一句话概括**：完全本地的开源 ElevenLabs 替代品，语音克隆、配音、听写、有声书，646 种语言。

**详细介绍**：ElevenLabs 好用，但贵，而且你的声音数据要上传到别人服务器。VoiceStudio 说：不，你可以在自己机器上干这一切。语音克隆、视频配音、听写、转录、有声书制作，646 种语言——基本上把语音 AI 的活儿全包了。痛点就是两个字：隐私 + 钱包。当然，本地跑语音模型，你的 GPU 可能会发出直升机般的轰鸣。

**项目网址**：https://github.com/debpalash/VoiceStudio

**Star 数量**：69,260

**推荐指数**：⭐⭐⭐⭐⭐（开源语音圈的良心，前提是你有张好显卡）

### mksglu/context-mode

**一句话概括**：给 AI 编程 Agent 做上下文窗口优化，工具输出沙箱化后减少 98%。

**详细介绍**：Agent 编程最大的痛点之一：上下文窗口被工具输出塞爆。你让 Agent 跑个命令，它返回 5000 行日志，窗口直接没了。context-mode 的做法是：把工具输出扔进沙箱，只把关键信息喂给模型，减少 98%。还持久化会话记忆，跨 17 个平台路由。简单说，就是给 Agent 的脑子装了个“垃圾过滤器”。

**项目网址**：https://github.com/mksglu/context-mode

**Star 数量**：29,829

**推荐指数**：⭐⭐⭐⭐（痛点抓得准，但 17 个平台的兼容性能不能都靠谱，是个问号）
