给 AI Agent 补上记忆、规范与桌面手脚

今天榜单几乎被 Agent 工程化工具包场：从 NVIDIA 用本体层给 Agent 提供可信业务语义，到 claude-mem 把跨会话记忆压缩复用，再到 agent-desktop 让 Agent 直接读桌面无障碍树。最值得先看的是 auto-ontology 和 worktrunk——前者试图解决 Agent 回答“数字对不对”的根问题，后者把并行 Agent 的 Git worktree 操作压成三条命令。

1
NVIDIA/auto-ontology ★ 5,503
Python

从企业元数据自动生成本体，给 Agent 一套可查询、可溯源的数据语义层。

Agent 能查库不代表查得对，指标定义在各系统间不一致时，快而错的答案毫无价值。它把元数据整理成本体，通过 MCP、CLI、API 暴露给任意 Agent 框架，并用认证定义校验生成查询、附带血缘。局限在于效果高度依赖企业元数据本身的质量。

2
max-sixty/worktrunk ★ 11,141
Rust

把 Git worktree 管得像分支一样顺手的 Rust CLI，专为并行跑多个 AI Agent 设计。

Claude Code、Codex 这类 Agent 能长时间无人值守，同时跑五到十个很常见，但原生 git worktree 连新建都要把分支名敲三遍。Worktrunk 用三条核心命令封装增删切换，还带 hooks 和写时复制构建缓存，减少并行工作目录的重复开销。

3
mattpocock/skills ★ 313,594
Shell

作者日常工程用的 Agent 技能集，刻意做小、可改、可组合，不接管你的流程。

GSD、BMAD、Spec-Kit 这类方法试图包办过程，代价是开发者失去控制、流程本身出 bug 也难排查。这些技能反其道而行，按 Claude Code、Codex、Copilot、Gemini CLI 分别提供安装方式，强调适配任意模型、随手改造成自己的。

4
floci-io/floci ★ 29,753
Java

免费本地 AWS 模拟器，docker compose up 后把 SDK 指向 localhost:4566 就能跑。

本地开发和 CI 里模拟 AWS 常被账号、token 和付费功能门卡住。Floci 不要账号不要认证，兼容现有 AWS SDK、CLI、Terraform、CDK 和 Testcontainers，并声称可作为 LocalStack 的 drop-in 替代，换镜像即可迁移。

5
thedotmack/claude-mem ★ 113,010
TypeScript

给编码 Agent 做跨会话记忆：自动捕获工具调用观察，压缩成语义摘要再注入后续会话。

会话一断，Agent 对项目的上下文就归零。claude-mem 在后台记录工具使用观察并生成摘要，下次会话按相关性回注，支持 Claude Code、Codex、Gemini、Copilot 等多种宿主。默认走托管记忆服务，本地观察者需显式开启。

6
vercel-labs/agent-desktop ★ 15,497
Rust

不靠截图和像素匹配，直接读 macOS、Windows、Linux 桌面应用的无障碍树来操作界面。

截图式 computer use 又慢又脆。agent-desktop 把无障碍树转成带 ref 的 JSON，Agent 对 ref 点击或输入，再读一次 UI 验证结果；循环逻辑留在 Agent 侧，工具本身不含模型。快照、剪贴板和截图可能含隐私内容，日志与上传需自行隔离。

7
github/spec-kit ★ 147,422
Python

GitHub 出的规范驱动开发工具箱，给编码 Agent 提供可复用流程、模板和可验证产出。

直接让 Agent 写代码容易跑偏。Spec Kit 把建功能、修 bug、评估想法拆成独立入口，规范贯穿规划、实现与收敛；流程由可组合的原语拼装，也可自带流程。适合想要结构化但不想被单一方法论绑死的团队。

8
The-PR-Agent/pr-agent ★ 14,865
Python

最早的開源 AI PR 审查 Agent，现为 Qodo 社区维护的 legacy 项目，明确区别于其商业版。

仓库自己划清界限：这不是 Qodo 面向开源项目的免费层，而是社区维护的旧线。它接入 GitHub、GitLab、Bitbucket、Azure DevOps 做自动审查，支持 OpenAI、Anthropic、Ollama 等模型；Docker 镜像已迁到 pragent/pr-agent 命名空间，老版本冻结在旧地址。

harry0703/MoneyPrinterTurbo ★ 139,184
Python

给一个主题或关键词，自动写脚本、配素材、加字幕和背景音乐，合成高清短视频。

短视频批量生产的关键在素材匹配是否贴题。它用大模型同时写文案、提炼搜索关键词并决定画面，提供 WebUI 和 API 两种用法，底层依赖 ffmpeg 合成。README 里赞助商和 API 优惠信息密集，实际成片质量仍取决于所选模型与素材源。
