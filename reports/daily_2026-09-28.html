今日 GitHub 狠活：AI 智能体开始上班，Windows 游戏被塞进 iPhone

今天的热榜突出一个"卷"——智能体管理、智能体记忆、智能体办公全家桶，连学 AI 都要从零开始了。话不多说，开整。

1
paperclipai/paperclip ★ 90,216
TypeScript

一个开源应用，专门用来管理你手底下那堆&quot;上班摸鱼&quot;的 AI 智能体。

现在谁手上没几个 Agent？写代码的、查资料的、发邮件的，散落在各个角落，管起来比管实习生还累。Paperclip 就是冲着这个痛点来的——把这些智能体统一收编，让它们&quot;上班&quot;有组织有纪律。TypeScript 写的，前端体验应该不错。9 万 Star 说明大家是真的受够了散养智能体的苦。

2
vectorize-io/hindsight ★ 37,624
Python

给 AI 智能体装上&quot;会学习的记忆&quot;，让它别每次都失忆。

智能体最大的尴尬是什么？聊完一轮就忘了你是谁。Hindsight 主打&quot;Agent Memory That Learns&quot;，意思是不仅记住，还能从记忆里学东西。Python 生态，做 RAG 或者多轮对话的朋友可以重点关注。3.7 万 Star，算是这个细分赛道里的头部选手了。

3
debpalash/VoiceStudio ★ 40,412
Python

完全本地跑的开源版 ElevenLabs，声音克隆、配音、转录、有声书一条龙。

ElevenLabs 好用是好用，但钱包和隐私都遭不住。VoiceStudio 直接把整套能力搬到本地：声音克隆、声音设计、视频配音、听写、转录、有声书制作，还号称支持 646 种语言。4 万 Star 摆在那儿，说明&quot;本地 + 免费&quot;这四个字永远是流量密码。

4
rohitg00/ai-engineering-from-scratch ★ 59,446
Python

从零开始学 AI 工程，学完能上手造，造完能交付。

口号很直白——&quot;Learn it. Build it. Ship it for others.&quot;。市面上 AI 教程多如牛毛，但大多停留在&quot;调个 API 就完事&quot;。这个项目主打工程化视角，从底层往上一路搭。近 6 万 Star，看来想转行 AI 工程师的人是真的多。

5
InfinityLoop1308/PipePipe ★ 6,625
Shell

开源安卓 App，让你自由浏览 YouTube 等平台内容。

懂的都懂，某些平台在某些地区就是&quot;薛定谔的能访问&quot;。PipePipe 是 NewPipe 生态里的一个分支，主打自由浏览。6,625 Star，用 Shell 写的（其实主要是安卓项目），属于小而美的实用工具。有需求的朋友可以试试。

6
vercel-labs/scriptc ★ 5,440
TypeScript

Vercel 实验室出品，把 TypeScript 直接编译成原生代码。

前端圈的老话题了——JS/TS 能不能像 C 一样跑得快？scriptc 的思路是直接编译到 Native，绕过解释器和 JIT。Vercel 出品，实验性质浓厚，但 5,440 Star 说明大家都在盯着这块。想给 TS 性能开挂的可以蹲一波。

7
mvschwarz/openrig ★ 1,055
TypeScript

把 Claude Code 和 Codex 拧成一股绳，当一套系统来跑。

现在 AI 编程助手各玩各的，Claude 一套、Codex 一套，切换起来心累。openrig 是个多智能体编排框架，让这俩&quot;大佬&quot;协同工作。1,055 Star，小众但方向有意思，属于早期项目，适合喜欢折腾的先行者。

8
dream-num/univer ★ 20,551
TypeScript

给 AI 智能体准备的&quot;Office 全家桶&quot;，表格、文档、幻灯片、画布、关系表、PDF 一个运行时全包。

别的项目在做单个工具，Univer 直接做了一整套办公套件运行时，还专门为 AI Agent 优化。2 万 Star，野心不小。想象一下你的智能体不用在 Excel、Word、PPT 之间反复横跳，一个 runtime 全搞定——这才是&quot;AI 原生办公&quot;该有的样子。

9
willfaust/Madeira ★ 846
C

在&quot;越狱&quot;的 iOS 上跑 x86-64 Windows PC 游戏，靠的是 FEX-Emu + Wine + DXMT 三件套。

这个项目属于&quot;技术宅的浪漫&quot;——把 Windows PC 游戏硬生生塞进 iPhone。底层是 FEX-Emu 做指令翻译、Wine 做 Windows 兼容层、DXMT 做 DirectX 转 Metal。846 Star，C 语言写的，门槛高、折腾属性拉满，但能跑起来的那一刻绝对值回票价。前提是你得先越狱。

今日总结

今天的关键词就俩字：智能体。从管理（paperclip）、记忆（hindsight）到办公（univer），一条完整的"AI 打工人"产业链正在成型。与此同时，VoiceStudio 和 Madeira 提醒我们——开源社区的浪漫，永远在于"把贵的变免费，把不可能变可能"。

明天同一时间，我们继续蹲热榜。
