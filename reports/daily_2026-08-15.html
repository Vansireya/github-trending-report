今日 GitHub 狠活：AI 画图、OSINT 侦探、还有 128K Star 的官方神器！

各位老铁，又到了每日 GitHub 宝藏挖掘时间。今天的热榜可以说是“神仙打架”，从帮你“人肉”邮箱的渗透工具，到能在手机里跑大模型的微型 AI，再到那个让打工人眼前一黑的 128K Star 项目。废话不多说，直接上硬菜！

cathrynlavery/diagram-design

🎯 一句话概括: 给 Claude Code 用的 29 种“编辑级”图表模板，告别丑陋的 Mermaid 图。
💡 详细介绍: 受够了 AI 生成的图表总是带着一股“程序员式审美”的塑料感？这个项目就是来拯救你的。它提供了 29 种自包含的 HTML + SVG 图表设计，主打一个“无阴影、无 Mermaid 垃圾”。你可以直接把这些设计喂给 Claude Code，让它生成专业、清爽、可以直接放进发布会 PPT 的图表。对于被 AI 默认图表丑哭的开发者来说，这简直是救命的良药。
🔗 项目网址: https://github.com/cathrynlavery/diagram-design
✨ Star 数量: 17,248
⭐ 推荐指数: ★★★★☆（实用性强，但受众偏前端和 AI 重度用户）

cactus-compute/needle

🎯 一句话概括: 只有 14MB 的微型 AI 模型，手机、手表、智能家居都能跑。
💡 详细介绍: 大模型虽好，但动辄几个 GB 的体积让移动设备望而却步。Needle 这个项目就主打一个“小而美”，它把基础模型压缩到了 14MB，专门为手机、可穿戴设备、智能家居甚至机器人设计。这意味着你的智能门铃终于可以本地运行 AI 识别，而不需要把数据传到云端了。虽然能力比不上 GPT-4，但胜在轻巧、离线、隐私安全，是边缘计算的一把好手。
🔗 项目网址: https://github.com/cactus-compute/needle
✨ Star 数量: 5,605
⭐ 推荐指数: ★★★★☆（潜力巨大，适合 IoT 和嵌入式开发者）

megadose/holehe

🎯 一句话概括: 检查你的邮箱注册过哪些网站，一秒钟暴露你的“网络足迹”。
💡 详细介绍: 想知道你的邮箱被拿去注册了多少个“学习资料”网站？Holehe 就是你的“互联网考古”工具。它利用各大网站的“忘记密码”功能，通过分析响应状态来判断该邮箱是否注册过 Twitter、Instagram 等平台。对于做安全审计、或者想清理自己网络账号的人来说，这工具既高效又有点“社死”风险——建议在夜深人静时使用。
🔗 项目网址: https://github.com/megadose/holehe
✨ Star 数量: 12,849
⭐ 推荐指数: ★★★★★（渗透测试必备，简单粗暴有效）

macro-inc/macro

🎯 一句话概括: 一个把邮件、聊天、文档、任务、CRM 全部串起来的团队“全家桶”工作台。
💡 详细介绍: Macro 试图干掉你电脑上所有乱七八糟的协作软件。它把邮件、IM、文档、任务管理、甚至 AI Agent 和电话会议全部整合到一个工作区，并且用“@”符号将它们智能关联。更狠的是，它内置了共享 AI 记忆，意味着 AI 能记住你所有的项目上下文。如果你受够了在 Slack、Outlook、Notion 之间来回切换，这个用 Rust 写的高性能工作台值得一试。
🔗 项目网址: https://github.com/macro-inc/macro
✨ Star 数量: 3,034
⭐ 推荐指数: ★★★☆☆（理念很棒，但团队协作软件迁移成本高，观望为主）

smicallef/spiderfoot

🎯 一句话概括: 自动化 OSINT 侦察工具，帮你把攻击面摸得一清二楚。
💡 详细介绍: SpiderFoot 是一个老牌的开源情报（OSINT）自动化工具。它就像一个不知疲倦的“网络侦探”，能自动从数百个公开数据源收集信息，帮你绘制出目标（比如你的公司域名）的攻击面地图。无论是做渗透测试的前期踩点，还是安全团队做威胁情报分析，它都是效率神器。别拿它干坏事，除非你想和警察叔叔喝茶。
🔗 项目网址: https://github.com/smicallef/spiderfoot
✨ Star 数量: 20,946
⭐ 推荐指数: ★★★★★（安全从业者必备，功能强大且社区活跃）

citrolabs/ego-lite

🎯 一句话概括: 给 AI Agent 用的“隐身浏览器”，共享登录状态不打扰你。
💡 详细介绍: 让 AI 帮你操作浏览器最烦的是什么？是它老要登录、验证、甚至打断你干活。Ego-Lite 就是为 AI Agent 专门打造的浏览器，它可以把你的登录状态无缝共享给 Codex 或 Claude Code 这类 Agent，让 AI 在你“不被打扰”的情况下自动完成任务。零成本、零配置，对于想体验“全自动办公”的懒人来说，这简直是福音。
🔗 项目网址: https://github.com/citrolabs/ego-lite
✨ Star 数量: 10,366
⭐ 推荐指数: ★★★★☆（AI 自动化神器，但依赖 AI Agent 生态）

holaboss-ai/holaOS

🎯 一句话概括: 开源的“AI Agent 操作系统”，让 Claude Code 和 Codex 在你电脑上“同居”。
💡 详细介绍: HolaOS 不是一个操作系统，而是一个 AI Agent 的“工作空间”。它允许你同时运行 Claude Code、Codex 等多个 AI Agent，并让它们共享文件、浏览器和 100+ 工具集成。最厉害的是它有共享记忆，多个 Agent 可以协同工作。如果你觉得单个 AI 不够用，想搞一个“AI 团队”帮你写代码，这个项目值得研究。
🔗 项目网址: https://github.com/holaboss-ai/holaOS
✨ Star 数量: 7,290
⭐ 推荐指数: ★★★★☆（概念新颖，适合极客和 AI 重度玩家）

github/spec-kit

🎯 一句话概括: GitHub 官方出品的“规范驱动开发”工具包。
💡 详细介绍: 重磅！GitHub 官方亲自下场教你怎么写代码了。Spec-Kit 是一个帮助你从“需求文档”直接生成代码的工具包，也就是所谓的“Spec-Driven Development”。它的核心理念是先写规格说明，再让 AI 或开发者照着实现，从而减少沟通成本和返工率。虽然 128K Stars 有点吓人（可能是官方仓库的初始热度），但仓库本身还处于早期阶段，不过既然是官方出品，未来可期。
🔗 项目网址: https://github.com/github/spec-kit
✨ Star 数量: 128,517
⭐ 推荐指数: ★★★★★（官方背书，可能改变未来开发流程，必须关注）

lightningpixel/modly

🎯 一句话概括: 本地 AI 生成 3D 模型，全靠你的显卡吃饭。
💡 详细介绍: 想玩 3D 建模但不会 Blender？Modly 这款桌面应用让你用一句话或一张图片就能生成 3D 模型，而且完全在本地 GPU 上运行，不用花一分钱 API 费用。虽然生成精度和专业的建模软件还有差距，但对于游戏素材、概念设计或者 3D 打印爱好者来说，这已经足够惊艳了。
🔗 项目网址: https://github.com/lightningpixel/modly
✨ Star 数量: 5,939
⭐ 推荐指数: ★★★☆☆（有趣但实用性待提升，适合尝鲜玩家）

infiniflow/ragflow

🎯 一句话概括: 让大模型“开卷考试”的开源 RAG 引擎，知识库问答神器。
💡 详细介绍: RAGFlow 是一个顶级的开源 RAG（检索增强生成）引擎。简单说，它解决了大模型“一本正经胡说八道”的问题。你可以把公司文档、个人笔记丢给它，它会在回答问题前先从你的资料库中检索相关证据，然后生成有依据的回答。对于想要搭建私有知识库、企业智能客服的人来说，这是目前最成熟、最强大的开源方案之一。
🔗 项目网址: https://github.com/infiniflow/ragflow
✨ Star 数量: 88,382
⭐ 推荐指数: ★★★★★（RAG 领域的明星项目，实用性和热度都拉满）

小编的话：今天的榜单里，GitHub 官方那个 128K Star 的 Spec-Kit 属实有点“不讲武德”，但 RAGFlow 和 SpiderFoot 绝对是值得长期关注的硬核项目。各位看官，有看上的就赶紧去 Star 一波，毕竟收藏了就等于学会了。我们明天见！
