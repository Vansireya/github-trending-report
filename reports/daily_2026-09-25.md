### vectorize-io/hindsight

**一句话概括**：给 AI Agent 装上一个会「吃一堑长一智」的记忆系统。

**详细介绍**：现在的 Agent 有个通病——金鱼记忆，上一轮对话刚说完的事，下一轮就忘得一干二净。Hindsight 就是来治这个病的，它的核心理念是「Agent Memory That Learns」，不只是简单地把历史对话塞进向量库，而是让记忆能够被学习、被优化。简单说，就是让你的 Agent 从「每次都要重新自我介绍」进化到「老熟人，上次那事儿咱接着聊」。做 RAG 和 Agent 的同学，这个值得蹲一下。

**项目网址**：https://github.com/vectorize-io/hindsight

**Star 数量**：27,870

**推荐指数**：⭐⭐⭐⭐


### dream-num/univer

**一句话概括**：把表格、文档、幻灯片、画布、关系表和 PDF 全塞进一个运行时，专门伺候 AI Agent 的「Office 全家桶」。

**详细介绍**：AI Agent 想帮你干活，结果发现办公软件一个个都是封闭王国，API 难用得想砸键盘。Univer 的思路是：干脆自己造一个统一的 Office 运行时，让 Agent 能像人类一样操作表格、文档、PPT。它的定位是「The Office Harness for AI Agents」，野心不小。TypeScript 写的，前端同学上手无压力。如果你在琢磨怎么让 AI 帮你自动填表、自动写周报（然后被老板发现），这个项目值得研究。

**项目网址**：https://github.com/dream-num/univer

### FxEmbed/FxEmbed

**一句话概括**：修复 X/Twitter 和 Bluesky 的嵌入显示，让 Discord 和 Telegram 里的推文不再是一坨链接。

**详细介绍**：你在 Discord 或 Telegram 里贴一条推文链接，结果只显示一个干巴巴的 URL，图片没有、视频没有、投票没有、翻译也没有——是不是很想砸手机？FxEmbed 就是来解决这个世纪难题的。它能让嵌入的推文支持多图、视频、投票、翻译等等，把「链接」变成「内容」。5千多星看着不多，但每一个星背后都是一个被链接逼疯的社群运营。实用主义者的胜利。
