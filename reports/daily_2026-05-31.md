# 今日 GitHub 狠活：微软官方「文档转 Markdown」神器，还有AI一键生成短视频！

各位打工人、技术宅、摸鱼党，今天 GitHub 又整了一堆新活。从微软官方的摸鱼工具到AI帮你拍短视频，从能跟你聊代码的终端AI到离线生存电脑，个个都是狠角色。废话不多说，直接上干货。

### microsoft/markitdown

- **一句话概括**：微软官方出品的「万物转 Markdown」工具，专治各种格式不兼容。
- **详细介绍**：你是不是经常遇到这种破事：客户发来一个 Word 文档，你只想提取里面的文字；或者有个 PDF 表格，你想复制到笔记里，结果格式乱成一锅粥。MarkItDown 就是来拯救你的。它能把 Office 文档（Word、Excel、PPT）、PDF、HTML、图片（OCR 识别文字）等乱七八糟的格式，统统转换成干净整洁的 Markdown。对于写技术文档、做笔记、整理资料的人来说，这简直是生产力外挂——再也不用手动复制粘贴然后排版了。而且它是微软官方维护的，质量有保障，不用担心过两天就没人管了。
- **项目网址**：https://github.com/microsoft/markitdown
- **Star 数量**：132,567
- **推荐指数**：★★★★★（五星！微软官方出品，解决真实痛点，Star 数说明一切）

### harry0703/MoneyPrinterTurbo

- **详细介绍**：你是不是被短视频平台上的各种「AI 自动生成视频」的广告洗脑了？这个项目就是干这个的。你只需要输入一个主题或一段文案，它就能调用 AI 大模型自动生成高清短视频，连配音、字幕、背景音乐都帮你搞定。对于想做短视频营销、自媒体但不会剪辑的人来说，这就是作弊器。不过别指望它能直接帮你赚大钱——它只是帮你省了剪辑的时间，内容质量还得靠你的创意。但至少，你不再需要对着剪辑软件发呆了。
- **项目网址**：https://github.com/harry0703/MoneyPrinterTurbo
- **Star 数量**：72,102
- **推荐指数**：★★★★☆（四星，实用但别太当真，钱没那么好赚）

### anthropics/claude-code

- **一句话概括**：Anthropic 官方出的终端AI编程助手，能跟你唠代码。
- **详细介绍**：Claude Code 不是一个普通的代码补全工具，它是一个住在你终端里的 AI 代理。你可以在命令行里用自然语言跟它聊天，让它帮你写代码、解释复杂逻辑、处理 Git 工作流（比如自动 commit、merge）。它还能理解整个代码库，而不是只盯着你当前打开的文件。对于那些懒得记 Git 命令、或者被屎山代码折磨到崩溃的程序员来说，这玩意能救命。不过它目前还比较吃资源，而且你得习惯在终端里跟AI对话——这感觉有点像在跟一个不会抱怨的同事聊天。
- **项目网址**：https://github.com/anthropics/claude-code
- **Star 数量**：128,429
- **推荐指数**：★★★★★（五星，AI编程的又一里程碑，但别指望它帮你写完所有代码）
