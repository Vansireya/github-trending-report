今日 GitHub 狠活：AI 求职、交易机器人、还有你的第二大脑

各位打工人、技术宅、以及那些半夜还在刷 GitHub 的夜猫子们，早上好！今天的热榜又是一场 AI 的狂欢，从帮你写情书（划掉）写求职信的，到帮你炒股的，再到帮你把 Obsidian 变成赛博脑子的，应有尽有。废话不多说，直接上硬菜！

freestylefly/awesome-gpt-image-2

🎯 一句话概括: GPT-Image2 的“作弊码”大全，让你从提示词菜鸟秒变工业级调教师。
💡 详细介绍: 还在为 AI 画图提示词写得像小学生作文而苦恼？这个项目就是你的救星。它不仅仅是一个模板库，更像是一个“逆向工程”实验室，把 530+ 个成功案例拆解给你看，总结出 20+ 套可以直接套用的工业级模板。最骚的是，它还提炼出了“Skills”，让你能把提示词当成代码来写，实现“Prompt as Code”。这玩意儿简直是甲方乙方沟通的润滑剂，也是你朋友圈装逼的利器。
🔗 项目网址: https://github.com/freestylefly/awesome-gpt-image-2
✨ Star 数量: 17,781
⭐ 推荐指数: ★★★★☆（很实用，但更新太快，怕你学不过来）

anthropics/claude-plugins-community

🎯 一句话概括: Claude 官方钦定的“插件应用商店”，不过是社区驱动的。
💡 详细介绍: Claude Code 和 Claude Cowork 现在也有自己的“App Store”了，只不过这个商店是开源的、由社区维护的。如果你觉得 Claude 还不够顺手，想给它加个“外挂”，来这里就对了。这个仓库本身只是个“只读镜像”，真正的提交入口在别处，所以别在这儿提 PR，会被管理员无情关闭的。总之，这是让 Claude 变得更强的必经之路。
🔗 项目网址: https://github.com/anthropics/claude-plugins-community
✨ Star 数量: 1,748
⭐ 推荐指数: ★★★☆☆（官方出品，但生态还在早期，先观望）

MadsLorentzen/ai-job-search

🎯 一句话概括: 把找工作这事儿彻底“外包”给 AI 的终极框架。
💡 详细介绍: 你是不是海投简历投到手抽筋，结果面试通知寥寥无几？这个项目就是你的“求职外挂”。它基于 Claude Code，能自动帮你评估招聘启事、量身定制简历、写求职信，甚至还能帮你模拟面试。最棒的是，它完全跑在你的本地机器上，数据隐私有保障。Fork 一份，你就能拥有一个 24 小时不睡觉的私人求职助理。这哪是找工作，这是让 AI 替你打工啊！
🔗 项目网址: https://github.com/MadsLorentzen/ai-job-search
✨ Star 数量: 35,275
⭐ 推荐指数: ★★★★★（求职刚需，效果拔群，五星好评）

apache/maka

🎯 一句话概括: 一个“本地优先”的 AI 智能体工作台，主打一个“留痕”。
💡 详细介绍: Apache 孵化器的新项目，听名字就很有“马卡”的感觉（不是马卡龙）。它是个 AI Agent 的工作空间，但最特别的地方在于，它把模型消息、工具调用、结果、权限决策等所有事件都记录成一个“只追加”的日志。这意味着什么？意味着 AI 的一举一动都有迹可循，出了锅好甩，有了功好赏。对于需要严格审计和调试的企业级应用来说，这简直是救命的稻草。本地优先，数据安全，值得关注。
🔗 项目网址: https://github.com/apache/maka
✨ Star 数量: 3,333
⭐ 推荐指数: ★★★★☆（Apache 背书，架构先进，但还在孵化期）

TauricResearch/TradingAgents

🎯 一句话概括: 让一群 LLM 扮演华尔街之狼，帮你炒股。
💡 详细介绍: 这个项目直接给你组了一个“AI 交易天团”，里面有不同的 Agent 各司其职，有的负责分析基本面，有的负责技术面，还有的负责风险管理。它们会像真人交易员一样互相讨论、辩论，最后得出交易决策。虽然不能保证你稳赚不赔，但至少比你自己瞎操作要理性得多。100K 的 Star 数说明了一切——大家都想躺着赚钱，哪怕只是看个热闹。风险提示：投资有风险，AI 也可能被割韭菜。
🔗 项目网址: https://github.com/TauricResearch/TradingAgents
✨ Star 数量: 100,247
⭐ 推荐指数: ★★★★☆（想法很酷，用途很猛，但别把棺材本押上去）

AgriciDaniel/claude-obsidian

🎯 一句话概括: 给你的 Obsidian 装上 AI 大脑，让它自己整理笔记。
💡 详细介绍: 受 Karpathy 的 LLM Wiki 模式启发，这个项目能让 Claude Code 自动阅读你扔进 Obsidian 里的任何资料，然后自动建立链接、归类，最终形成一个你专属的 Markdown 知识图谱。这简直就是“外挂大脑”的雏形。你只需要负责“喂”资料，它负责“消化”和“整理”。对于知识管理爱好者来说，这玩意儿比 Notion AI 香多了，而且完全开源，数据掌握在自己手里。
🔗 项目网址: https://github.com/AgriciDaniel/claude-obsidian
✨ Star 数量: 12,716
⭐ 推荐指数: ★★★★★（PKM 神器，理念超前，强烈推荐）

rohitg00/ai-engineering-from-scratch

🎯 一句话概括: 从零开始手搓 AI 工程，一本通往“AI 工程师”的免费攻略。
💡 详细介绍: 这标题翻译过来就是“从入门到精通”。它不是一个具体的应用，而是一套系统的学习路径和项目集合。如果你想转行做 AI 工程，但又不知道从何下手，这个仓库就是你的地图。它教你“学它、造它、然后发布它”，完全是实战派风格。Star 数接近 5 万，说明想“从零开始”的人真的很多。

tinyhumansai/openhuman

🎯 一句话概括: 一个用 Rust 写的“个人 AI 超级智能”，试图记录你的一生。
💡 详细介绍: 这个项目野心不小，它想成为你的“第二大脑”，但比 Obsidian 那个更激进。它不仅仅管理笔记，而是构建一个关于你生活的“本地优先”记忆库，并且能指挥一群 Agent 替你干活。你可以把它想象成一个超级私人的 Siri，但比 Siri 聪明得多，而且完全由你掌控。用 Rust 写的，性能应该很顶。不过，“记录你的一生”听起来有点赛博朋克，隐私问题得想清楚。
🔗 项目网址: https://github.com/tinyhumansai/openhuman
✨ Star 数量: 37,773
⭐ 推荐指数: ★★★★☆（概念很炸裂，但“一生”太长，先看看再说）

basecamp/omarchy

🎯 一句话概括: Basecamp 出品的“高颜值、现代化、有主见”的 Linux 发行版。
💡 详细介绍: Basecamp 这家公司不好好做项目管理，跑来搞 Linux 发行版了。但这个 Omarchy 确实有点东西，它主打“开箱即用”和“美学”，默认配置就很漂亮，而且内置了很多现代化的开发工具。它很“有主见”，意味着它替你做了很多决定，你不需要折腾那些繁琐的配置。适合那些不想折腾 Arch 但又想体验现代化 Linux 的开发者。不过，对于 Linux 老炮儿来说，可能会觉得它“太霸道”了。
🔗 项目网址: https://github.com/basecamp/omarchy
✨ Star 数量: 31,267
