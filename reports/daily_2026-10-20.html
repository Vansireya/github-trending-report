AI 打工天团出道，你的简历和记忆都有人管了

今天的榜单堪称“AI 代理一条龙服务”：从帮你找工作、帮你写代码、帮你记住上下文，到帮你压缩 token 省钱，甚至连视频修复都给你安排上了。

1
ai-job-search ★ 57,609
Python

一个跑在你本机上的 AI 求职框架，帮你评估岗位、改简历、写求职信、准备面试，一条龙服务。

找工作这件事，痛点从来不是“没岗位”，而是“岗位太多懒得筛、简历改到怀疑人生、求职信写得像 AI 生成”——好吧现在真的是 AI 生成。这个项目基于 Claude Code 构建，核心思路是：把求职流程拆成可自动化的环节，让 AI 帮你干脏活累活。评估 JD 匹配度、按岗位定制 CV、生成求职信、模拟面试，全在你自己的机器上跑，数据不出门。最骚的是它鼓励你 fork 走自己改——毕竟求职这事儿，千人千面，别人的模板救不了你。

2
opencode ★ 217,920
TypeScript

开源版 coding agent，让 AI 帮你写代码，还不用被某家厂商绑死。

榜单第二，Star 数直接飙到 21 万+，这体量已经不是“项目”了，是“现象”。痛点很明确：闭源 coding agent 好用归好用，但你的代码、你的上下文、你的工作流全在别人服务器上，心里总有点发毛。opencode 主打开源、可自托管，TypeScript 技术栈，想接哪个模型接哪个模型。对于既要 AI 提效、又要数据主权的团队来说，这就是那个“既要又要”的答案。

3
ai-memory ★ 11,435
Rust

给 coding agent 装一个“长期记忆”，顺便解决换厂商就失忆的尴尬。

用 AI 写代码的人都懂那种痛：聊了半小时，agent 终于搞懂了你的项目结构，结果一关窗口，下次开新会话——它又失忆了，你又得从头解释一遍。更别提换个厂商的 agent，之前的上下文全白搭。这个 Rust 写的项目就是干这个的：给 agent CLI 提供长期记忆层，并且支持在不同 agent 厂商之间做 handoff。翻译成人话：让 AI 记住你，且不挑对象。Rust 的性能底子也让它在响应速度上不至于拖后腿。

4
ComfyUI ★ 139,843
Python

节点式扩散模型 GUI，本地跑图的最强 modular 引擎，没有之一。

这玩意儿在 AI 绘画圈的地位，大概相当于“你不一定用过，但你一定见过别人用”。基于节点/图的工作流界面，把 diffusion 模型的每一步拆成可拖拽的模块，想怎么拼怎么拼。痛点？痛点就是那些“一键出图”的工具永远满足不了想精细控制的人——换采样器、调 CFG、接 ControlNet、串 LoRA，ComfyUI 全给你。号称“世界最快本地推理引擎”，13 万+ 星也证明了群众的眼睛是雪亮的。

5
ruflo ★ 77,271
TypeScript

老牌 agent harness，部署多智能体 swarm、编排自主工作流、搭对话式 AI 系统。

名字带个 🌊，野心也像海一样大。号称“original agent harness”，功能列表长到像简历：自适应记忆、自学习智能、联邦、向量 RAG 集成，还原生集成 Claude Code / Codex / Hermes 等一堆。说白了，它想当的是“AI 代理的操作系统”——你有一堆 agent 要协同干活？交给我编排。痛点在于多 agent 系统的编排复杂度，普通开发者自己搭一套能累到脱发。7.7 万星说明这套“代理方阵”的思路确实戳中了不少人。

6
orca ★ 98,416
TypeScript

管理一整支 coding agent 舰队的平台，用自己的订阅跑任意 agent，桌面/移动/远程通吃。

现在谁还没几个 agent？Claude Code 一个、Grok Bot 一个、可能还有别的。问题来了：散落在各处，怎么统一调度？orca 的答案是——把它们编成舰队。你可以用自己的订阅跑任意 coding agent，桌面端、移动端、远程 runtime 都能接。痛点就是“agent 多了管不过来”，尤其对同时用多家 agent 的团队。9.8 万星，说明“舰队司令”这个角色，很多人都想当。

7
headroom ★ 76,296
Python

在内容喂给 LLM 之前先压缩，coding agent 省 20% token，JSON 省 60-95%，答案还不变。

这个项目属于“闷声省钱型”。痛点极其现实：token 就是钱，tool 输出、日志、文件、RAG chunk 一股脑塞给 LLM，账单蹭蹭涨，其中一大半是废话。headroom 的思路是在内容到达 LLM 之前先压缩——coding agent 场景省 20% token，JSON 场景省 60-95%，关键是“same answers”，答案质量不打折。提供 library、proxy、MCP server 三种形态，接入方式灵活。7.6 万星，说明被账单教育过的人真不少。

JavaScript

没有简介，但 6 千多星说明它肯定有点东西——看名字像操作系统/分类学相关的工具库。

jasna ★ 2,959

视频修复工具，把糊成马赛克的老视频往清晰了拉。
