# AI 编码代理开始补课：规范、安全与技能包

今天榜单被 AI 编码代理的配套工程占据：Google Chrome 联合多家浏览器团队推出 Modern Web Guidance，试图把代理从旧代码习惯里拽出来；OpenAI 的 codex-security 则把漏洞扫描、验证和修复串成一条工作流。两个项目指向同一个问题——代理写代码很快，但需要有人教它写对的代码。


### GoogleChrome/modern-web-guidance-src

**一句话概括**：把现代 Web 平台的最佳实践和兼容性数据打包成代理技能，让编码助手少写旧式 JavaScript。

**详细介绍**：LLM 训练数据里堆满遗留代码，代理容易默认生成臃肿的旧方案。这个项目由 Chrome、Edge、Firefox 和 MDN 团队共同维护，提供安装向导和评估面板，但当前只是源仓库，实际效果取决于代理是否接入这些技能。

**项目网址**：https://github.com/GoogleChrome/modern-web-guidance-src

**Star 数量**：3,381


### openai/codex-security

**一句话概括**：OpenAI 的安全 CLI 和 TypeScript SDK，能扫描仓库、验证漏洞、生成补丁并跟踪修复。

**详细介绍**：适合在终端或 CI 里跑安全扫描，也支持导入第三方扫描器结果、导出 SARIF/JSON/CSV。深度扫描会重复标准扫描并去重，但漏洞验证和补丁质量仍依赖模型判断，不能替代人工审计。

**项目网址**：https://github.com/openai/codex-security

**Star 数量**：12,576


### nvm-sh/nvm

**一句话概括**：老牌 Node 版本管理器，用 POSIX bash 脚本切换多个 Node.js 版本，近十万星。

**详细介绍**：在需要频繁切换 Node 版本的项目里几乎是标配，支持 .nvmrc 自动切换、LTS 别名和离线安装。局限是只覆盖 POSIX shell，Windows 原生环境得另找方案。

**项目网址**：https://github.com/nvm-sh/nvm

**Star 数量**：96,042


### pookjw/HermesEnabler

**一句话概括**：让任意 Apple Watch 用上爱马仕表盘，通过侧载 IPA 实现，仅支持 watchOS 27.0 到 27.3 beta 1。

**详细介绍**：需要配对的 iPhone、开发者模式和对证书的信任，Sideloadly 0.72 还有签名时丢掉手表应用的已知问题。版本窗口极窄，升级 watchOS 就可能失效，属于尝鲜型工具。

**项目网址**：https://github.com/pookjw/HermesEnabler

**Star 数量**：1,605


### we-promise/sure

**一句话概括**：Maybe Finance 被放弃后的社区分叉，一个可自托管的个人财务应用，Ruby 编写。

**详细介绍**：原团队烧掉近百万美元后开源，社区接手维护。适合想自己掌控财务数据的人，但自托管意味着数据库、备份和升级都得自己管，不是开箱即用的 SaaS。

**项目网址**：https://github.com/we-promise/sure

**Star 数量**：14,074


### QwenLM/qwen-code

**一句话概括**：Qwen 推出的开源终端编码代理，带 Auto-Memory、SubAgents 和 MCP，支持多协议切换。

**详细介绍**：可以在终端、IDE、桌面和聊天工具里跑，模型和框架都开源，能接 OpenAI、Anthropic、Gemini 或本地 Ollama。1.0 Preview 刚把 Qoder 的代理能力并进来，迭代快也意味着接口可能不稳。

**项目网址**：https://github.com/QwenLM/qwen-code

**Star 数量**：29,918


### ashhart/TensorFold

**一句话概括**：用 Zig 写的 LLM 推理引擎，直接在 Apple Silicon 和 NVIDIA GPU 上跑 Metal 或 CUDA 内核。

**详细介绍**：卖点是不用装 Python 或 MLX，一个二进制读 checkpoint、分词并推理。但项目还很早期，贡献流程里甚至要求先用 Agent Traffic Control 认领任务，生态和文档都待成熟。

**项目网址**：https://github.com/ashhart/TensorFold

**Star 数量**：1,992


### nodejs/node

**一句话概括**：Node.js 官方运行时仓库，跨平台 JavaScript 环境，十二万星的老面孔。

**详细介绍**：榜单常客，本身不需要多介绍。值得留意的是它采用开放治理和语义化版本，Alpha 线每年十月开新分支，生产环境应盯 LTS 而非 Current。

**项目网址**：https://github.com/nodejs/node

**Star 数量**：123,627


### addyosmani/agent-skills

**一句话概括**：把资深工程师的工作流和质量门禁打包成代理技能，配 9 个斜杠命令覆盖开发全周期。

**详细介绍**：从 /spec 到 /ship，每个命令激活对应技能，让代理按“先规格后代码”“小步构建”的节奏走。适合 Claude Code、Cursor 等工具，但技能本身是提示词工程，效果取决于代理是否老实执行。

**项目网址**：https://github.com/addyosmani/agent-skills

**Star 数量**：116,783


### meta/astryx

**一句话概括**：Meta 内部用了八年的设计系统开源，150+ 无障碍组件，基于 React 19 和 StyleX，主打代理可用。

**详细介绍**：组件内部开放、支持 swizzle 弹出源码，不绑定样式库。目前 Beta，文档和 Storybook 齐全，但“agent ready”更多是设计取向，实际代理生成质量还得看接入方式。

**项目网址**：https://github.com/meta/astryx

**Star 数量**：26,764


**今日总结**：今天最值得看的是代理工程的基础设施化：浏览器厂商和 OpenAI 都在给代理立规矩、补安全课。工具越自动，越需要有人把质量门禁写进流程里。
