# 今日 GitHub 狠活：从赛博老婆到隔墙识人，AI 已经玩疯了

各位技术宅、赛博朋克和“我只是路过”的朋友们，大家好！又到了每日 GitHub 热门项目“开盲盒”时间。今天的榜单可谓是“群魔乱舞”，有想给你造个老婆的，有想用 WiFi 把你“看光”的，还有想把你的工作文档一键“扒光”的。话不多说，让我们看看今天又有哪些神仙（或神经）项目在 GitHub 上兴风作浪。

### moeru-ai/airi
*   **一句话概括**：一个能自托管、能陪你语音聊天、甚至能帮你打《我的世界》和《异星工厂》的“赛博老婆/老公”容器。
*   **详细介绍**：这项目主打一个“赛博生命体养成”。开发者估计是《神经源》的粉丝，想造出类似水平的 AI 伴侣。它不只是一个聊天机器人，而是号称能承载“灵魂”，支持实时语音，还能接入游戏进行交互。说白了，就是给你一个完全由你掌控、不会闹脾气、还能陪你打游戏的虚拟伙伴。痛点？解决现代人的孤独感算吗？（或者只是把宅男宅女们往更深的二次元里推了一把？）
*   **项目网址**：https://github.com/moeru-ai/airi
*   **Star 数量**：20,276
*   **推荐指数**：⭐⭐⭐⭐（给技术宅和孤独患者们一个五星级的家，扣一星是怕你沉迷）

### ruvnet/wifi-densepose
*   **一句话概括**：用普通的 WiFi 信号，实现实时人体姿态估计、生命体征监测和存在检测，无需摄像头。
*   **详细介绍**：这玩意儿有点“黑科技”内味儿了。想象一下，你家的 WiFi 路由器不仅能上网，还能“看”到你在房间里是站着、坐着还是做广播体操，甚至能监测你的呼吸心跳。它利用 WiFi 信号在人体上的反射和扰动来分析，完美解决了隐私敏感场景下的监控需求（比如浴室、卧室），或者单纯就是不想装摄像头的地方。以后在家裸奔可能也得注意下路由器的“目光”了。
*   **项目网址**：https://github.com/ruvnet/wifi-densepose
*   **Star 数量**：17,594
*   **推荐指数**：⭐⭐⭐⭐⭐（技术酷炫，应用场景明确，隐私与监控的边界探索者）

### ruvnet/ruflo
*   **一句话概括**：专为 Claude AI 设计的“首席调度官”，一个企业级的多智能体协同作战平台。
*   **详细介绍**：如果说单个 AI 模型是一个超级士兵，那 Ruflo 就是指挥一整支特种部队的司令部。它允许你部署和管理一群 Claude 智能体，让它们各司其职（有的查资料，有的写代码，有的做决策），协同完成复杂任务。特点是架构扎实，支持分布式“蜂群”智能，还能无缝接入知识库和各种工具。痛点在于，当你的任务复杂到需要“开会讨论”时，它就是那个不会扯皮的完美项目经理。
*   **项目网址**：https://github.com/ruvnet/ruflo
*   **Star 数量**：17,321
*   **推荐指数**：⭐⭐⭐⭐（面向企业级和复杂工作流，普通用户可能用牛刀杀鸡，但潜力巨大）

### microsoft/markitdown
*   **一句话概括**：微软出品的“文档格式化清除器”，能把各种 Office 文档和文件一键转换成干净的 Markdown。
*   **详细介绍**：打工人和内容创作者的福音！你是否受够了从 Word、PPT、Excel 甚至 PDF 里复制粘贴出来那堆乱七八糟的格式？Markitdown 就是来干这个脏活累活的。它由微软官方开发，专门把那些“富文本”扒得只剩最核心的 Markdown 骨架，让你能轻松地把内容迁移到博客、笔记软件或任何支持 Markdown 的地方。简单、粗暴、实用。
*   **项目网址**：https://github.com/microsoft/markitdown
*   **Star 数量**：88,997
*   **推荐指数**：⭐⭐⭐⭐⭐（微软难得做件接地气的好工具，解决的是世界级格式烦恼）

### bytedance/deer-flow
*   **一句话概括**：字节跳动的开源“超级打工人”智能体框架，能搞研究、写代码、搞创作。
*   **详细介绍**：又一个来自大厂的“智能体全家桶”。Deer-Flow 给 AI 配备了沙箱环境、记忆模块、各种工具技能，还能调用子智能体，目标是处理那些需要几分钟到几小时的复杂任务。你可以把它理解为一个高度定制化和自动化的 AI 助手流水线。字节在 AI 应用层真是疯狂输出，这个框架就是想让开发者能快速搭建出能干“长线活”的 AI 员工。
*   **项目网址**：https://github.com/bytedance/deer-flow
*   **Star 数量**：22,974
*   **推荐指数**：⭐⭐⭐⭐（大厂背书，功能全面，适合需要构建复杂 AI 应用的开发者）

### alibaba/OpenSandbox
*   **一句话概括**：阿里出品的 AI 应用“万能沙盒”，为各种 AI 智能体提供一个安全统一的运行和测试环境。
*   **详细介绍**：AI 智能体要干活，比如执行代码、操作 GUI、进行强化学习，总不能直接在真机环境里瞎搞吧？OpenSandbox 就是给它们准备的专用“游乐场”兼“测试基地”。它提供多语言 SDK 和统一的 API，背后用 Docker/K8s 做支撑，确保 AI 的行为被隔离、可控、可评估。无论是开发 Coding Agent 还是训练 AI，都需要这么个安全屋。
*   **项目网址**：https://github.com/alibaba/OpenSandbox
*   **Star 数量**：3,372
*   **推荐指数**：⭐⭐⭐⭐（基础设施型项目，虽不炫酷但至关重要，开发者刚需）

### Shubhamsaboo/awesome-llm-apps
*   **一句话概括**：一个汇集了各种基于大语言模型（LLM）的炫酷应用、AI 智能体和 RAG 项目的“Awesome”清单。
*   **详细介绍**：如果你觉得上面一个个项目看花了眼，想直接找个“自助餐厅”，那么这个仓库就是你的天堂。它整理了海量使用 OpenAI、Anthropic、Gemini 及开源模型的 AI 应用实例，涵盖智能体、检索增强生成等各种玩法。灵感枯竭时来逛逛，或者想快速找到某个方向的实现参考，这里绝对是宝藏。痛点？解决你的“AI 项目选择困难症”和“不知道现在流行啥”的焦虑。
*   **项目网址**：https://github.com/Shubhamsaboo/awesome-llm-apps
*   **Star 数量**：98,706
*   **推荐指数**：⭐⭐⭐⭐⭐（常看常新的资源大全，AI 领域的“大众点评”，必收藏）

### K-Dense-AI/claude-scientific-skills
*   **一句话概括**：一套为 Claude 智能体准备的“专业技能包”，专攻科研、工程、金融分析和写作等领域。
*   **详细介绍**：光有一个聪明的 Claude 大脑还不够，你得给它装备上专业的“技能芯片”。这个项目提供了一系列开箱即用的技能模块，让你的 Claude 智能体瞬间变身某个领域的专家。比如，它可以帮你分析数据、撰写学术论文、进行金融建模等。相当于给通用 AI 装上了专业的工具箱，让它从“通才”变成“专才”。
*   **项目网址**：https://github.com/K-Dense-AI/claude-scientific-skills
*   **Star 数量**：10,302
*   **推荐指数**：⭐⭐⭐⭐（垂直领域实用工具集，科研党和分析师们的效率外挂）

### basecamp/omarchy
*   **一句话概括**：Basecamp 公司打造的“美丽、现代且固执己见”的 Linux 发行版。
*   **详细介绍**：“固执己见”是精髓。这可不是另一个让你从零开始折腾的 Linux 发行版，而是一个带着强烈审美和预设配置的“成品”。Basecamp 觉得市面上很多 Linux 不够好看或不够好用，就自己动手做了一个他们认为理想的版本。适合那些认同其设计哲学、不想在系统配置上花费太多时间，但又想要一个漂亮、高效工作环境的用户。痛点？治疗 Linux 用户的“桌面美化综合征”和“配置选择恐惧症”。
*   **项目网址**：https://github.com/basecamp/omarchy
*   **Star 数量**：20,742
*   **推荐指数**：⭐⭐⭐（小众精品，爱者甚爱，恨者可能觉得不够自由）

### X-PLUG/MobileAgent
*   **一句话概括**：一个强大的“手机 GUI 智能体”家族，能让 AI 自动操作手机 App。
*   **详细介绍**：让 AI 帮你点外卖、刷短视频、回消息？MobileAgent 就是干这个的。它专注于理解和操作手机图形界面（GUI），让 AI
