# Agent 技能包与工具链集体上桌

今天榜单几乎被 Agent 技能生态包场：从漏洞挖掘、开发方法论到图表生成，都在把 Claude Code 这类编码代理改造成有章法的专业工具。其中 Claude-BugHunter 把 681 份公开漏洞报告整理成可调用的技能，superpowers 则试图给代理立一套完整的软件开发规矩，两者都值得先看。


### elementalsouls/Claude-BugHunter

**一句话概括**：给 Claude Code 装的漏洞挖掘技能包，84 个技能、15 个斜杠命令，外加 681 份公开报告的模式库。

**详细介绍**：它把方法论、Web 应用狩猎、企业身份与基础设施攻击矩阵分层打包，并接入 Burp MCP，让代理在授权测试中按阶段推进而不是乱撞。局限在于效果高度依赖报告模式库的覆盖面和操作者自己的范围控制。

**项目网址**：https://github.com/elementalsouls/Claude-BugHunter

**Star 数量**：20,286


### obra/superpowers

**一句话概括**：一套给编码代理用的完整软件开发方法论，由可组合技能和初始指令驱动。

**详细介绍**：代理启动后不会直接写代码，而是先追问真实目标、拆出规格、分块确认设计，再生成连“没品味没判断力的初级工程师”也能执行的计划。适合想把代理纳入正规 SDLC 的团队，但流程本身会拉长前期沟通。

**项目网址**：https://github.com/obra/superpowers

**Star 数量**：325,370


### HKUDS/CLI-Anything

**一句话概括**：把各类软件包装成 CLI，让 AI Agent 通过命令行直接操作 CAD、3D 场景、图表等工具。

**详细介绍**：项目提供 CLI-Hub 来浏览和安装社区构建的 CLI harness，目标是让代理用一条命令驱动原本面向人类的软件。实际可用性取决于每个 harness 的完成度，目前更像一个正在扩张的社区接口层。

**项目网址**：https://github.com/HKUDS/CLI-Anything

**Star 数量**：64,046


### jingyaogong/minimind

**一句话概括**：从零训练 64M 超小语言模型的全流程开源项目，主打两小时、三块钱的复现门槛。

**详细介绍**：覆盖预训练、SFT、LoRA、DPO、PPO/GRPO 到 Tool Use 和 Agentic RL，核心算法用原生 PyTorch 手写，不依赖高层抽象。适合想拆开大模型黑盒的学习者，但“两小时”仅指单张 3090 跑完 SFT 一个 epoch。

**项目网址**：https://github.com/jingyaogong/minimind

**Star 数量**：69,752


### cursor/plugins

**一句话概括**：Cursor 官方插件规范与首批官方插件集合，每个插件带独立 manifest。

**详细介绍**：现有插件覆盖教学、持续学习、团队工作流、深度分支审查和插件脚手架等场景，其中 Thermos 主打安全与正确性审计加并行子代理。它更像是 Cursor 生态的插件样板间，具体能力要看各插件自己的实现。

**项目网址**：https://github.com/cursor/plugins

**Star 数量**：18,924


### firecrawl/firecrawl

**一句话概括**：把网站转成干净 Markdown 并接入代理的知识基础设施，支持本地单二进制、云服务和自托管三种形态。

**详细介绍**：本地版无需数据库和队列，装好即可作为 MCP 服务器给代理用；云版额外提供搜索和 550+ 数据提供商。自托管则要自己扛队列、worker 和数据库，适合对数据流向有要求的团队。

**项目网址**：https://github.com/firecrawl/firecrawl

**Star 数量**：208,226


### nginx/nginx

**一句话概括**：NGINX 官方开源仓库，Web 服务器、负载均衡、反向代理和内容缓存的老牌底座。

**详细介绍**：README 本身是一份面向新手的结构化入门，覆盖模块、配置、运行时和从源码构建。它不靠新鲜感取胜，但作为基础设施参考和动态模块开发的起点仍然扎实。

**项目网址**：https://github.com/nginx/nginx

**Star 数量**：33,100


### openvinotoolkit/openvino

**一句话概括**：面向推理优化与部署的开源工具包，支持从 PyTorch、TensorFlow、ONNX 到 Hugging Face 模型的转换与加速。

**详细介绍**：目标是在 CPU、Intel GPU 和 NPU 上降低资源占用并提升推理性能，覆盖视觉、语音、生成式 AI 等任务。适合需要在边缘到云之间统一部署路径的团队，但硬件绑定 Intel 加速器是现实前提。

**项目网址**：https://github.com/openvinotoolkit/openvino

**Star 数量**：12,344


### cathrynlavery/diagram-design

**一句话概括**：让代理画出单文件 HTML+SVG 编辑级图表的技能，52 种图型，明确拒绝 Mermaid 式糊弄。

**详细介绍**：用自然语言描述架构、象限或时序图，代理选型、说明计划并输出一个双击即开的 HTML 文件，还能抓取站点配色和字体来匹配品牌。适合对图表观感有要求的人，但输出是静态文件，交互能力有限。

**项目网址**：https://github.com/cathrynlavery/diagram-design

**Star 数量**：71,241


### mvanhorn/last30days-skill

**一句话概括**：让代理跨 Reddit、X、YouTube、HN、Polymarket 和网页做主题调研，再合成有出处的摘要。

**详细介绍**：它按点赞、喜欢和真金白银的赔率给信息排序，零配置即可跑 Reddit、HN、Polymarket 和 GitHub，向导再解锁 X、YouTube、TikTok 等来源。适合快速摸清一个话题近 30 天的舆论面，但摘要质量受各平台数据可及性牵制。

**项目网址**：https://github.com/mvanhorn/last30days-skill

**Star 数量**：73,678


**今日总结**：今天最值得留意的不是某个单点工具，而是“技能包”正在成为代理生态的分发单位。选一个装进自己的工作流，比继续收藏榜单更有用。
