Python

给你的 AI Agent 装上眼睛，让它能刷遍全网社交平台，还不花一分钱 API 费。

你的 AI Agent 再聪明，如果只能对着本地文件发呆，那跟咸鱼有什么区别？这个项目就是来解决这个痛点的——一个 CLI 搞定 Twitter、Reddit、YouTube、GitHub、B站、小红书的信息读取和搜索，零 API 费用。翻译成人话就是：你的 Agent 终于可以自己去网上冲浪了，而且不用你掏钱买门票。Python 写的，接入成本低，适合想让 Agent 真正“联网”的开发者。
