今日 GitHub 狠活：有人把 AirDrop 开源了，有人把系统提示词全扒了

今天的热榜堪称神仙打架：从 9 万星的跨平台传文件神器，到把 ChatGPT/Claude/Gemini 底裤扒光的提示词仓库，再到用纯 C 在破电脑上跑前沿大模型的狠活。话不多说，开整。

colibri

一句话概括：用纯 C 写的超轻量推理引擎，让你在自家老硬件上跑前沿 MoE 大模型。

详细介绍：这年头想跑个大模型，不是要 A100 就是要 4090，普通人只能干瞪眼。colibri 的思路很清奇——把专家（experts）从磁盘流式加载，模型本体小到离谱，零依赖、纯 C 实现，编译完就能跑。翻译成人话就是：你那台吃灰的旧笔记本，可能真能跑起来前沿 MoE 模型。当然，速度嘛……你自己体会，但"能跑"和"跑得快"本来就是两码事。

项目网址：https://github.com/JustVugg/colibri

Star 数量：32,229

推荐指数：⭐⭐⭐⭐（硬件穷人的福音，折腾党的新玩具）

open-code-review

一句话概括：阿里开源的代码审查工具，确定性流水线 + LLM Agent 混合架构。

详细介绍：阿里内部大规模实战打磨过的代码审查工具，终于开源了。它的定位很明确：不是让 AI 瞎评一通，而是把"确定性规则"和"LLM 智能分析"结合起来——该用规则卡的地方绝不含糊，该用大模型理解语义的地方才上 AI。内置多语言规则集，NPE、线程安全、XSS、SQL 注入这些经典坑都给你标到行级别。兼容 OpenAI 和 Anthropic 接口，接入成本低。对于天天被 CR 折磨的团队来说，这玩意儿能省下不少头发。

项目网址：https://github.com/alibaba/open-code-review

Star 数量：26,019

推荐指数：⭐⭐⭐⭐⭐（大厂背书 + 实用主义，团队刚需）

YuE

一句话概括：前沿音乐生成模型，支持符号规划、零样本翻唱和智能音乐编辑。

详细介绍：AI 生成音乐的项目不少，但 YuE2 的野心更大——它不只是"给你生成一段旋律"，而是引入了符号规划（symbolic planning）和 Agent 式的音乐编辑能力。零样本翻唱意味着你丢给它一首歌，它能给你换个风格重新演绎。做视频配乐、搞音乐创作、甚至单纯玩票，这玩意儿都能派上用场。当然，版权问题请自行斟酌，别怪我没提醒你。

项目网址：https://github.com/multimodal-art-projection/YuE

Star 数量：8,441

推荐指数：⭐⭐⭐⭐（音乐创作者的 AI 助手，潜力股）

VoiceStudio

一句话概括：完全本地运行的开源 ElevenLabs 替代品，支持 646 种语言的语音克隆和视频配音。

详细介绍：ElevenLabs 好用是好用，但价格和隐私问题让不少人望而却步。VoiceStudio 直接掀桌子：语音克隆、语音设计、视频配音、听写、转录、有声书制作，全给你打包，全部本地跑，支持 646 种语言。你的声音数据不用上传到任何服务器，隐私拉满。对于做播客、有声书、视频本地化的创作者来说，这就是白嫖党的终极梦想。

项目网址：https://github.com/debpalash/VoiceStudio

Star 数量：29,420

推荐指数：⭐⭐⭐⭐⭐（本地 + 全能 + 免费，还要啥自行车）

MiroFish

一句话概括：一个简洁通用的群体智能引擎，号称能"预测万物"。

详细介绍：名字听着像摸鱼，实际是个正经的群体智能（Swarm Intelligence）引擎。所谓群体智能，就是模拟一群简单个体通过协作涌现出复杂行为——鸟群、蚁群、鱼群都是这个逻辑。MiroFish 把这套机制抽象成一个通用引擎，你喂它数据，它给你做预测。至于"预测万物"这个口号嘛……听听就好，但作为研究群体智能的工程框架，它的设计思路确实值得一看。

项目网址：https://github.com/666ghj/MiroFish

Star 数量：73,244

推荐指数：⭐⭐⭐⭐（概念有趣，落地看场景）

Agent-Reach

一句话概括：给你的 AI Agent 装上"眼睛"，一个 CLI 就能读取和搜索全网内容，零 API 费用。

详细介绍：现在的 AI Agent 最大的痛点之一就是"瞎"——它只能看你喂给它的东西。Agent-Reach 直接给 Agent 开了天眼：Twitter、Reddit、YouTube、GitHub、B 站、小红书，一个命令行工具全搞定，关键是零 API 费用。不用申请 key、不用绑信用卡、不用担心额度，对个人开发者和小团队来说简直是救命稻草。当然，爬虫的合规性和稳定性你自己掂量。

项目网址：https://github.com/Panniantong/Agent-Reach

Star 数量：81,398

推荐指数：⭐⭐⭐⭐⭐（Agent 开发者的刚需工具，8 万星不是白来的）

system_prompts_leaks

一句话概括：把 Anthropic、OpenAI、Google、xAI 各家大模型的系统提示词全扒出来了。

详细介绍：这个仓库的存在本身就是一种行为艺术。Claude Fable 5.1、Opus 5、ChatGPT GPT-6-Astra、Gemini 3.8 Flash、Grok……各家大模型的系统提示词被提取出来公之于众，而且定期更新。对于研究 prompt engineering 的人来说，这是绝佳的学习素材——看看顶级团队是怎么写系统提示词的。对于普通用户来说，这就是吃瓜现场——原来那些 AI 的"人设"是这么来的。

项目网址：https://github.com/asgeirtj/system_prompts_leaks

Star 数量：66,841

推荐指数：⭐⭐⭐⭐⭐（Prompt 工程师的圣经，吃瓜群众的天堂）

oh-my-hermes

一句话概括：Hermes Agent 的全能插件，集成了长期记忆系统和模型优化工作流。

详细介绍：Hermes Agent 是个不错的编码智能体，但默认配置嘛……总差点意思。oh-my-hermes 就是来补这个缺的：长期记忆系统让 Agent 记住你的偏好和历史上下文，模型优化工作流包让它在不同任务上自动切换最优策略。名字致敬 oh-my-zsh，定位也类似——让你的 Agent 从"能用"变成"好用"。虽然星数不多，但这类工具往往是深度用户的真爱。

项目网址：https://github.com/rlaope/oh-my-hermes

Star 数量：2,108

推荐指数：⭐⭐⭐（小众但精准，Hermes 用户必装）

localsend

一句话概括：开源的跨平台 AirDrop 替代品，手机电脑互传文件不再看品牌脸色。

详细介绍：AirDrop 好用，但仅限苹果生态；安卓和 Windows 用户只能眼馋。localsend 就是来打破这堵墙的：跨平台、开源、局域网直传，不压缩画质、不走服务器、不限文件大小。iPhone 传安卓、Windows 传 Mac，通通不在话下。9 万多星说明了一切——这玩意儿是真刚需，而且真的好用。唯一的要求就是设备得在同一个局域网里。

项目网址：https://github.com/localsend/localsend

Star 数量：91,383

推荐指数：⭐⭐⭐⭐⭐（跨平台传文件的天花板，闭眼入）

vaultwarden

一句话概括：用 Rust 写的非官方 Bitwarden 兼容服务端，自建密码管理器的首选。

详细介绍：Bitwarden 本身已经够良心了，但总有人想把数据完全握在自己手里。vaultwarden（原名 bitwarden_rs）就是为这群人准备的：Rust 编写，资源占用极低，一台树莓派就能跑起来，兼容 Bitwarden 官方客户端。你不用信任任何云服务商，密码库就在自己服务器上。对于有自建能力的技术用户来说，这是密码管理的终极方案——免费、开源、可控。

项目网址：https://github.com/dani-garcia/vaultwarden

Star 数量：67,553

推荐指数：⭐⭐⭐⭐⭐（自建密码管理的标杆项目，稳如老狗）

今日总结：今天的热榜很有意思——一边是"把大模型塞进破电脑"的极致优化（colibri），一边是"把大模型底裤扒光"的信息透明（system_prompts_leaks）；一边是本地优先的隐私派（VoiceStudio、vaultwarden），一边是打破生态壁垒的开放派
