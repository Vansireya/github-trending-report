今日 GitHub 狠活：AI 代理开始自己查安全漏洞了，Cloudflare 先下手为强

各位打工人早上好，欢迎收看今天的 GitHub 热榜。今天的关键词只有一个：AI Agent 全家桶。从安全审计到设计规范，从机器人鸭子到电子书宝库，GitHub 今天的榜单仿佛在说：人类，你歇着吧，剩下的交给我们。

cloudflare/security-audit-skill

一句话概括：给编码代理装上一套多阶段安全审计技能，查出来的漏洞还能机器可读、独立验证。

详细介绍：以前让 AI 写代码，写完你还得自己提心吊胆地查安全漏洞，现在 Cloudflare 直接把这个活儿也交给了 AI——而且不是瞎查，是分阶段、可验证、结果能直接喂给流水线的那种。44k 星说明大家苦"AI 写代码一时爽，上线安全火葬场"久矣。这个项目解决的核心痛点就是：让 AI 不仅会写，还会自己审判自己写的代码。

项目网址：https://github.com/cloudflare/security-audit-skill

Star 数量：44,740

推荐指数：⭐⭐⭐⭐⭐

NVIDIA/OpenShell

一句话概括：给自主 AI 代理准备的"安全私有运行沙箱"。

详细介绍：AI 代理越来越能干，但你敢让它随便在你机器上跑命令吗？NVIDIA 说：不敢就对了，来用 OpenShell。这是一个用 Rust 写的运行时，专门给那些"自己会思考、自己会动手"的 AI 代理提供一个隔离的安全环境。翻译成人话：给代理套个笼子，让它在里面尽情折腾，外面世界安然无恙。19k 星，说明大家对"代理失控"这件事是真的怕。

项目网址：https://github.com/NVIDIA/OpenShell

Star 数量：19,519

推荐指数：⭐⭐⭐⭐

aws/agent-toolkit-for-aws

一句话概括：AWS 官方出品的 MCP 服务器、技能和插件合集，帮 AI 代理在 AWS 上盖房子。

详细介绍：AWS 终于坐不住了，官方下场给 AI 代理发工具包。痛点很明确：你想让 AI 帮你操作 AWS，但一堆 API、权限、配置能把它绕晕。这个工具包就是官方铺好的红毯，让代理能规规矩矩地在云上干活。3k 星不算多，但官方背书 + Python 生态，属于"现在不火以后必用"的类型。

项目网址：https://github.com/aws/agent-toolkit-for-aws

Star 数量：3,155

推荐指数：⭐⭐⭐

Nutlope/hallmark

详细介绍：AI 生成的设计有个通病——看着挺像那么回事，但总透着一股"我是 AI 我骄傲"的塑料感。Hallmark 就是来治这个的，一套设计技能，让你的 AI 助手产出不那么"AI slop"的东西。32k 星说明设计师和开发者对"AI 味"的容忍度已经到极限了。用 CSS 写设计规范，这很合理。

项目网址：https://github.com/Nutlope/hallmark
