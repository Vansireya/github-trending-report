Agent 技能包与工具链密集登场

今天榜单几乎被 Agent 技能包和配套工具占据：Claude-BugHunter 把漏洞挖掘经验打包成 85 个技能，superpowers 则试图给编码 Agent 立一套开发方法论。另一边，minimind 继续用极低成本训练小模型，提醒人们底层复现仍有独立价值。

1
elementalsouls/Claude-BugHunter ★ 26,356
Python

把 85 个漏洞挖掘技能、16 个斜杠命令和 681 条公开报告模式塞进 Claude Code 的技能包。

面向授权红队和漏洞赏金场景，按方法论、Web 应用狩猎、企业身份与基础设施攻击矩阵分层组织，并集成 Burp MCP。局限在于它依赖 Claude Code 技能系统，且 README 强调需在授权范围内使用，不能当作自动化攻击工具。

2
obra/superpowers ★ 328,476
Shell

一套给编码 Agent 用的完整软件开发方法论，由可组合技能和初始指令构成。

它让 Agent 先追问需求、拆出规格，再分块确认设计，最后生成连“没品味、没判断力”的初级工程师也能执行的计划。覆盖 Claude Code、Codex、Cursor 等多种宿主，但本质是流程约束，效果取决于 Agent 是否遵守技能指令。

3
HKUDS/CLI-Anything ★ 67,105
Python

试图把各类软件包装成 Agent 可直接调用的 CLI，并配一个社区 CLI-Hub 做分发。

通过 pip 安装 cli-anything-hub 后，可浏览和安装社区构建的 CLI，让 Agent 操作 CAD、3D 场景、图表等软件。思路是把“Agent 原生”落到命令行接口层，但实际覆盖度和各 CLI 的稳定性取决于社区贡献。

4
jingyaogong/minimind ★ 72,300
Python

用约 3 块钱 GPU 租用成本和 2 小时 SFT，从零训出 64M 参数的超小语言模型。

项目开源了极简模型结构及预训练、SFT、LoRA、RLHF、Agentic RL 等全链路代码，核心算法用原生 PyTorch 实现。适合想理解大模型内部机制的个人开发者，但 64M 规模的能力边界有限，不能替代实用级模型。

5
cursor/plugins ★ 20,048
TypeScript

Cursor 官方插件规范与官方插件集合，每个插件是带独立 manifest 的目录。

仓库列出教学、持续学习、团队工具包、分支审查等插件，其中 thermos 做深度安全与正确性审计，ralph-loop 做自引用迭代循环。它定义了插件如何组织，但生态尚在早期，插件质量和维护取决于各自作者。

6
firecrawl/firecrawl ★ 211,816
TypeScript

把网站抓取成干净 Markdown 的知识基础设施，支持本地单二进制、云服务和自托管三种形态。

Firecrawl Local 无需数据库和队列，可作为 MCP 服务器接入 AI Agent；云服务额外提供搜索和 550+ 数据提供商。适合给 Agent 补充网页知识，但本地版需要 Rust 和 C 编译器，自托管则要自己维护队列与数据库。

7
nginx/nginx ★ 33,691
C

NGINX 官方开源仓库，Web 服务器、反向代理、负载均衡和内容缓存的经典实现。

README 面向新手提供结构化入门，覆盖模块、配置、运行时、SSL、限流和缓存等基础主题。它本身不是新项目，上榜更多说明基础设施常青；实际部署仍需参考完整文档，不能只靠 README 上手。

8
openvinotoolkit/openvino ★ 12,973
C++

英特尔主导的深度学习推理优化与部署工具包，覆盖 CPU、GPU 和 NPU。

支持 PyTorch、TensorFlow、ONNX、JAX 等框架模型转换，并可通过 Optimum Intel 直接接入 Hugging Face 模型。适合在边缘到云端的英特尔硬件上压缩和部署推理，但硬件绑定较明显，非英特尔平台收益有限。

9
cathrynlavery/diagram-design ★ 74,548
HTML

给编码 Agent 用的图表设计技能，输出自包含 HTML + SVG，提供 52 种图表类型。

用户用自然语言描述架构图、象限图或时序图，Agent 选型并生成单个可双击打开的 HTML 文件，还能抓取网站配色和字体来匹配品牌。它明确反对 Mermaid 式粗糙输出，但图表质量仍取决于 Agent 对描述的理解。
