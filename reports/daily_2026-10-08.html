今日 GitHub 狠活：AI Agent 们开始互相卷「技能包」了

今天的热榜有点意思——一半项目在教 AI 怎么干活，另一半在教 AI 怎么把话说清楚。看来人类的耐心，连 AI 都看不下去了。

rea

一句话概括： 用 AI Agent 逆向工程一切，从 App 行为一路扒到原生二进制。

详细介绍： 以前搞逆向得靠 IDA 里熬大夜，现在直接派 Agent 去啃。它解决的是「我不想读懂汇编但我想知道这软件到底在干嘛」的终极痛点。TypeScript 写的，说明作者认为逆向工程的门槛应该和写前端一样低——这很勇敢。

项目网址： https://github.com/morluto/rea

Star 数量： 16,401

推荐指数： ⭐⭐⭐⭐（方向很酷，但逆向这行，Agent 翻车了你可能都不知道它在哪翻的）

mattpocock/skills

一句话概括： 真·工程师的技能包，直接从作者的 .agents 目录里掏出来的。

详细介绍： 279,847 颗星，这个数字已经不需要我多解释了——它基本上就是 AI Agent 技能领域的「老干妈」，什么都能配。作者 Matt Pocock 本来就是 TypeScript 圈的顶流，现在把私藏的 Agent 技能全公开，属于是把压箱底的家传秘方贴在了电线杆上。

项目网址： https://github.com/mattpocock/skills

Star 数量： 279,847

推荐指数： ⭐⭐⭐⭐⭐（这个星数已经不是推荐不推荐的问题了，是你不看就显得有点不合群）

AnyPS5

一句话概括： 把 PS5 游戏自动移植到 Linux 和 Windows 的工具。

详细介绍： 索尼看了想发律师函，玩家看了想放烟花。PS5 独占游戏一直是 PC 玩家的心头痛，这个 C++ 工具想用自动化方式把可执行文件搬到 PC 上。技术上很硬核，法律上很微妙，道德上……我们不做评价，我们只负责转发。

项目网址： https://github.com/boykopovar/AnyPS5

Star 数量： 11,068

推荐指数： ⭐⭐⭐（技术力拉满，但建议先咨询一下你的律师朋友）

i-have-adhd

一句话概括： 一个让 AI 别废话、直接给答案的技能，专治「Agent 绕圈子」。

详细介绍： 痛点极其真实：你问 AI 一个 yes/no 问题，它先给你写 800 字背景介绍，再列 5 个注意事项，最后才在结尾轻飘飘地说「所以答案是……不」。这个 Python 项目就是给 Agent 装了个「说重点」的开关，ADHD 友好输出——意思是，别让我等，别让我找，直接说结论。

项目网址： https://github.com/ayghri/i-have-adhd

Star 数量： 55,257

推荐指数： ⭐⭐⭐⭐⭐（当代人注意力比黄金还贵，这个项目值 6 星，但我只能给 5 星）

diagram-design

一句话概括： 给 AI 编程工具用的编辑级图表设计，42 种图表类型，纯 HTML + SVG。

详细介绍： 简介里那句「No Mermaid slop」简直是替全人类出了一口恶气。Mermaid 生成的图，懂的都懂——能用，但丑得让人不想用。这个项目提供 42 种图表类型，自包含 HTML + SVG，没有阴影，没有花里胡哨，就是干净利落的编辑级设计。支持 Claude Code、Codex、Copilot 等一众工具。

项目网址： https://github.com/cathrynlavery/diagram-design

Star 数量： 45,159

推荐指数： ⭐⭐⭐⭐（「No Mermaid slop」这五个字就值一颗星）

addyosmani/agent-skills

一句话概括： 给 AI 编程 Agent 的生产级工程技能包。

详细介绍： Addy Osmani 出品，Google 工程圈的活化石级人物。这个项目解决的是「AI 写的代码能跑但不敢上生产」的问题——把真正的工程实践、代码审查、测试规范打包成 Agent 技能。102,924 颗星说明大家苦「AI 写的代码像实习生交的作业」久矣。

项目网址： https://github.com/addyosmani/agent-skills

Star 数量： 102,924

推荐指数： ⭐⭐⭐⭐⭐（Addy 出品，必属精品，这波是工程界的降维打击）

raddebugger

一句话概括： Epic Games 出品的原生、用户态、多进程图形化调试器。

详细介绍： Epic 不声不响扔了个调试器出来。原生、用户态、多进程、图形化——这四个词放在一起，基本就是「RAD Debugger 想把 WinDbg 和 x64dbg 的优点缝在一起，而且缝得很好看」。C 写的，性能不用担心。7,908 颗星不算爆款，但懂调试器的人都知道这东西含金量有多高。

项目网址： https://github.com/EpicGames/raddebugger

Star 数量： 7,908

推荐指数： ⭐⭐⭐⭐（调试器是程序员的听诊器，Epic 这把听诊器做得挺精致）

claude-mem

一句话概括： 让 AI Agent 拥有跨会话的持久记忆，不再每次聊天都从零开始。

详细介绍： 你每次开新对话，Agent 都像失忆了一样问你「你好，有什么可以帮您」——这个项目就是来治这个病的。它捕获 Agent 在会话中的所有操作，用 AI 压缩后注入到未来的会话里。支持 Claude Code、Codex、Gemini、Copilot 等一大票工具。97,840 颗星说明「AI 金鱼记忆」是全人类的共同痛点。

项目网址： https://github.com/thedotmack/claude-mem

Star 数量： 97,840

推荐指数： ⭐⭐⭐⭐⭐（如果 AI 能记住我上次骂它的话，它可能会进步得更快）

cmux

一句话概括： 基于 Ghostty 的开源 macOS 终端，带垂直标签页和 AI Agent 通知。

详细介绍： 终端用户分两种：一种觉得 iTerm2 够用了，另一种永远在找更好的终端。cmux 基于 Ghostty 内核，加了垂直标签页和 AI Agent 通知——后者的意思是，你的 AI 在后台干活干完了会弹通知告诉你，不用你盯着终端发呆。Swift 写的，macOS 原生体验，专为多任务和可编程性设计。

项目网址： https://github.com/manaflow-ai/cmux

Star 数量： 27,899

推荐指数： ⭐⭐⭐⭐（终端界的「再买剁手」系列，但垂直标签页确实香）

cua

一句话概括： 开源驱动 + 跨 OS 集群 + 基准测试，把 computer-use 2.0 规模化。

详细介绍： 这个项目的野心是让 AI 直接操作电脑——不是 API 调用，是像人一样点鼠标、敲键盘。提供开源驱动、跨操作系统集群和训练/评估/数据生成的基准测试。Rust 写的，性能拉满。28,823 颗星说明「让 AI 自己用电脑」这个方向，大家都觉得是未来。

项目网址： https://github.com/trycua/cua

Star 数量： 28,823

推荐指数： ⭐⭐⭐⭐（距离「AI 帮我点外卖」又近了一步，但距离「AI 把我电脑搞崩」也近了一步）

今日总结： 10 个项目里，5 个在给 AI 装技能，2 个在给 AI 装记忆，1 个在教 AI 说人话，1 个在让 AI 操作电脑，还有 1 个在让 PS5 游戏上 PC——前九个在卷 AI，最后一个在卷索尼。世界就是这么参差。
