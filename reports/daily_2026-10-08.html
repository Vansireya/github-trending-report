今日 GitHub 狠活：AI Agent 们开始互相卷「技能包」了

今天的热榜有点意思——一半项目在教 AI 怎么干活，另一半在教 AI 怎么把话说清楚。看来人类的耐心，连 AI 都看不下去了。

rea ★ 16,401
TypeScript

用 AI Agent 逆向工程一切，从 App 行为一路扒到原生二进制。

以前搞逆向得靠 IDA 里熬大夜，现在直接派 Agent 去啃。它解决的是「我不想读懂汇编但我想知道这软件到底在干嘛」的终极痛点。TypeScript 写的，说明作者认为逆向工程的门槛应该和写前端一样低——这很勇敢。

Shell

真·工程师的技能包，直接从作者的 .agents 目录里掏出来的。

279,847 颗星，这个数字已经不需要我多解释了——它基本上就是 AI Agent 技能领域的「老干妈」，什么都能配。作者 Matt Pocock 本来就是 TypeScript 圈的顶流，现在把私藏的 Agent 技能全公开，属于是把压箱底的家传秘方贴在了电线杆上。

AnyPS5 ★ 11,068
C++

把 PS5 游戏自动移植到 Linux 和 Windows 的工具。

索尼看了想发律师函，玩家看了想放烟花。PS5 独占游戏一直是 PC 玩家的心头痛，这个 C++ 工具想用自动化方式把可执行文件搬到 PC 上。技术上很硬核，法律上很微妙，道德上……我们不做评价，我们只负责转发。

4
i-have-adhd ★ 55,257
Python

一个让 AI 别废话、直接给答案的技能，专治「Agent 绕圈子」。

痛点极其真实：你问 AI 一个 yes/no 问题，它先给你写 800 字背景介绍，再列 5 个注意事项，最后才在结尾轻飘飘地说「所以答案是……不」。这个 Python 项目就是给 Agent 装了个「说重点」的开关，ADHD 友好输出——意思是，别让我等，别让我找，直接说结论。

5
diagram-design ★ 45,159
HTML

给 AI 编程工具用的编辑级图表设计，42 种图表类型，纯 HTML + SVG。

简介里那句「No Mermaid slop」简直是替全人类出了一口恶气。Mermaid 生成的图，懂的都懂——能用，但丑得让人不想用。这个项目提供 42 种图表类型，自包含 HTML + SVG，没有阴影，没有花里胡哨，就是干净利落的编辑级设计。支持 Claude Code、Codex、Copilot 等一众工具。

6
addyosmani/agent-skills ★ 102,924
JavaScript

给 AI 编程 Agent 的生产级工程技能包。

Addy Osmani 出品，Google 工程圈的活化石级人物。这个项目解决的是「AI 写的代码能跑但不敢上生产」的问题——把真正的工程实践、代码审查、测试规范打包成 Agent 技能。102,924 颗星说明大家苦「AI 写的代码像实习生交的作业」久矣。

7
raddebugger ★ 7,908
C

Epic Games 出品的原生、用户态、多进程图形化调试器。

Epic 不声不响扔了个调试器出来。原生、用户态、多进程、图形化——这四个词放在一起，基本就是「RAD Debugger 想把 WinDbg 和 x64dbg 的优点缝在一起，而且缝得很好看」。C 写的，性能不用担心。7,908 颗星不算爆款，但懂调试器的人都知道这东西含金量有多高。

claude-mem ★ 97,840
TypeScript

让 AI Agent 拥有跨会话的持久记忆，不再每次聊天都从零开始。

你每次开新对话，Agent 都像失忆了一样问你「你好，有什么可以帮您」——这个项目就是来治这个病的。它捕获 Agent 在会话中的所有操作，用 AI 压缩后注入到未来的会话里。支持 Claude Code、Codex、Gemini、Copilot 等一大票工具。97,840 颗星说明「AI 金鱼记忆」是全人类的共同痛点。

9
cmux ★ 27,899
Swift

基于 Ghostty 的开源 macOS 终端，带垂直标签页和 AI Agent 通知。

终端用户分两种：一种觉得 iTerm2 够用了，另一种永远在找更好的终端。cmux 基于 Ghostty 内核，加了垂直标签页和 AI Agent 通知——后者的意思是，你的 AI 在后台干活干完了会弹通知告诉你，不用你盯着终端发呆。Swift 写的，macOS 原生体验，专为多任务和可编程性设计。
