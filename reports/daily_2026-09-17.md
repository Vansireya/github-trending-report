# 今日 GitHub 狠活：阿里把代码审查玩成了流水线，NSA 还在用 Java 教你怎么拆二进制

> 今天的榜单突出一个"卷"字：阿里把代码审查做成了混合架构流水线，Cloudflare 让 AI Agent 自己给自己做安全审计，还有人用纯 C 把 MoE 大模型塞进了你的旧笔记本。下面逐个开喷——不对，是逐个点评。


### alibaba/open-code-review

**一句话概括：** 阿里巴巴开源的代码审查工具，确定性流水线 + LLM Agent 混合架构，专治"这行代码有 NPE 但没人发现"。

**详细介绍：** 代码审查这件事，人做久了会瞎，机器做久了会蠢——纯规则引擎查不出上下文语义，纯 LLM 又容易一本正经地胡说八道。阿里这个项目的思路很务实：能确定性判断的用流水线，需要理解语义的交给 LLM Agent，各干各的活。内置了 NPE、线程安全、XSS、SQL 注入等多语言规则集，还能给出精确到行级别的评论，不是那种"你这个文件有问题"的废话式反馈。兼容 OpenAI 和 Anthropic 接口，意味着你不用被绑死在某一家。32K Star 说明了一件事：天下苦 Code Review 久矣。

**项目网址：** https://github.com/alibaba/open-code-review

**Star 数量：** 32,224

**推荐指数：** ⭐⭐⭐⭐⭐


### cloudflare/security-audit-skill

**一句话概括：** Cloudflare 出的编码 Agent 技能包，让 AI 自己给自己做多阶段安全审计，输出机器可读的审计结果。

**详细介绍：** 安全审计的痛点在于：人做太慢，工具做太死。这个项目的定位是给 coding agent 装上一个"安全审计技能"，分阶段执行审计流程，而且关键点在于——findings 是**独立验证**过的，不是 AI 拍脑袋说"这里可能有漏洞"就完事了。机器可读的输出格式意味着你可以直接把它塞进 CI/CD 流水线，而不是让安全工程师对着 PDF 报告手动建 Jira ticket。7.5K Star 对于一个"技能包"来说已经相当能打了，说明安全自动化这个方向确实是刚需。

**项目网址：** https://github.com/cloudflare/security-audit-skill

**Star 数量：** 7,504

**推荐指数：** ⭐⭐⭐⭐


### JustVugg/colibri

**一句话概括：** 纯 C 写的极简推理引擎，零依赖，靠磁盘流式加载专家权重，让你在自家旧硬件上跑前沿 MoE 大模型。

**详细介绍：** 这个项目的野心用一句话就能说清楚：**你不需要买 H100。** MoE（混合专家）模型的特点是参数量巨大但每次推理只激活一小部分专家，colibri 就抓住了这个特性——把专家权重放在磁盘上，需要哪个流式加载哪个。纯 C 实现，零依赖，没有 Python 环境地狱，没有 CUDA 版本冲突，没有"pip install 完之后发现 torch 和 numpy 打架"。35K Star 说明社区对"在本地跑大模型"这件事的渴望已经到了什么程度。当然，磁盘 IO 会成为新的瓶颈，但比起买显卡的钱，一块 NVMe SSD 简直是白菜价。

**项目网址：** https://github.com/JustVugg/colibri

**Star 数量：** 35,100

**推荐指数：** ⭐⭐⭐⭐⭐


### abue-ammar/tinycast

**一句话概括：** 一个完全原生的小巧 macOS 启动器，附带热键和剪贴板历史功能。

**详细介绍：** macOS 上的启动器市场已经被 Alfred 和 Raycast 瓜分得差不多了，但这两个都有一个共同问题：它们不是"原生"的。tinycast 走的是完全原生路线，用 Swift 写，轻量、快、不占内存。功能上就是三件事：启动应用、全局热键、剪贴板历史——没有插件市场，没有 AI 集成，没有"我们正在重新定义生产力"的宏大叙事。有时候你只是想要一个不卡的启动器而已。5.6K Star 对于一个小工具来说算是不错的成绩，说明"少即是多"这个道理在 2025 年依然成立。

**项目网址：** https://github.com/abue-ammar/tinycast

**Star 数量：** 5,670

**推荐指数：** ⭐⭐⭐

### ankitects/anki

**一句话概括：** 老牌间隔重复闪卡学习工具，用算法帮你对抗遗忘曲线。

**详细介绍：** Anki 不需要太多介绍——它可能是这个榜单上"年龄最大"的项目。间隔重复（Spaced Repetition）这个学习方法的核心理念是：在你快要忘记某个知识点的临界点复习它，效率最高。Anki 把这套算法做成了软件，从医学生背解剖图谱到程序员背 API，从语言学习到考证刷题，几乎通吃。30K Star 是多年积累的结果，不是一夜爆红。Rust 重写后端之后性能有了明显提升。这个项目的存在证明了一件事：**好的工具不需要花哨，只需要真的有用。**

**项目网址：** https://github.com/ankitects/anki

**Star 数量：** 30,907

**推荐指数：** ⭐⭐⭐⭐⭐
