AI 智能体开始接管桌面、Git 与记忆

今天的榜单几乎被 AI 智能体的周边工具占满：从让智能体直接操作桌面应用的 agent-desktop，到为并行智能体管理 Git worktree 的 worktrunk，再到给 Claude Code 做持久记忆的 claude-mem。最值得留意的是 vercel-labs/agent-desktop 和 max-sixty/worktrunk，它们分别从“看屏幕”和“管分支”两个角度，补上了智能体真正干活时缺的那块基础设施。

1
thedotmack/claude-mem ★ 112,097
TypeScript

给 Claude Code 等智能体做跨会话记忆压缩，自动抓取工具调用观察并生成语义摘要，下次会话再注入。

它解决的是智能体每次重连后“失忆”的问题：自动记录会话中的工具使用观察，用 AI 压缩成摘要，未来会话按需取回。局限在于记忆质量依赖摘要模型，且默认走托管服务，本地观察者需要显式切换。

2
vercel-labs/agent-desktop ★ 13,167
Rust

让 AI 智能体通过操作系统无障碍树“看”并操作桌面应用，返回带 ref 的 JSON，不靠截图和像素匹配。

智能体拿到每个可操作元素的 ref 后点击或输入，再重新读取 UI 验证结果，循环逻辑留在智能体侧。它本身不含模型，只提供 CLI 和 C 库；快照和剪贴板可能含隐私内容，需要自行隔离日志。

3
max-sixty/worktrunk ★ 10,596
Rust

把 git worktree 包装成三条核心命令，让并行跑多个 AI 智能体时各自有独立工作目录，互不踩踏。

原生 git worktree 的 UX 很别扭，起一个新工作树要反复输入分支名。Worktrunk 用钩子自动化本地流程，还支持写时复制构建缓存；但它假设你已经在并行管理多个智能体，单线程用户收益有限。

4
JustVugg/colibri ★ 47,342
C

纯 C 写的 MoE 推理引擎，热专家放 GPU、温专家放内存、冷专家从 NVMe 流式读取，让大模型跑在现有硬件上。

它利用 MoE 每 token 只激活少量专家的特性，把其余专家留在磁盘按需读取，无需 GPU 也能跑。已支持十余个模型家族，但“从磁盘流式读专家”意味着实际速度受存储带宽制约，适合尝鲜而非高吞吐场景。

5
mattpocock/skills ★ 311,660
Shell

一套作者日常使用的智能体技能集，强调小而可组合、不接管流程，和 GSD、BMAD 那类重流程方案反着来。

这些技能面向真实工程而非“氛围编程”，可搭配任意模型，安装后按项目或插件方式更新。它的价值在于保持开发者控制权，但技能本身偏个人工作流，直接套用前需要按自己习惯裁剪。

6
p-e-w/heretic ★ 38,914
Python

无需训练就能修改语言模型行为：移除审查、压制废话、降低谄媚，靠对比示例和打分器做数学 steering。

它用一组数学技巧在推理时引导模型行为，支持 4-bit 量化以降低显存门槛，一个下午能在游戏 PC 上跑完。但效果取决于示例和打分器的配置，属于行为微调而非重新训练，边界并不精确。

7
spotify/portal-ai-plugins ★ 3,082
TypeScript

把 Spotify Portal 接进 Claude Code、Codex、Cursor 等编码智能体，提供目录搜索、服务简报和只读诊断。

插件围绕 Portal CLI 做认证、搜索软件目录、生成服务简报并安全调用 Portal 动作，自带 dry-run 和确认保护。另附 shunt 插件把批量读文件和样板生成路由到更便宜的 worker 模型，但目前仅限 Claude Code。

8
floci-io/floci ★ 28,943
Java

免费开源的本地 AWS 模拟器，docker compose up 就能在 localhost:4566 跑起 S3、EC2、ECS 等服务。

不需要云账号、认证令牌或付费功能门，现有 AWS SDK、CLI、Terraform 和测试套件直接指过来即可。它自称 LocalStack 的 drop-in 替代，换镜像就能迁移；但模拟覆盖度是否够全，仍需按自己的服务清单验证。

9
Usagi-org/ai-goofish-monitor ★ 16,668
Python

用 Playwright 加 AI 监控闲鱼商品，支持多任务并发、自然语言建任务、多模态分析和多渠道即时通知。

后台可配关键词、价格、区域筛选和 AI Prompt，支持 Cron 定时与账号代理轮换，Docker 一键部署。它依赖登录态 cookie 和页面结构，闲鱼改版或风控收紧时维护成本会直接上升。

今日结论

今天真正值得看的是智能体基础设施的“补课”：记忆、桌面操作、分支隔离都在从 demo 走向日常工具。colibri 和 heretic 则提醒，模型侧的本土化改造也在加速。
