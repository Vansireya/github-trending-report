# 今日 GitHub 狠活：AI 科学家、一键换脸与开源 CRM 大乱斗

各位技术老饕和摸鱼先锋，欢迎收看今日 GitHub 热榜速递。今天的热门项目堪称“神仙打架”，从能帮你写论文的 AI 科学家，到一键让你变成“顶流”的换脸神器，再到想干翻 Salesforce 的开源 CRM，应有尽有。话不多说，直接上菜。

### mvanhorn/last30days-skill
*   **一句话概括**：一个能帮你全网冲浪、搜集并总结任何话题过去30天动态的 AI 情报员。
*   **详细介绍**：还在为写周报、做市场调研、追热点而头秃吗？这个 AI 技能就是你的赛博包打听。它能在 Reddit、X（推特）、YouTube、Hacker News、Polymarket 甚至整个互联网上爬行，把关于某个话题最近30天的所有讨论、视频、观点都扒拉出来，然后给你炖出一锅有根有据、观点明确的“信息浓汤”。你再也不用在几十个标签页之间反复横跳了。
*   **项目网址**：https://github.com/mvanhorn/last30days-skill
*   **Star 数量**：12,708
*   **推荐指数**：★★★★☆ (信息焦虑症患者的福音，但依赖外部数据源)

### hacksider/Deep-Live-Cam
*   **一句话概括**：仅凭一张照片，就能实现实时视频换脸和“一键深伪”的黑科技。
*   **详细介绍**：“我有个朋友”想体验一下当明星的感觉，或者制作一些“以假乱真”的搞笑视频。这个项目就是为此而生的终极玩具（或者说，危险工具）。它最大的卖点是“单图启动”，你不需要目标人物的大量照片或视频，一张自拍或网图就够了。实时换脸功能更是让视频通话充满了“惊喜”（或惊吓）。友情提示：请务必用于符合社会主义核心价值观的娱乐目的，否则后果自负。
*   **项目网址**：https://github.com/hacksider/Deep-Live-Cam
*   **Star 数量**：83,096
*   **推荐指数**：★★★★★ (技术力爆表，娱乐性拉满，但请谨慎使用)

### SakanaAI/AI-Scientist-v2
*   **一句话概括**：一个能像科学家一样，通过“树状搜索”自主进行科学发现的 AI 智能体。
*   **详细介绍**：别以为 AI 只会写诗画画，这位“AI科学家-v2”的志向是推动人类知识边界。它不再是被动回答问题，而是能主动设计实验、提出假设、分析数据，并像真正的科研工作者一样，通过“思考-验证-再思考”的树状搜索路径来探索未知。想象一下，你给它一个研究方向，它就能在数字世界里搭建实验室，自动产出可能的新发现。这简直是研究生和科研狗们的“梦中情代”。
*   **项目网址**：https://github.com/SakanaAI/AI-Scientist-v2
*   **Star 数量**：2,873
*   **推荐指数**：★★★★☆ (概念非常前沿，潜力巨大，但目前可能还处于“实验室阶段”)

### microsoft/VibeVoice
*   **一句话概括**：微软开源的“前沿语音 AI”，目标是打造最牛的自然语音合成与克隆技术。
*   **详细介绍**：厌倦了 Siri、小娜那些毫无感情的电子音？VibeVoice 就是来革它们命的。作为微软的开源大招，它致力于生成极具表现力、情感饱满、几乎无法与真人区分的高质量语音。无论是为你的视频配音，还是打造个性化的语音助手，甚至是“复活”某个经典角色的声音，它都提供了强大的底层工具。大厂开源，品质和后续维护相对有保障。
*   **项目网址**：https://github.com/microsoft/VibeVoice
*   **Star 数量**：24,699
*   **推荐指数**：★★★★★ (大厂背书，方向热门，语音赛道的重磅选手)

### twentyhq/twenty
*   **一句话概括**：一个由社区驱动的、旨在构建 Salesforce 现代开源替代品的 CRM 系统。
*   **详细介绍**：Salesforce 很好，但也很贵，而且可能有点“老气”。Twenty 的野心就是成为 CRM 界的“Notion”——更现代、更灵活、更开源、更便宜（免费）。它允许你高度自定义客户关系管理的每一个模块，并且背靠活跃的社区。如果你受够了传统 CRM 的笨重和年费，想自己掌控一切，Twenty 提供了一个非常性感的选项。毕竟，谁不想拥有一个可以随便折腾的“数字销售部队”呢？
*   **项目网址**：https://github.com/twentyhq/twenty
*   **Star 数量**：42,024
*   **推荐指数**：★★★★★ (需求明确，社区活跃，挑战巨头的勇气可嘉)

### datalab-to/chandra
*   **一句话概括**：一个能搞定复杂表格、表单和手写体识别的全能 OCR 模型。
*   **详细介绍**：普通 OCR 遇到表格就变“麻瓜”，遇到手写字就“两眼一黑”。Chandra 就是专治这些疑难杂症的“OCR 圣手”。它不仅能识别文字，还能理解文档的完整布局结构，把表格里的数据规规矩矩地提取出来，连手写的潦草笔记也不放过。对于需要处理大量扫描文档、票据、历史档案的机构或个人来说，这玩意能省下无数个手动录入的工时。
*   **项目网址**：https://github.com/datalab-to/chandra
*   **Star 数量**：7,035
*   **推荐指数**：★★★★☆ (解决实际痛点，非常实用，但处理极端复杂情况的效果待考)

### virattt/dexter
*   **一句话概括**：一个用于深度金融研究的自主 AI 智能体。
*   **详细介绍**：想炒股？想分析财报？但面对海量的金融数据、新闻、报告感到无从下手？Dexter 就是你专属的、不知疲倦的金融分析师 AI。它能自动搜集金融信息，进行深度分析和研究，帮你生成投资报告、识别市场趋势或风险。当然，它给出的建议仅供参考，真正的决策（和盈亏）还得你自己负责。毕竟，如果它真能100%预测市场，作者早就闷声发大财去了，对吧？
*   **项目网址**：https://github.com/virattt/dexter
*   **Star 数量**：19,701
*   **推荐指数**：★★★★☆ (垂直领域应用典范，金融狗和散户的“外挂”，但需理性对待结果)

### Yeacham-Heo/oh-my-claudecode
*   **一句话概括**：为 Claude Code 设计的、团队优先的多智能体编排框架。
*   **详细介绍**：Claude Code 很强，但一个人工智能程序员够用吗？这个项目说：不够，我们要一个 AI 程序员团队！它允许你像管理一个开发团队一样，编排多个 Claude Code 智能体，让它们各司其职（比如一个写前端，一个写后端，一个做测试），协同完成一个复杂的软件项目。这简直就是“一人成军”的究极形态，对于想用 AI 大幅提升团队开发效率的领导者来说，极具吸引力。
*   **项目网址**：https://github.com/Yeachan-Heo/oh-my-claudecode
*   **Star 数量**：13,978
*   **推荐指数**：★★★★☆ (思路清奇，直击团队开发痛点，但依赖 Claude 且复杂度较高)
