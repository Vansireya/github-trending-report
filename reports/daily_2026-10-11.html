今日 GitHub 狠活：当 AI 学会逆向工程，PS5 游戏终于不用吃灰了

今天的 Trending 榜单突出一个"离谱"——有人让 Agent 去逆向二进制，有人把 PS5 游戏搬上 PC，还有人把 PPT 做成了真·原生动画。废话不多说，上菜。

morluto/rea

🎯 一句话概括: 让 AI Agent 帮你逆向任何东西，从 App 行为一路扒到原生二进制。
💡 详细介绍: 逆向工程这活儿，以前是少数人的手艺活，得会看汇编、会调 IDA、会跟混淆代码斗智斗勇。rea 直接把 Agent 拉进来干这脏活累活——你想知道某个 App 背后在干嘛？丢给它。想搞清楚某个二进制里藏了什么逻辑？也丢给它。它把&quot;逆向&quot;这件事从手工坊升级成了流水线，虽然你依然需要点技术底子来判断结果对不对，但至少不用再对着几千行反汇编发呆到凌晨三点了。
🔗 项目网址: https://github.com/morluto/rea
✨ Star 数量: 75,452
⭐ 推荐指数: ⭐⭐⭐⭐⭐（安全研究员和逆向爱好者的新玩具，星数说明一切）

boykopovar/AnyPS5

🎯 一句话概括: 自动把 PS5 可执行文件移植到 Linux 和 Windows 的工具。
💡 详细介绍: PS5 独占游戏馋哭了多少人？这个项目想做的事情就是——让 PS5 的游戏能在你的 PC 上跑起来。它自动处理可执行文件的移植工作，省去了手动折腾的噩梦。当然，法律和兼容性的事儿咱不展开，但技术上这确实是个狠活。C++ 写的，性能不用担心，就是不知道索尼看了作何感想。
🔗 项目网址: https://github.com/boykopovar/AnyPS5
✨ Star 数量: 27,152
⭐ 推荐指数: ⭐⭐⭐⭐（技术含量拉满，但请自行判断使用场景）

storytold/artcraft

🎯 一句话概括: 给艺术家、设计师和电影人用的&quot;有意为之&quot;的创作引擎。
💡 详细介绍: 市面上创作工具一大堆，但大多数要么太通用（什么都能做，什么都做不好），要么太死板（模板一套，创意清零）。ArtCraft 的定位是&quot;intentional crafting engine&quot;——它不追求大而全，而是让你带着明确意图去构建作品。Rust 写的，性能和内存安全都有保障。适合那些受够了&quot;创意被工具限制&quot;的人。
🔗 项目网址: https://github.com/storytold/artcraft
✨ Star 数量: 14,745
⭐ 推荐指数: ⭐⭐⭐（小众但精致，适合有特定需求的创作者）

cathrynlavery/diagram-design

🎯 一句话概括: 给 AI 编程助手用的编辑级图表设计系统，44 种图表类型，输出干净的 HTML + SVG。
💡 详细介绍: 受够了 Mermaid 那种&quot;能看但丑&quot;的图表了吧？这个项目直接甩出 44 种图表类型，生成自包含的 HTML + SVG，没有阴影、没有花里胡哨的装饰，就是干净利落的编辑级设计。而且它专门适配了 Claude Code、Codex、GitHub Copilot、Cursor 等一众 AI 编程工具——意思是你在写代码的时候，AI 顺手就能给你画出专业级的架构图。Mermaid 的&quot;凑合能用&quot;时代该结束了。
🔗 项目网址: https://github.com/cathrynlavery/diagram-design
✨ Star 数量: 49,076
⭐ 推荐指数: ⭐⭐⭐⭐⭐（程序员画图痛点终结者，星数实至名归）

mksglu/context-mode

🎯 一句话概括: AI 编程 Agent 的上下文窗口优化器，工具输出减少 98%，还能跨平台记忆。
💡 详细介绍: 用 AI 写代码的人都知道，上下文窗口就是命根子——一不小心就被工具输出塞满了，然后 Agent 就开始胡言乱语。context-mode 干的事情很直接：把工具输出丢进沙箱处理，体积直接砍掉 98%；同时持久化会话记忆，让你换个平台继续干活时不用从头解释。支持 17 个平台，通过 MCP + hooks 做路由。简单说，就是给你的 AI 助手装了个&quot;记忆外挂&quot;和&quot;瘦身滤镜&quot;。
🔗 项目网址: https://github.com/mksglu/context-mode
✨ Star 数量: 26,372
⭐ 推荐指数: ⭐⭐⭐⭐（AI 编程重度用户必备，轻量用户可能感知不强）

mattpocock/skills

🎯 一句话概括: 来自真实工程师的 .agents 目录技能合集。
💡 详细介绍: 这个项目星数直接飙到 28 万，什么概念？说明大家都受够了&quot;AI 编程助手看起来很聪明但实际很蠢&quot;的现状。作者 Matt Pocock 是 TypeScript 圈的名人，他直接把自己 `.agents` 目录里的技能配置开源了——不是理论，不是教程，就是实打实在用的东西。Shell 写的，轻量、直接、可复制。如果你在用 AI 写代码但总觉得差口气，这里可能有你缺的那块拼图。
🔗 项目网址: https://github.com/mattpocock/skills
✨ Star 数量: 284,661
⭐ 推荐指数: ⭐⭐⭐⭐⭐（星数就是最好的推荐语）

flutter/flutter

🎯 一句话概括: Google 的跨平台 UI 框架，一套代码构建移动端和更多平台的应用。
💡 详细介绍: Flutter 还需要介绍吗？Dart 语言、自绘引擎、热重载、一套代码跑遍 iOS/Android/Web/桌面。虽然这几年争议不少（比如 Dart 的学习曲线、包体积问题），但它的开发效率和 UI 一致性依然是跨平台方案里的第一梯队。这次上榜大概率是因为某个新版本或者新特性，但对于还没入坑的人来说——如果你受够了 React Native 的桥接问题和原生开发的重复劳动，Flutter 依然值得一试。
🔗 项目网址: https://github.com/flutter/flutter
✨ Star 数量: 179,569
⭐ 推荐指数: ⭐⭐⭐⭐⭐（跨平台开发常青树，入坑不亏）

tensorflow/tensorflow

🎯 一句话概括: Google 的开源机器学习框架，人人可用。
💡 详细介绍: TensorFlow 和 PyTorch 的&quot;框架之争&quot;已经持续好几年了，虽然 PyTorch 在学术界风头更劲，但 TensorFlow 在工业部署和生产环境依然有不可替代的地位——TF Serving、TF Lite、TF.js 这一整套生态不是白给的。C++ 核心 + Python 接口，性能和生产部署能力依然是它的护城河。上榜大概率是因为新版本发布或者某个重要更新。
🔗 项目网址: https://github.com/tensorflow/tensorflow
✨ Star 数量: 200,755
⭐ 推荐指数: ⭐⭐⭐⭐⭐（ML 领域基石之一，学不学另说，得知道）

hugohe3/ppt-master

🎯 一句话概括: AI 把文档或主题变成真正的原生 PowerPoint 演示文稿，带原生形状、转场、动画、图表和语音旁白。
💡 详细介绍: 市面上的 AI PPT 工具不少，但大多数生成的是&quot;网页版幻灯片&quot;或者&quot;图片堆砌&quot;，导出到 PowerPoint 里就原形毕露——没有原生形状、没有转场、没有动画，改都没法改。ppt-master 走的是另一条路：生成的是真正的 `.pptx` 文件，原生形状、原生转场、原生动画，图表和数据表按需生成，还能用演讲者备注生成语音旁白，甚至支持你自己的 `.pptx` 模板。Python 写的。简单说，就是让 AI 做出来的 PPT 不再是一坨截图。
🔗 项目网址: https://github.com/hugohe3/ppt-master
✨ Star 数量: 59,580
⭐ 推荐指数: ⭐⭐⭐⭐⭐（打工人刚需，星数说明一切）

pytorch/pytorch

🎯 一句话概括: Python 里的张量和动态神经网络，GPU 加速拉满。
💡 详细介绍: PyTorch 现在就是深度学习框架里的&quot;默认选项&quot;——学术界发论文用它，工业界做原型也用它。动态计算图让调试变得像写普通 Python 一样自然，GPU 加速和分布式训练支持都很成熟。TensorFlow 和 PyTorch 同时上榜，说明这两家还在持续较劲，但对用户来说，竞争是好事。如果你刚入门深度学习，PyTorch 依然是目前最友好的起点。
🔗 项目网址: https://github.com/pytorch/pytorch
✨ Star 数量: 104,167
⭐ 推荐指数: ⭐⭐⭐⭐⭐（深度学习入门首选，没有之一）
