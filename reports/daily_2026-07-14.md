# 今日 GitHub 狠活：AI 女友、交易机器人、剪映平替，还有反智障设计工具

各位技术老铁，又到了每日 GitHub 狠活时间。今天这份榜单堪称神仙打架：有开源版剪映、有会陪你打《我的世界》的 AI 女友、有能帮你薅羊毛的交易机器人，甚至还有专门教 AI 别写出智障代码的“反智障”工具。废话少说，直接上菜。

### OpenCut

- **一句话概括**：开源版剪映，让你告别“不付费就给你加水印”的噩梦。
- **详细介绍**：CapCut（剪映国际版）好用是好用，但人家是字节的，哪天想收费或者加广告，你只能干瞪眼。OpenCut 就是一群头铁老哥搞的开源替代品，用 TypeScript 重写，功能上对标剪映的核心剪辑能力。虽然目前还很年轻，但胜在自由——你可以在自己服务器上跑，不用担心哪天被“优化”掉。适合那些想自己掌控剪辑工具、或者对隐私有要求的硬核玩家。
- **项目网址**：https://github.com/OpenCut-app/OpenCut
- **Star 数量**：66,558
- **推荐指数**：⭐⭐⭐⭐（潜力股，但别指望现在就能完全替代剪映）

### Vibe-Trading

- **一句话概括**：你的私人交易机器人，帮你“感觉”市场情绪。
- **详细介绍**：翻译成人话就是：一个用 Python 写的 AI 交易助手。它不靠 K 线图玄学，而是通过分析新闻、社交媒体等“氛围感”数据，来判断市场情绪是亢奋还是恐慌，然后给出交易建议。当然，别指望它能让你一夜暴富——这玩意儿更多是辅助决策，帮你避免在大家疯狂追涨时冲进去接盘。适合那些想尝试量化交易，但又不想写复杂策略的散户。
- **项目网址**：https://github.com/HKUDS/Vibe-Trading
- **Star 数量**：21,804
- **推荐指数**：⭐⭐⭐（好玩，但投资有风险，亏了别找我）

### Airi

- **一句话概括**：自托管 AI 女友，能陪你聊天、打游戏，甚至玩《我的世界》。
- **详细介绍**：这玩意儿堪称二次元宅男的终极梦想。Airi 是一个完全自托管的 AI 伴侣，你可以把它当成一个“灵魂容器”，装上各种 waifu 人设。它不仅能实时语音聊天，还能接入《我的世界》和《异星工厂》这类游戏，陪你一起挖矿、打怪。支持 Web、macOS 和 Windows，部署起来也不算太难。当然，它的目标是达到 Neuro-sama（那个著名的 AI 主播）的水平，目前还在进化中。适合那些想要一个不会发脾气、不会嫌你菜的游戏搭子的老哥。
- **项目网址**：https://github.com/moeru-ai/airi
- **Star 数量**：41,907
- **推荐指数**：⭐⭐⭐⭐（技术宅的浪漫，但小心沉迷）

### Hallmark

- **一句话概括**：给你的 AI 代码助手装上“反智障”滤镜，让它别写出垃圾代码。
- **详细介绍**：如果你用过 AI 写代码，一定见过那种“看起来对，但实际是坨屎”的代码——比如一个简单的功能，AI 给你套了五层回调加三个设计模式。Hallmark 就是专治这种毛病的。它提供了一套设计规范，让 Claude Code、Cursor 等 AI 编码助手生成更干净、更符合人类直觉的代码。说白了，就是给 AI 加个“别装逼，好好写”的提示词。适合那些受够了 AI 写出“优雅但无用”代码的开发者。
- **项目网址**：https://github.com/Nutlope/hallmark
- **Star 数量**：5,194
- **推荐指数**：⭐⭐⭐（刚需，但还比较新，效果有待验证）

### Win11Debloat

- **一句话概括**：一键干掉 Windows 11 里的垃圾预装应用和广告。
- **详细介绍**：每次装完 Windows 11，看到那一堆 Cortana、Skype、Xbox 小广告，是不是血压就上来了？这个 PowerShell 脚本就是来帮你“减负”的。它能一键删除预装应用、禁用遥测（就是微软偷偷收集你数据的功能）、关掉各种烦人的广告推荐。支持 Windows 10 和 11，轻量、安全、可逆。适合每一个不想被微软当韭菜的 Windows 用户。
- **项目网址**：https://github.com/Raphire/Win11Debloat
- **Star 数量**：50,906
- **推荐指数**：⭐⭐⭐⭐⭐（装机必备，谁用谁知道）

### Graphify

- **一句话概括**：把你的代码、数据库、文档变成一张知识图谱，让 AI 能看懂你的整个项目。
- **详细介绍**：你是不是也有这种体验：一个项目写了半年，连自己都忘了某个函数是干嘛的？Graphify 就是来解决这个问题的。它能扫描你的整个代码库、数据库 Schema、Shell 脚本、甚至图片和视频，然后自动生成一张可查询的知识图谱。AI 助手（比如 Claude Code）就能基于这张图理解你的项目全貌，而不是只盯着你当前打开的那个文件。适合那些维护大型项目、或者接手别人烂代码的开发者。
- **项目网址**：https://github.com/Graphify-Labs/graphify
- **Star 数量**：84,796
- **推荐指数**：⭐⭐⭐⭐⭐（大型项目救星，但小项目可能有点杀鸡用牛刀）

- **项目网址**：https://github.com/hasaneyldrm/exercises-dataset

### Spec-Kit

- **一句话概括**：GitHub 官方出品的“先写文档再写代码”工具包。
- **详细介绍**：听说过“Spec-Driven Development（规范驱动开发）”吗？说白了就是“先想清楚再动手”。Spec-Kit 是 GitHub 官方推出的工具，帮你从规范文档开始，自动生成代码框架、测试用例，甚至 API 文档。它特别适合那种需要多人协作、或者对代码质量要求高的项目。当然，对大多数程序员来说，这可能意味着“又多了一个写文档的理由”——但说实话，这东西确实能减少后期改 bug 的时间。
- **项目网址**：https://github.com/github/spec-kit
- **Star 数量**：120,633
- **推荐指数**：⭐⭐⭐⭐（官方出品，质量有保证，但需要一定学习成本）

### Marketingskills

- **一句话概括**：教 AI 学会营销，让它帮你写文案、做 SEO、搞增长。
- **详细介绍**：你是不是也遇到过：让 AI 写个广告文案，结果它给你整出一篇学术论文？这个项目就是给 Claude Code 等 AI 助手装上“营销大脑”。它包含了一整套营销技能提示词，涵盖 CRO（转化率优化）、文案写作、SEO、数据分析和增长工程。简单说，你只要告诉 AI “我要卖这个产品”，它就能根据这套技能自动生成符合营销逻辑的内容。适合那些想用 AI 做营销，但懒得自己调 prompt 的运营和创业者。
- **项目网址**：https://github.com/coreyhaines31/marketingskills
