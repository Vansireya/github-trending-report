ai-job-search ★ 53,554
Python

一个跑在你本机上的 AI 求职框架，帮你评估岗位、改简历、写求职信、准备面试。

找工作时最痛苦的是什么？不是投简历，是每投一个岗位就得把简历重写一遍、求职信重新编一遍，仿佛在给不同的人讲同一个相亲故事。这个项目基于 Claude Code 构建，把“评估岗位匹配度 → 定制 CV → 写 cover letter → 面试彩排”整条链路自动化，而且强调<strong>跑在你自己的机器上</strong>，Fork 下来就是你的。翻译成人话：它不会把你的求职数据传上云，但会把你卷死同事的效率拉满。

Python

Claude Code 火了之后，野生插件满天飞，质量参差不齐，装错一个可能比不装还坑。这个仓库是官方下场做的“精选超市”，把靠谱的插件集中收编、统一管理。痛点很明确：<strong>生态一散，用户就懵</strong>。官方目录相当于给插件市场立了个“官方认证”的牌子，至少不用在 GitHub 里大海捞针式地试毒了。

开源的编码 Agent，TypeScript 写的。

一句话介绍，二十多万 Star，这反差本身就是今天的最大狠活。描述短得像高冷男神的个性签名，但数据说明一切——开源编码 Agent 这条赛道已经卷到“不用多说，代码见真章”的地步。它解决的核心痛点是：<strong>不想被某一家闭源编码助手锁死</strong>。开源意味着你能自己部署、自己改、自己审计，代价是你得自己承担它写崩代码的责任。

Cursor 作为 AI 编辑器里的当红炸子鸡，终于开始正经搞插件生态了。这个仓库既是<strong>规范文档</strong>也是<strong>官方插件样板间</strong>，告诉开发者“想给 Cursor 写插件，请按这个姿势来”。痛点在于：编辑器再强，也架不住用户各有各的怪需求，开放插件是唯一出路。对开发者来说，这是一张通往 Cursor 生态的入场券；对普通用户来说，这意味着以后 Cursor 能干的活会越来越多。

ruflo ★ 76,586
TypeScript

号称“原版 Agent 挽具”，用来部署多智能体蜂群、编排自主工作流、搭建对话式 AI 系统。

描述里塞满了 buzzword——自适应记忆、自学习智能、联邦、向量 RAG 集成，还宣称原生支持 Claude Code / Codex / Hermes 等一大堆。翻译一下：它想当<strong>多 Agent 协作的总调度台</strong>，让一堆 AI 打工人组队干活而不是单打独斗。痛点是真的存在：单个 Agent 能力有限，多 Agent 协作又极易乱成一锅粥。至于它是不是真能当“蜂群指挥官”，建议先小规模试毒，别一上来就放一窝蜂。

ai-memory ★ 10,562
Rust

给编码 Agent 用的长期记忆方案，还能在不同 Agent 厂商之间做交接。

所有编码 Agent 都有同一个失忆症：<strong>关掉会话，前功尽弃</strong>。你昨天跟它讲清楚的架构约定，今天开新窗口它全忘了，你得再讲一遍，像极了每天重新培训新实习生。这个用 Rust 写的项目专治此病，提供长期记忆层，还支持跨厂商 handoff——Claude Code 干到一半，换 Codex 接着干，记忆不断档。Rust 加持意味着性能不拖后腿，属于那种“用了就回不去”的基础设施型项目。

orca ★ 96,817
TypeScript

一个管理“Agent 舰队”的工作台，桌面、移动、远程运行时都能跑，用你自己的订阅跑任意编码 Agent。

当一个人同时开着 Claude Code、Grok Bot 和一堆别的 Agent 时，混乱就开始了：谁在干什么？哪个跑完了？哪个卡住了？Orca 想当这个<strong>舰队司令塔</strong>，把多个 Agent 统一纳管。最讨喜的一点是“用你自己的订阅”——不搞二次收费那套。痛点精准打击多 Agent 玩家的管理焦虑，毕竟养一支 AI 舰队容易，指挥一支 AI 舰队难。

Python

港大数据智能实验室出品，目标是“让所有软件都变成 Agent 原生”。

口号喊得很响——“Making ALL Software Agent-Native”。核心思路是给各种软件套上 CLI 层，让 AI Agent 能像人类敲命令一样操作它们。痛点在于：<strong>世界上绝大多数软件压根没考虑过被 AI 调用</strong>，Agent 想干活只能靠截图点鼠标，又慢又脆。CLI-Anything 想用命令行这层“通用接口”把老软件们集体接入 Agent 时代。野心很大，配套还有 CLI-Hub 站点，学术团队出品，值得围观。
