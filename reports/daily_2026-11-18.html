Agent 技能包与工作流工具集中出现

今天榜单几乎被 Agent 技能包和配套工具占满，从安全测试、选题调研到代码审查、工作流编排，都在把 Claude Code 这类编码代理往更具体的专业场景里推。最值得看的是 Claude-BugHunter 和 last30days-skill：前者把漏洞挖掘方法论拆成 82 个技能，后者用 Reddit、X、Polymarket 的投票和真金白银给话题排序。

1
elementalsouls/Claude-BugHunter ★ 9,708
Python

给 Claude Code 装上一整套漏洞挖掘技能包，82 个技能、15 个斜杠命令，覆盖 24 类漏洞。

它把五阶段方法论、红队思维和 681 条已披露报告模式打包成可安装的技能，让代理在授权测试中按固定套路推进。局限在于效果高度依赖模型本身和测试范围，README 也强调只在授权场景使用。

2
mvanhorn/last30days-skill ★ 69,296
Python

一个按点赞、投票和真金白银排序的 AI 调研技能，横跨 Reddit、X、YouTube、HN 和 Polymarket。

适合快速摸清某个话题最近 30 天的真实热度，而不是靠编辑推荐。零配置就能跑 Reddit、HN 和 Polymarket，但 X、YouTube 等源需要走一次安装向导，且排序逻辑天然偏向有互动数据的平台。

3
alibaba/open-code-review ★ 53,888
Go

阿里内部打磨两年的 AI 代码审查 CLI，用确定性管线加 LLM Agent 做行级评论。

它不只读 diff，还能让代理翻全文、搜代码库、看其他改动文件来补上下文，内置 NPE、线程安全、XSS、SQL 注入等多语言规则。README 称同模型下精度和 F1 高于通用代理，token 消耗约为九分之一，但需要自配模型端点。

4
Tencent/LoopForge ★ 3,431
Go

腾讯开源的编码代理交付工作台，把 CodeBuddy、Codex、Claude Code 塞进带人工审批的 SOP 里。

你在聊天里描述需求，Main Bot 开 Docker 沙箱、拉仓库、派角色、开 PR；跑顺的流程可以固化成带人工闸门的标准作业程序。适合团队重复交付，但前提是接受自托管和 Docker 沙箱这套基础设施。

5
dream-num/univer ★ 29,208
TypeScript

把表格、文档、协作和文件处理做成可嵌入的 Office SDK，人和 AI 代理都能操作。

它从开源 Sheets 和 Docs 起步，通过 Facade API 和事件把编辑能力接进你自己的产品，也留给代理调用。想自建 AI 办公界面的人可以看，但完整 Office 能力涉及商业授权范围，需要先分清开源核心和 SDK 的边界。

6
getarcaneapp/arcane ★ 9,431
Go

一个面向所有人的现代 Docker 管理界面，Go 编写，主打自托管。

README 信息偏少，主要指向文档站和 SBOM，能确认的是它围绕 Compose 和容器管理做自托管面板。当前 main 分支已是 v3，功能请求迁到了 Discussions，适合想替代 Portainer 类工具的人先看文档再决定。

7
google-labs-code/stitch-skills ★ 10,181
TypeScript

Google Stitch 的代理技能库，按 Agent Skills 开放标准打包成设计、构建、工具三类插件。

它通过 Stitch MCP 服务器工作，可装进 Codex、Gemini CLI、Claude Code、Cursor 等代理，用插件市场或稀疏检出快速接入。适合把 UI 设计意图直接交给编码代理执行，但目前围绕 Stitch 生态，脱离该服务价值有限。

8
cursor/plugins ★ 16,963
TypeScript

Cursor 官方插件规范与首批官方插件，每个插件一个目录、一份 manifest。

仓库里能看到教学、持续学习、团队工具包、深度分支审查等插件，其中 Thermos 主打安全与正确性审计加并行子代理。它更像插件市场的样板间，价值在于示范插件怎么组织，而不是提供开箱即用的完整方案。

9
obra/superpowers ★ 319,488
Shell

一套给编码代理用的完整软件开发方法论，由可组合技能和初始指令构成。

它不让代理一上来就写代码，而是先逼出规格、分块确认设计、再生成连“没品味的初级工程师”都能执行的计划。覆盖 Claude Code、Codex、Cursor、Gemini CLI 等一长串宿主，适合想给代理立规矩的团队，但方法论本身需要人愿意跟着走。

今日结论

今天的信号很集中：大家不再满足于让代理“能聊”，而是给它装技能、定流程、加审批、接前端。真正稀缺的不是又一个技能包，而是像 AG-UI 这样让代理和界面说同一种话的底层约定。
