# 今日 GitHub 狠活：ADHD 拯救者、AI 炒股天团，还有 28 万星的"超能力"

> 今天的 Trending 榜单堪称"AI 焦虑与人类救赎"的混合体——有人教你让 AI 说人话，有人让 AI 帮你盖楼、画图、炒股，还有人干脆把系统设计面试答案整理好了。话不多说，上菜。


### ayghri/i-have-adhd

**一句话概括：** 让 AI 编程助手别再"先讲三段废话再给答案"的输出矫正器。

**详细介绍：** 你有没有这种经历——问 AI 一个 bug 怎么修，它先给你来一段"这是一个很好的问题"，再铺垫 200 字背景，最后答案埋在第七段。这个项目就是治这个的：它给 coding agent 装上一个"ADHD 模式"，强制它把结论甩你脸上，别绕圈子。3.4 万星说明什么？说明全世界的程序员都被 AI 的"话痨病"折磨得不轻。

**项目网址：** https://github.com/ayghri/i-have-adhd

**Star 数量：** 34,877

**推荐指数：** ⭐⭐⭐⭐⭐（痛点精准，疗效显著，程序员的电子 ADHD 药）


### Tencent/teamai-cli

**一句话概括：** 腾讯出品的命令行工具，目标是让每个团队都变成"AI 原生团队"。

**详细介绍：** 大厂出品，主打一个"团队级 AI 工作流"。不是让你一个人偷偷用 Copilot，而是把 AI 能力嵌进整个团队的协作流程里。TypeScript 写的，CLI 形态，听起来像是要把"AI Native"从口号变成日常操作。不过 3,080 星说明它还在早期，属于"潜力股观察区"。

**项目网址：** https://github.com/Tencent/teamai-cli

**Star 数量：** 3,080

**推荐指数：** ⭐⭐⭐（大厂背书值得关注，但生态成熟度待验证）


### obra/superpowers

**一句话概括：** 一套"真的能用"的 AI Agent 技能框架 + 软件开发方法论。

**详细介绍：** 28 万星。你没看错，28 万。这个数字本身就是一种行为艺术。它提供的不只是工具，而是一整套让 AI agent 真正干活的方法论——怎么拆任务、怎么调用技能、怎么保证输出质量。Shell 写的，说明它深入系统底层。如果你还在纠结"AI agent 到底怎么落地"，这个项目基本就是标准答案级别的存在。

**项目网址：** https://github.com/obra/superpowers

**Star 数量：** 284,074

**推荐指数：** ⭐⭐⭐⭐⭐（28 万星不是刷出来的，是刚需堆出来的）


### pascalorg/editor

**一句话概括：** 开源 3D 建筑编辑器，带本地 CLI 和 MCP 工具，人和 AI 都能用。

**详细介绍：** 想盖房子但不会用 CAD？想画 3D 图但不想学 Blender？这个项目把 3D 建筑编辑做成了"人和 AI 协作"的形态——你描述，AI 建模，本地 CLI 跑流程，MCP 工具做集成。2.2 万星说明"AI + 建筑设计"这个交叉领域正在被认真对待，不只是玩具。

**项目网址：** https://github.com/pascalorg/editor

**Star 数量：** 22,976

**推荐指数：** ⭐⭐⭐⭐（垂直领域硬核工具，建筑/设计从业者值得一试）


### earthtojake/text-to-cad

**一句话概括：** 用文字描述就能做 CAD/CAE/CAM 的 AI agent 技能库。

**详细介绍：** 制造业的朋友们注意了——这个项目试图把"画工程图"这件事变成"说话"。你描述一个零件，AI 帮你生成 CAD 模型，还能延伸到仿真（CAE）和加工（CAM）。1.5 万星说明工业界的 AI 化需求是真实存在的，而且很迫切。当然，目前大概率还停留在"辅助"阶段，别指望它直接给你造个发动机。

**项目网址：** https://github.com/earthtojake/text-to-cad

**Star 数量：** 15,073

**推荐指数：** ⭐⭐⭐⭐（工业 AI 化的探路者，制造业工程师的福音）


### cathrynlavery/diagram-design

**一句话概括：** 38 种编辑级图表模板，专为 Claude Code / Codex 等 AI 工具设计，拒绝 Mermaid 丑图。

**详细介绍：** 简介里那句"No Mermaid slop"（拒绝 Mermaid 垃圾）简直是说出了无数人的心声。Mermaid 画的图能用，但丑。这个项目提供 38 种自包含的 HTML + SVG 图表模板，无阴影、无花哨、编辑级审美，直接给 AI 编程工具用。3.6 万星证明：程序员也是有审美需求的，只是平时被迫妥协。

**项目网址：** https://github.com/cathrynlavery/diagram-design

**Star 数量：** 36,700

**推荐指数：** ⭐⭐⭐⭐⭐（审美即正义，Mermaid 受害者集体点赞）


### TauricResearch/TradingAgents

**一句话概括：** 多 Agent LLM 金融交易框架——让一群 AI 开会决定怎么炒股。

**详细介绍：** 10 万星。这个数字在金融类开源项目里堪称恐怖。它的思路是：不让一个 AI 拍脑袋做交易决策，而是让多个 LLM agent 扮演不同角色（分析师、交易员、风控），互相辩论后形成决策。听起来很美好，但友情提醒：AI 炒股亏了钱，你没法找它维权。

**项目网址：** https://github.com/TauricResearch/TradingAgents

**Star 数量：** 104,021

**推荐指数：** ⭐⭐⭐⭐⭐（10 万星的好奇心，但投资有风险，AI 也不例外）
