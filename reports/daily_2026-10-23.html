今日 GitHub 狠活：PHP 老当益壮，AI 摸鱼插件狂揽 17 万星

今天的榜单堪称"人间真实"——一边是 PHP 被念叨了二十年"要死"，一边默默攒下 4 万星；另一边，一个教你 AI 怎么"偷懒"的项目直接冲上 17 万星，看来"能少写一行是一行"是全人类的共同信仰。

1
php/php-src ★ 41,223
C

PHP 解释器本尊，就是那个"世界上最好的语言"的发动机。

每次有人喊"PHP 要凉了"，这个仓库的 commit 记录都会默默打脸。它解决的问题很简单——让你写的 `<?php echo "Hello World"; ?>` 能真的跑起来。别看它常被吐槽，全球多少网站的后端还指着它吃饭呢。C 语言写成，性能扎实，是 Web 开发老炮儿的集体回忆，也是新手入门的"必经之路"。想给 PHP 本体提 PR 的勇士，欢迎来战。

2
anthropics/knowledge-work-plugins ★ 31,677
Python

Anthropic 官方出的插件集，专给知识工作者在 Claude Cowork 里用。

你是不是也遇到过——买了个 AI 工具，结果发现它"啥都能聊，啥都干不利索"？这个仓库就是来解决这个尴尬的：Anthropic 亲自下场，把知识工作场景（文档、协作、分析之类）的插件开源出来，让你直接插上就能用，不用自己从零折腾 prompt 和工具链。官方出品，兼容性和维护性相对有保障，适合把 Claude 当生产力工具的知识打工人。

3
DietrichGebert/ponytail ★ 173,647
JavaScript

让你的 AI 编程助手"像全屋最懒的资深老开发一样思考"——最好的代码，是你根本没写的那行。

这个项目的哲学堪称一绝：与其让 AI 疯狂输出几百行代码，不如让它学会"能不加就不加、能复用就复用、能删就删"。它解决的是 AI 编程时代的新痛点——AI 写代码太快了，快到代码库分分钟变成屎山。ponytail 给 agent 灌输"资深摸鱼老哥"的思维模式，追求最小改动、最少新增。17 万星说明什么？说明大家都受够了 AI 的"过度热情"。懒，是一种高级的工程美德。

4
cloudflare/security-audit-skill ★ 39,743
JavaScript

Cloudflare 出的编码 agent 技能，做多阶段安全审计，结论机器可读、可独立验证。

安全审计这事儿，最怕的就是"报告写得天花乱坠，一验证全是误报"。这个 skill 的思路很 Cloudflare——分阶段审计，每个发现都能被独立验证，输出机器可读的结果，方便接进 CI/CD 流水线。对于想让 AI 帮忙做安全扫描、又怕被 AI 一本正经胡说八道的团队来说，这套"可验证"的设计就是定心丸。

5
Graphify-Labs/graphify ★ 133,072
Python

把任意代码库连同文档、SQL schema、配置和 PDF 一起，变成可查询的知识图谱。

接手一个祖传项目时，你是不是也想问"这坨代码到底谁调谁"？graphify 就是干这个的：本地确定性 AST 解析，把代码、文档、数据库结构全串成一张图，每条边都有解释，而且——注意这个卖点——不用向量数据库。它作为 `/graphify` skill 接入 Claude Code、Cursor、Codex、Gemini CLI，让 AI 助手真的"看懂"你的项目结构，而不是靠猜。13 万星，说明"读懂屎山"是刚需。

6
supabase/supabase ★ 113,528
TypeScript

基于 Postgres 的开发平台，给你一个专属数据库来搭 Web、移动端和 AI 应用。

Firebase 好用但锁死、还贵？Supabase 就是那个"开源版 Firebase"——底层是正儿八经的 Postgres，认证、存储、实时订阅、边缘函数一应俱全，数据还攥在你自己手里。对于想快速起项目又不想被云厂商绑死的开发者，这是目前最省心的选择之一。11 万星不是白来的，社区活跃度肉眼可见。

7
fastapi/fastapi ★ 103,819
Python

高性能、易上手、开发快、可直接上生产的 Python Web 框架。

写 Python 后端还在纠结 Flask 还是 Django？FastAPI 用类型注解 + 自动生成 OpenAPI 文档，把"写接口"和"写文档"这两件苦差事合并成一件。异步性能好，Pydantic 校验香，10 万星的老牌实力派。如果你要快速搭一个 AI 服务的 API 层，它基本是默认答案。

Claude Code 功能一堆，官方文档又长又干，很多人装了之后只会 `claude "帮我改个 bug"`。这个仓库把学习曲线掰弯了：图示 + 实例 + 复制即用的模板，从入门到进阶 agent 一条龙。4 万多星说明"看不懂官方文档"是普遍痛点，而"抄作业"永远是最快的成长方式。
