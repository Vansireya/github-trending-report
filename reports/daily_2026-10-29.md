# 给编码代理补上设计感与工作流

今天榜单几乎被“怎么让编码代理更好用”占满：JetBrains 亲自下场做代理式 IDE，而 obra/superpowers 用一套可组合技能把开发流程拆成可执行的步骤。真正有意思的分歧在于，有人想重做编辑器，有人只想给代理塞一本设计规范。


### JetBrains/thinkrail

**一句话概括**：JetBrains 做的代理式 IDE，把每个任务切成独立 git worktree 工作区，让代理并行干活不碰你的主检出。

**详细介绍**：打开任意 git 仓库即可切出带独立分支的工作区，代理在隔离环境里改代码，好的合并、差的删掉；完成的 workspace 会自动归到项目架子上。目前扩展能力还在路上，README 说下一步才让 IDE 按你的习惯自造工具。

**项目网址**：https://github.com/JetBrains/thinkrail

**Star 数量**：5,240


### elayadesign/ai-design-skills

**一句话概括**：给编码工具用的设计技能包，每个技能一个自包含文件夹，按需安装，不搞全家桶。

**详细介绍**：目前主打 landing-page-design：从提问、页面结构、转化文案到字体间距圆角动效一整套视觉系统。安装方式很土但通用——把 SKILL.md 塞进 Claude Code、Cursor、Codex 等工具读规则文件的位置。技能数量还少，胜在结构清楚。

**项目网址**：https://github.com/elayadesign/ai-design-skills

**Star 数量**：11,301


### obra/superpowers

**一句话概括**：把软件开发方法论拆成可组合技能，逼代理先问清你要什么，再分块给你看规格，最后才写代码。

**详细介绍**：它不急着让代理动手，而是先逼出一份规格、分短块让你签字，再生成连“没品味没判断力的初级工程师”都能执行的实施计划。覆盖 Claude Code、Codex、Cursor 等一长串工具，但本质是流程约束，代理是否老实遵守仍取决于模型。

**项目网址**：https://github.com/obra/superpowers

**Star 数量**：307,559


### HKUDS/DeepTutor

**一句话概括**：港大数据智能实验室的终身个性化辅导系统，多代理协作，带 CLI 和可插拔的学习工作区。

**详细介绍**：从 README 看迭代很密：模块化安装、块状笔记本、带旁白的视频课、可恢复的嵌入检查点。它面向的是长期学习路径而非单次问答，但功能面铺得很宽，实际辅导质量需要自己跑一轮才知道。

**项目网址**：https://github.com/HKUDS/DeepTutor

**Star 数量**：48,301


### macro-inc/macro

**一句话概括**：把邮件、聊天、文档、任务、代理、通话和 CRM 塞进一个界面，靠 @ 链接和共享 AI 记忆串起来。

**详细介绍**：团队约 15 人自用两年，用 SolidJS 和 Rust 重写，目标是让小公司不再靠 MCP 和 Zapier 把 Slack、Linear、Notion 粘在一起。野心很大，代价是你要把整个工作流搬进一个新产品，迁移成本不低。

**项目网址**：https://github.com/macro-inc/macro

**Star 数量**：5,491


### Nutlope/hallmark

**一句话概括**：反 AI 味的设计技能，从五十套主题里抽三套，再用真实浏览器 lint 那些一眼机器生成的痕迹。

**详细介绍**：它盯的是具体病症：每个标题上方的眉题、字距拉开的全大写标签、标题里一个彩色词、结尾必放的邮件订阅框。分 Floor、Reflex、Finish 三档门禁，Floor 直接不许发布。适合不想再看到紫蓝渐变的人，但主题库和规则仍在扩充。

**项目网址**：https://github.com/Nutlope/hallmark

**Star 数量**：40,902


### pbakaus/impeccable

**一句话概括**：给编码代理的设计词汇表：用 polish、bolder 调方向，用 critique、audit 做审查，赶在发布前拦住 AI 味。

**详细介绍**：同一个模型同一份需求，没有它会交出奶油色页面加细衬线加胶囊按钮的安全牌，有了它会围绕一张夜景照片重建页面。支持的工具列表长到夸张，但效果依赖代理是否认真执行这些指令词。

**项目网址**：https://github.com/pbakaus/impeccable

**Star 数量**：93,100


### makecindy/cindy

**一句话概括**：开箱即用的开源 AI 代理，把电脑和手机连成一台，会话、文件、模型订阅都能跨设备接着用。

**详细介绍**：手机端内置远程桌面，聊天不够时直接操作连着的电脑；模型共享让你用另一台机器上配好的订阅或本地模型。它把“你的电脑就是服务器”当卖点，省掉自托管，但前提是设备常在线且权限开对。

**项目网址**：https://github.com/makecindy/cindy

**Star 数量**：8,207


### nightly-labs/openbot

**一句话概括**：本地优先的桌面工作台，给每个 AI 队友独立工作区、任务队列、文件共享和嵌入式浏览器。

**详细介绍**：支持 Codex、Claude Code、Grok CLI 等一串代理，还能互相发消息协作。但 README 自己挂了警告：开发预览版，代理以 danger-full-access 和从不审批的策略运行，能读写文件、跑命令、控制浏览器。适合信任的任务，不适合生产环境。

**项目网址**：https://github.com/nightly-labs/openbot

**Star 数量**：3,360


### togg53192-cmd/jailbreaks

**一句话概括**：32 份面向 26 个以上模型的系统提示、人格锁定和工作区策略合集，号称每份都可直接粘贴。

**详细介绍**：覆盖开源权重家族和闭源前沿模型，也包含 AGENTS.md 和 Ollama Modelfile 格式。作者定位是研究指令层级、人格框架和策略覆盖如何影响模型行为，并明确警告仅供研究教育。这类仓库的价值在观察，不在照单全收。

**项目网址**：https://github.com/togg53192-cmd/jailbreaks

**Star 数量**：7,342


**今日总结**：今天最值得看的是设计技能这条线：hallmark 和 impeccable 都在用具体规则对抗模型的审美默认值，比再做一个代理框架更务实。至于重做 IDE 和重做工作台，先看它们能不能让人少切几次窗口。
