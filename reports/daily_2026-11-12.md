# Agent 技能与工具链集中涌现

今天榜单几乎被 AI 编码代理的配套工程占满，从设计系统、代码审计到浏览器操作，都在回答同一个问题：怎么让代理干活更靠谱。最值得先看的是 shadcn/improve 和 addyosmani/agent-skills，前者把“想清楚”和“动手写”拆给不同模型，后者把资深工程师的工作流固化成斜杠命令。


### meta/astryx

**一句话概括**：Meta 内部用了八年的设计系统开源，150+ 组件、品牌主题和暗色模式打包成一套，还特意声明对 AI 助手友好。

**详细介绍**：它基于 React 19+ 和 StyleX，导入预构建 CSS 就能用，不需要额外构建插件。比较特别的是“开放内部”：组件可逐层组合，swizzle 能把源码弹出到项目里自己改。目前处于 Beta，且与 StyleX 绑定较深，换技术栈前得想清楚。

**项目网址**：https://github.com/meta/astryx

**Star 数量**：25,372


### ZhuLinsen/daily_stock_analysis

**一句话概括**：给自选股做每日 AI 体检，覆盖 A 股、港股、美股等六个市场，结论直接推到企业微信或 Telegram。

**详细介绍**：它把行情、新闻、技术指标和基本面数据聚合起来，让 LLM 生成带评分、买卖点位和风险警报的决策仪表盘，还能用 GitHub Actions 零成本定时跑。但数据源依赖 AkShare、Tushare 等第三方接口，不同市场的能力边界并不一致，报告质量也受模型和提示词影响。

**项目网址**：https://github.com/ZhuLinsen/daily_stock_analysis

**Star 数量**：70,535


### GoogleChrome/modern-web-guidance-src

**一句话概括**：Chrome、Edge、Firefox 和 MDN 一起维护的“现代 Web 技能包”，专门纠正编码代理爱写老式 JavaScript 的毛病。

**详细介绍**：它把 Web 平台最佳实践和浏览器兼容数据嵌入代理，让代理优先用原生方案而不是堆砌旧模式。仓库本身是源码和评测仪表盘，不是直接可用的产品；想用需要按文档安装技能，效果也取决于代理是否遵循。

**项目网址**：https://github.com/GoogleChrome/modern-web-guidance-src

**Star 数量**：1,938


### shadcn/improve

**一句话概括**：让最贵的模型只做审计和写计划，把执行交给便宜模型，计划本身就是交付物。

**详细介绍**：在仓库里跑 /improve，它会扫描代码、给出发现列表，你挑几条让它写成 plans/ 下的 Markdown 计划，再派便宜模型在隔离 worktree 里执行并对照计划审查 diff。思路很清醒：智能用在判断上，体力活外包。限制是计划质量完全取决于审计模型，且合并仍需人工把关。

**项目网址**：https://github.com/shadcn/improve

**Star 数量**：11,086


### addyosmani/agent-skills

**一句话概括**：把资深工程师的九步工作流做成斜杠命令，从写规格到上线，每一步都卡住质量门。

**详细介绍**：命令覆盖 /spec、/plan、/build、/test、/review、/ship 等环节，每个命令自动激活对应技能，强调“先规格后代码”“小步原子任务”。它面向 Claude Code、Codex、Cursor 等支持 Agent Skills 的代理，安装后能减少手动串联步骤，但前提是团队认可这套流程，否则只是多了一层命令包装。

**项目网址**：https://github.com/addyosmani/agent-skills

**Star 数量**：116,087


### vercel-labs/agent-browser

**一句话概括**：用 Rust 写的浏览器 CLI，把页面压成带 @e1 引用的可访问性树文本，让代理一条命令一步地操作网页。

**详细介绍**：代理先 snapshot 拿到元素引用，再点击或输入，然后重新 snapshot 确认结果，浏览器在命令之间保持打开。它支持 CSS、文本、XPath 和语义定位，点击失败会报错而不是假装成功。适合需要精细控制的自动化场景，但每一步都要往返 shell，复杂流程的编排成本不低。

**项目网址**：https://github.com/vercel-labs/agent-browser

**Star 数量**：50,003


### we-promise/sure

**一句话概括**：被放弃的 Maybe Finance 由社区接手，继续做可自托管的个人财务应用。

**详细介绍**：原团队烧了近百万美元后于 2023 年停摆并开源，这个 fork 想保住代码库并探索托管服务。它提供完整的个人财务功能，但作为社区维护项目，数据源和长期维护节奏是现实变量，适合愿意自己部署和折腾的用户。

**项目网址**：https://github.com/we-promise/sure

**Star 数量**：13,122


### homeassistant-ai/ha-mcp

**一句话概括**：把 Home Assistant 接进 Claude、ChatGPT 等助手，用自然语言配置和自动化智能家居。

**详细介绍**：推荐通过 HACS 安装集成，服务器在 Home Assistant 进程内运行，覆盖 OS、Supervised、Container 和 Core 全安装类型。设置需要管理员令牌并选择客户端连接方式。注意 v7.3.0 把 ha_config_set_yaml 移到了 beta，升级前得确认兼容性。

**项目网址**：https://github.com/homeassistant-ai/ha-mcp

**Star 数量**：7,481


### openai/codex-security

**一句话概括**：OpenAI 出的安全扫描 CLI 和 TypeScript SDK，找漏洞、验证、打补丁一条龙，还能接进 CI。

**详细介绍**：它支持扫描仓库、指定路径或 Git 变更，深度扫描会重复标准扫描并去重结果，还能验证候选发现、生成补丁、起草 SECURITY.md 和威胁模型。发现可以导出 SARIF/JSON/CSV 或同步到 Linear、Jira、GitHub。功能面很宽，但实际效果取决于规则和模型判断，适合作为安全流程的辅助而非唯一防线。

**项目网址**：https://github.com/openai/codex-security

**Star 数量**：11,882


### TheAlgorithms/Java

**一句话概括**：老牌算法教学仓库的 Java 版，所有实现以学习为目的，不追求生产级效率。

**详细介绍**：它覆盖数据结构与各类算法，适合刷题和教学参考，README 明确说实现可能比 Java 标准库低效。贡献门槛低，有 Hacktoberfest 标签，但正因如此代码质量参差，拿来直接用前最好自己过一遍。

**项目网址**：https://github.com/TheAlgorithms/Java

**Star 数量**：67,106


**今日总结**：今天最清晰的信号是：代理能力在往“流程化”和“可审查”走，而不是单纯堆模型。设计系统和安全扫描也在主动适配代理，值得留意的是这些工具都强调人类保留最终判断权。
