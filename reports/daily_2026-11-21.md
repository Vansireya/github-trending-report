# Agent 技能包与 CLI 化成为今日主线

今天榜单几乎被“让 Agent 更能干活”的工程化项目占满：Claude-BugHunter 把漏洞挖掘经验拆成 83 个技能，superpowers 则试图给编码 Agent 套上一整套开发方法论。另一条线是 CLI-Anything，想把所有软件都包成 Agent 可调用的命令行入口。


### elementalsouls/Claude-BugHunter

**一句话概括**：把 681 份公开漏洞报告提炼成 83 个 Claude Code 技能，覆盖 24 类漏洞和红队攻击矩阵。

**详细介绍**：安装后 Claude Code 会按五阶段方法论引导漏洞挖掘，并内置 Burp MCP 集成和项目文件夹脚手架。局限在于它依赖 Claude Code 技能系统，且 README 强调需在授权范围内使用，公开训练平台之外的实际效果仍取决于使用者判断。

**项目网址**：https://github.com/elementalsouls/Claude-BugHunter

**Star 数量**：14,573


### obra/superpowers

**一句话概括**：一套给编码 Agent 用的完整软件开发方法论，从逼问需求开始，到拆解成初级工程师能执行的计划。

**详细介绍**：它不急着让 Agent 写代码，而是先让 Agent 反问用户到底要做什么，再把规格分块展示、确认设计后才出实施计划。支持 Claude Code、Codex、Cursor 等一长串宿主，但方法论本身是否比直接写代码更高效，取决于项目复杂度和用户耐心。

**项目网址**：https://github.com/obra/superpowers

**Star 数量**：322,953


### HKUDS/CLI-Anything

**一句话概括**：给任意软件套一层 CLI，让 AI Agent 能像人一样敲命令操作 CAD、3D 场景和图表工具。

**详细介绍**：项目提供 cli-hub 来浏览和安装社区构建的 CLI harness，目标是让 Pi、Cursor、Claude Code 等 Agent 直接调用软件产出真实工件。目前大量能力依赖社区提交的 CLI 封装，覆盖面和稳定性还在早期。

**项目网址**：https://github.com/HKUDS/CLI-Anything

**Star 数量**：61,507


### jingyaogong/minimind

**一句话概括**：用 3 块钱 GPU 租用费和 2 小时，从零训出一个 64M 参数的小语言模型，代码全部 PyTorch 原生实现。

**详细介绍**：它把预训练、SFT、LoRA、DPO、PPO/GRPO 到 Agentic RL 的完整链路摊开给你看，不依赖 transformers/trl 的高层封装。适合想理解 LLM 内部机制的人，但“2 小时”仅指单张 3090 上 SFT 一个 epoch，完整复现仍需按阶段投入。

**项目网址**：https://github.com/jingyaogong/minimind

**Star 数量**：67,778


### cursor/plugins

**一句话概括**：Cursor 官方插件规范与首批官方插件，每个插件是带 manifest 的独立目录。

**详细介绍**：仓库里能看到教学、持续学习、团队工具包、热核级分支审查等插件，其中 thermos 主打深度安全与正确性审计。它更像是 Cursor 插件生态的样板间，插件质量参差，且部分插件作者是个人而非官方。

**项目网址**：https://github.com/cursor/plugins

**Star 数量**：17,892


### firecrawl/firecrawl

**一句话概括**：把网站抓成干净 Markdown 喂给 Agent，本地单二进制跑，也能接云端 550+ 数据源。

**详细介绍**：Firecrawl Local 不需要数据库、队列或容器，装完就能当 MCP 服务器用；云端版则补上搜索和 Alexandria 数据提供方。自托管完整服务需要自己管队列和数据库，适合对数据落地有要求的团队。

**项目网址**：https://github.com/firecrawl/firecrawl

**Star 数量**：205,455


### nginx/nginx

**一句话概括**：NGINX 官方开源仓库，Web 服务器、负载均衡、反向代理和内容缓存的老牌底座。

**详细介绍**：README 面向新手，覆盖模块、配置、运行时和从源码构建的流程。它本身不解决 AI 时代的新问题，但任何 Agent 生成的服务最终仍可能落在它前面，属于基础设施里的常量。

**项目网址**：https://github.com/nginx/nginx

**Star 数量**：32,607


### openvinotoolkit/openvino

**一句话概括**：Intel 主导的推理优化工具包，把 PyTorch、TensorFlow、ONNX 等模型压到 CPU、GPU 和 NPU 上跑。

**详细介绍**：支持从边缘到云的部署，并能通过 Optimum Intel 直接拉 Hugging Face 上的 transformers 和 diffusers 模型。对非 Intel 硬件用户吸引力有限，但在 Intel 平台做生成式 AI 推理部署时是绕不开的选项。

**项目网址**：https://github.com/openvinotoolkit/openvino

**Star 数量**：11,818


### cathrynlavery/diagram-design

**一句话概括**：让 Agent 画编辑级图表，输出单个自包含 HTML+SVG 文件，明确拒绝 Mermaid 的默认审美。

**详细介绍**：支持 51 种图表类型，用户用自然语言描述架构、象限或时序图，Agent 选型后直接写文件。可导入品牌色和字体，但“无阴影、无 Mermaid 味”的风格偏好很强，适合对外分享的正式图表，不适合快速草图。

**项目网址**：https://github.com/cathrynlavery/diagram-design

**Star 数量**：69,385


### mvanhorn/last30days-skill

**一句话概括**：让 Agent 并行搜索 Reddit、X、YouTube、HN 和 Polymarket，按点赞和真金白银排序后合成摘要。

**详细介绍**：零配置即可跑 Reddit、HN、Polymarket 和 GitHub，设置向导再解锁 X、YouTube、TikTok 等来源。它把“最近 30 天”的舆论信号做成可复用的研究技能，但摘要质量受限于各平台数据可及性和排序权重。

**项目网址**：https://github.com/mvanhorn/last30days-skill

**Star 数量**：71,537


**今日总结**：今天最值得看的是 Agent 技能从“提示词合集”走向有结构、有安装方式的工程包；但技能越多，越考验使用者判断何时该让 Agent 停下来问一句。
