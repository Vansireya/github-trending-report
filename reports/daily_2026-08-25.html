今日 GitHub 狠活：AI 求职神器、开源 Jira 杀手，还有免费薅 Claude Code 羊毛！

各位老铁，今天的技术圈又炸了！GitHub Trending 上神仙打架，从免费白嫖 AI 编程助手到把罗技驱动按在地上摩擦的开源替代品，应有尽有。咱不整虚的，直接上菜，看看哪些项目值得你今晚熬夜 star。

Alishahryar1/free-claude-code

🎯 一句话概括: 一个让你在终端、App、IDE 甚至手机里免费白嫖 Claude Code、Codex 等 AI 编程助手的“羊毛收割机”。
💡 详细介绍: 这玩意儿解决的最大痛点就是“穷”。官方 Claude Code 按量收费，用起来肉疼。这个项目直接给你整了个聚合入口，号称有 13 亿+ 免费 token，还支持语音，最骚的是它说“ToS friendly”，意思是你不用担心被封号。虽然我怀疑它是不是靠某种“慈善家”API 中转，但程序员薅羊毛的智慧是无穷的，且用且珍惜。
🔗 项目网址: https://github.com/Alishahryar1/free-claude-code
✨ Star 数量: 48,974
⭐ 推荐指数: ★★★★☆（白嫖一时爽，一直白嫖一直爽，但稳定性存疑，扣一星）

openai/codex

🎯 一句话概括: OpenAI 官方出品的轻量级终端编程 Agent，让你的命令行直接化身“结对程序员”。
💡 详细介绍: 别再跟 IDE 里的 Copilot 大眼瞪小眼了。Codex 是那种“老派”的终端工具，你给它一个任务，它就在你眼皮底下改代码、跑测试、修 bug。它用 Rust 写的，启动快得飞起，资源占用低。对于喜欢在纯终端环境里折腾的极客来说，这玩意儿比那些笨重的 GUI 插件不知道高到哪里去了。这是 OpenAI 官方出品，不是野路子，质量有保障。
🔗 项目网址: https://github.com/openai/codex
✨ Star 数量: 117,042
⭐ 推荐指数: ★★★★★（官方出品，性能怪兽，终端党的终极浪漫）

MadsLorentzen/ai-job-search

🎯 一句话概括: 一个跑在你电脑上的 AI 求职管家，帮你筛选职位、定制简历、写求职信，甚至模拟面试。
💡 详细介绍: 找工作最烦的是什么？海投简历石沉大海，每家公司都要改一遍 CV，还要绞尽脑汁写 cover letter。这个项目基于 Claude Code 搭建了一个完整的求职框架，AI 会帮你分析职位描述，然后自动把你的简历往 JD 上“蹭”，还能生成针对性极强的求职信。最绝的是它还能帮你准备面试。这简直是社恐和懒人的福音，把“舔狗”式求职变成了“AI 代舔”。
🔗 项目网址: https://github.com/MadsLorentzen/ai-job-search
✨ Star 数量: 34,068
⭐ 推荐指数: ★★★★★（求职刚需，AI 赋能，效率提升不止一个档次）

multica-ai/andrej-karpathy-skills

🎯 一句话概括: 一份“咒语”文件，把 Andrej Karpathy 对 LLM 编程陷阱的观察总结成规则，让 Claude Code 少犯蠢。
💡 详细介绍: Karpathy 是谁？OpenAI 创始成员，特斯拉前 AI 总监，他说的话在 AI 圈就是“圣旨”。这个项目把他对 LLM 写代码时容易犯的错（比如过度自信、上下文丢失、改坏现有功能等）总结成了一份 `CLAUDE.md` 配置文件。你只要把这个文件丢给 Claude Code，它就能“继承”大神的经验，行为举止瞬间变得像个老练的程序员，而不是一个只会生成代码片段的新手。这属于“AI 炼丹”的秘方级项目。
🔗 项目网址: https://github.com/multica-ai/andrej-karpathy-skills
✨ Star 数量: 206,508
⭐ 推荐指数: ★★★★★（Karpathy 的“思想钢印”，谁用谁知道）

makeplane/plane

🎯 一句话概括: 开源界的 Jira 和 Linear 杀手，一个现代化的项目管理平台，管任务、管迭代、管文档一把梭。
💡 详细介绍: Jira 卡出翔，Linear 收费贵，ClickUp 功能太杂？Plane 就是那个“刚刚好”的替代品。它界面简洁现代，支持任务管理、Sprint 冲刺、文档协作和问题分类（Triage）。最爽的是它是开源的，你可以自己部署，数据完全私有，不用再看 SaaS 厂商的脸色。对于受够了商业软件折磨的团队来说，Plane 就是那味“解药”。
🔗 项目网址: https://github.com/makeplane/plane
✨ Star 数量: 57,928
⭐ 推荐指数: ★★★★★（开源之光，项目管理界的“爽文男主”）

AprilNEA/OpenLogi

🎯 一句话概括: 一个用 Rust 写的罗技 Options+ 开源替代品，本地优先，无账号无遥测，让你重新掌控自己的鼠标。
💡 详细介绍: 罗技的官方驱动软件 G Hub 和 Options+ 有多烂，用过的都知道——后台占用高、强制登录、偶尔还给你弹广告。OpenLogi 就是来“弑君”的。它通过 HID++ 协议直接跟鼠标通信，让你在本地就能改按键、调 DPI、设置 SmartShift。没有账户系统，没有遥测，干净得像个刚出厂的螺丝刀。对于罗技鼠标用户来说，这简直是救赎。
🔗 项目网址: https://github.com/AprilNEA/OpenLogi
✨ Star 数量: 15,861
⭐ 推荐指数: ★★★★☆（罗技用户的福音，但仅限罗技设备，受众稍窄）

apache/maka

🎯 一句话概括: Apache 基金会孵化的本地优先 AI Agent 工作区，把 AI 的每一次思考和行为都记录成不可篡改的日志。
💡 详细介绍: AI Agent 最让人不放心的是什么？黑盒操作，你不知道它为啥这么干。Maka 的方案是把模型消息、工具调用、结果、权限决策全部记录成一个 append-only 的日志。这意味着你可以像查数据库 binlog 一样回溯 AI 的每一个决策步骤，真正做到“可审计、可追溯”。对于企业级应用来说，这种透明度是刚需。Apache 背书，质量有保证。
🔗 项目网址: https://github.com/apache/maka
✨ Star 数量: 2,903
⭐ 推荐指数: ★★★★☆（企业级 AI 应用的“黑匣子”，刚起步但方向极佳）
