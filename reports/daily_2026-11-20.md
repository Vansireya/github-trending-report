# AI 代理技能包占据热榜，从漏洞挖掘到图表设计

今天的热榜几乎被 AI 代理技能包和工具链占满，从漏洞挖掘、开发方法论到图表生成，都在把 Claude Code 等代理变成更专业的执行者。最值得看的是 Claude-BugHunter 和 superpowers：前者把 681 份公开漏洞报告整理成可调用的技能，后者试图给编码代理一套完整的软件开发流程。


### elementalsouls/Claude-BugHunter

**一句话概括**：一个给 Claude Code 用的漏洞挖掘技能包，包含 83 个技能、15 个斜杠命令和 681 份公开漏洞报告模式。

**详细介绍**：它把漏洞挖掘拆成方法论、Web 应用狩猎、企业身份和基础设施攻击矩阵等层次，并集成 Burp MCP。适合授权红队和靶场练习，但实际效果取决于使用者对范围边界的把控。

**项目网址**：https://github.com/elementalsouls/Claude-BugHunter

**Star 数量**：12,823


### obra/superpowers

**一句话概括**：一套面向编码代理的软件开发方法论，用可组合技能让代理先问清需求再动手写代码。

**详细介绍**：它强调从对话中提炼规格、分块确认设计、再生成实施计划，而不是直接跳进编码。支持 Claude Code、Codex、Cursor 等多种宿主，但流程本身需要使用者愿意接受这种前置约束。

**项目网址**：https://github.com/obra/superpowers

**Star 数量**：322,231


### HKUDS/CLI-Anything

**一句话概括**：试图让所有软件都变成代理可调用的命令行工具，通过 CLI-Hub 安装和管理社区构建的 CLI。

**详细介绍**：项目提供 pip 安装的 hub，让代理通过生成的 CLI 操作 CAD、3D 场景、图表等软件。目前依赖社区贡献的 CLI 覆盖度，实际可用范围取决于已有哪些软件被适配。

**项目网址**：https://github.com/HKUDS/CLI-Anything

**Star 数量**：60,715


### jingyaogong/minimind

**一句话概括**：从零训练 64M 超小语言模型的完整开源项目，覆盖预训练、SFT、LoRA、RLHF 等全流程。

**详细介绍**：核心算法用原生 PyTorch 实现，不依赖高层抽象，适合想理解 LLM 内部机制的人。README 明确“2 小时”指单张 3090 跑完 SFT 一个 epoch，“3 块钱”是相应 GPU 租用成本。

**项目网址**：https://github.com/jingyaogong/minimind

**Star 数量**：67,092


### cursor/plugins

**一句话概括**：Cursor 官方插件仓库，包含插件规范和多个面向开发工具的官方插件。

**详细介绍**：每个插件是独立目录，带自己的 manifest，覆盖教学、持续学习、团队工具包、分支审查等场景。适合想给 Cursor 扩展代理工作流的团队参考插件结构。

**项目网址**：https://github.com/cursor/plugins

**Star 数量**：17,615


### firecrawl/firecrawl

**一句话概括**：把网站转成干净 Markdown 的知识基础设施，支持本地运行、云端服务和自托管三种方式。

**详细介绍**：本地版是单个二进制，无需数据库或队列，可作为 MCP 服务器接入代理；云端版额外提供搜索和 550+ 数据提供方。自托管则需要部署完整 API、队列和数据库。

**项目网址**：https://github.com/firecrawl/firecrawl

**Star 数量**：204,445


### nginx/nginx

**一句话概括**：NGINX 官方开源仓库，Web 服务器、负载均衡、反向代理和内容缓存的经典实现。

**详细介绍**：README 面向新手提供结构化介绍，涵盖模块、配置、运行时和从源码构建。对于需要稳定反向代理和负载均衡的场景，它仍是默认选项之一。

**项目网址**：https://github.com/nginx/nginx

**Star 数量**：32,388


### openvinotoolkit/openvino

**一句话概括**：英特尔主导的 AI 推理优化与部署工具包，支持从边缘到云端的多种硬件。

**详细介绍**：可转换和部署 PyTorch、TensorFlow、ONNX 等框架训练的模型，并针对 CPU、GPU 和 NPU 优化。适合需要在英特尔硬件上压缩推理资源占用的部署场景。

**项目网址**：https://github.com/openvinotoolkit/openvino

**Star 数量**：11,602


### cathrynlavery/diagram-design

**一句话概括**：一个代理技能，用自包含的 HTML + SVG 文件画编辑级图表，支持 51 种图表类型。

**详细介绍**：用户用自然语言描述需求，代理选择图表类型并生成单个 HTML 文件，可双击打开。明确反对 Mermaid 的默认样式，适合需要品牌一致性和精细排版的图表输出。

**项目网址**：https://github.com/cathrynlavery/diagram-design

**Star 数量**：68,781


### mvanhorn/last30days-skill

**一句话概括**：一个跨 Reddit、X、YouTube、HN 和 Polymarket 做主题研究的代理技能，按互动和真金白银排序。

**详细介绍**：零配置即可用 Reddit、HN、Polymarket 和 GitHub，运行一次后向导可解锁 X、YouTube、TikTok 等来源。它把点赞、上票和赔率当作信号，适合快速摸清一个话题近 30 天的真实热度。

**项目网址**：https://github.com/mvanhorn/last30days-skill

**Star 数量**：70,939


**今日总结**：今天的热榜说明代理技能包正在从“能聊天”走向“能干活”，但多数项目仍依赖特定宿主和社区覆盖度，选型时先看它约束了什么、又放开了什么。
