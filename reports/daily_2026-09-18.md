### alibaba/open-code-review

**一句话概括**：阿里内部打磨过的代码审查工具，把"确定性流水线"和"LLM Agent"缝在一起，专门在行级别挑你的刺。

**详细介绍**：代码审查这件事，人做太慢，纯 LLM 做又容易胡说八道。阿里这个项目的思路是"混合架构"——该用规则卡的地方绝不让大模型自由发挥，该让 LLM 理解上下文的地方也不硬编码。内置了 NPE、线程安全、XSS、SQL 注入等多语言规则集，还能给你精确到行的评论。兼容 OpenAI 和 Anthropic，不挑食。适合那种"CI 跑完还要等三天才有人 review"的团队。

**项目网址**：https://github.com/alibaba/open-code-review

**Star 数量**：35,016

**推荐指数**：⭐⭐⭐⭐⭐

### cloudflare/security-audit-skill

**一句话概括**：给编码 Agent 装上的"安全审计技能包"，多阶段扫描，结果可机器读取、可独立验证。

**详细介绍**：Cloudflare 出品，思路很清晰——与其让 AI 随口说"这里可能有漏洞"，不如把安全审计拆成多个阶段，每一步的发现都能被独立验证，输出机器可读的结果。翻译成人话就是：AI 报的漏洞，你得能复现，不能靠幻觉吓人。对于把 AI Agent 塞进 CI/CD 流水线的团队来说，这东西能省掉不少"狼来了"的噪音。

**项目网址**：https://github.com/cloudflare/security-audit-skill

**Star 数量**：10,813

**推荐指数**：⭐⭐⭐⭐

### addyosmani/agent-skills

**一句话概括**：给 AI 编码 Agent 准备的"生产级工程技能"合集，作者是 Google 的 Addy Osmani。

**详细介绍**：近 10 万 Star，说明大家真的很想让 AI Agent 别只会写"Hello World"。这个仓库本质上是把资深工程师的工程实践——代码规范、测试策略、重构手法、性能考量——打包成 Agent 能理解和执行的技能。你可以把它理解成"给 AI 补课用的教材"，只不过补的是软件工程而不是算法题。Addy Osmani 的招牌本身就是质量背书。

**项目网址**：https://github.com/addyosmani/agent-skills

**Star 数量**：95,902

**推荐指数**：⭐⭐⭐⭐⭐

### Tencent/BrowserSkill

**一句话概括**：让 AI Agent 直接用你已登录的真实浏览器干活，不用打断你手头的事。

**详细介绍**：自动化浏览器这事不新鲜，但痛点在于——要么你得开个干净的浏览器实例重新登录，要么 Agent 一操作你就没法用电脑了。腾讯这个项目用 CLI + 扩展的方式，让 Agent 接管你当前已登录的浏览器会话，而且不抢你的操作。对于需要 Agent 帮忙填表、抓数据、点按钮但又不想重新配置登录态的场景，这个思路很实用。前提是你信任 AI 用你的账号。

**项目网址**：https://github.com/Tencent/BrowserSkill

**Star 数量**：4,310

**推荐指数**：⭐⭐⭐⭐

### alphaXiv/OpenResearch

**一句话概括**：把编码 Agent 变成研究 Agent，让 AI 帮你查文献、做调研。

**详细介绍**：alphaXiv 团队做的工具，用 Rust 写的，性能上先赢一局。核心卖点是让本来只会写代码的 Agent 具备研究能力——检索、阅读、综合、引用。对于需要快速摸清一个技术领域现状的开发者来说，这相当于给 Agent 加了"读论文"的被动技能。当然，AI 读论文的幻觉问题依然存在，建议交叉验证。

**项目网址**：https://github.com/alphaXiv/OpenResearch

**Star 数量**：5,000

**推荐指数**：⭐⭐⭐⭐

### anthropics/claude-code

**一句话概括**：Anthropic 官方的终端 Agent 编码工具，用自然语言指挥它写代码、解释代码、处理 Git 流程。

**详细介绍**：14.5 万 Star，榜单里 Star 数最高的项目，没有之一。Claude Code 的定位很明确——住在你终端里的编码 Agent，理解你的代码库，执行日常任务，解释复杂逻辑，处理 Git 工作流。它不试图取代 IDE，而是成为命令行里的"结对程序员"。对于习惯终端工作流的开发者来说，这可能是目前最顺手的 Agent 编码工具。当然，前提是你得接受把代码库交给云端 LLM。

**项目网址**：https://github.com/anthropics/claude-code

**Star 数量**：145,910

**推荐指数**：⭐⭐⭐⭐⭐

### NationalSecurityAgency/ghidra

**一句话概括**：NSA 开源的软件逆向工程框架，安全研究员的瑞士军刀。

**详细介绍**：在一堆 AI Agent 工具里，Ghidra 显得格外"古典硬核"。这是美国国家安全局开源的逆向工程框架，支持反汇编、反编译、脚本扩展，功能强大到让商业逆向工具瑟瑟发抖。7.8 万 Star 说明安全社区对它爱得深沉。如果你需要分析二进制、研究恶意软件、或者单纯想看看编译后的代码长什么样，Ghidra 是绕不开的选择。NSA 出品，至少不用担心后门——毕竟人家本来就能看。

**项目网址**：https://github.com/NationalSecurityAgency/ghidra

### Tencent/WeKnora

**一句话概括**：腾讯开源的 LLM 知识平台，把原始文档变成可查询的 RAG、自主推理 Agent 和自维护 Wiki。

**详细介绍**：RAG 这个词已经被用烂了，但 WeKnora 的野心不止于此——它想做一个完整的知识管理闭环：文档进来，RAG 出去，Agent 负责推理，Wiki 负责自我维护。用 Go 写的，性能应该不差。对于需要把内部文档、知识库、技术资料变成"能问答的系统"的团队来说，这是一个开箱即用的方案。腾讯在 To B 场景的积累，让这个项目比很多玩具级 RAG 项目靠谱得多。

**项目网址**：https://github.com/Tencent/WeKnora

**Star 数量**：26,356

**推荐指数**：⭐⭐⭐⭐⭐

### abue-ammar/tinycast

**一句话概括**：一个极简、完全原生的 macOS 启动器，带热键和剪贴板历史。

**详细介绍**：在一堆 AI 和大数据项目里，tinycast 是一股清流——它就是个 macOS 启动器，原生 Swift 写的，小巧、快、不花哨。功能包括热键启动、剪贴板历史，定位是替代 Alfred 或 Raycast 的轻量选择。6 千多 Star 说明还是有人怀念"简单工具就该简单"的日子。如果你受够了 Electron 套壳的启动器吃你 500MB 内存，tinycast 值得一试。

**项目网址**：https://github.com/abue-ammar/tinycast

**Star 数量**：6,185
