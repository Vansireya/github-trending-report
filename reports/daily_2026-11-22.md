# Agent 技能包与工具链集中涌现

今天榜单几乎被 Agent 技能包和配套工具占据，从漏洞挖掘到软件开发方法论，再到把任意软件包装成 CLI。最值得看的是 Claude-BugHunter 把 681 份公开漏洞报告拆成可审计的技能模式，以及 superpowers 试图给编码 Agent 立一套完整开发流程。


### elementalsouls/Claude-BugHunter

**一句话概括**：把 681 份公开漏洞报告拆成 83 个技能和 15 个斜杠命令，让 Claude Code 按红队思路干活。

**详细介绍**：覆盖 24 类漏洞和身份、基础设施攻击矩阵，还带 Burp MCP 集成和项目文件夹脚手架。亮点是 433 条模式单独标注来源、可审计，但本质仍是辅助授权测试，不能替代人工判断。

**项目网址**：https://github.com/elementalsouls/Claude-BugHunter

**Star 数量**：16,279


### obra/superpowers

**一句话概括**：一套给编码 Agent 的完整开发方法论：先逼你讲清需求，再拆成可读的设计和实现计划。

**详细介绍**：它不急着写代码，而是让 Agent 先追问目标、分段确认规格，再产出连“没品味的初级工程师”都能执行的计划。支持 Claude Code、Codex、Cursor 等一长串宿主，但流程偏重，适合正经项目而非随手改两行。

**项目网址**：https://github.com/obra/superpowers

**Star 数量**：323,827


### HKUDS/CLI-Anything

**一句话概括**：给任意软件套一层 CLI，让 Agent 能像人一样点按钮、拉菜单、出 CAD 图和 3D 场景。

**详细介绍**：思路是“今天的软件服务人，明天的用户是 Agent”，通过生成 CLI harness 把图形界面操作转成命令行。配套 CLI-Hub 可浏览安装社区产物，但生成质量取决于具体软件，复杂 GUI 的覆盖度仍是现实瓶颈。

**项目网址**：https://github.com/HKUDS/CLI-Anything

**Star 数量**：62,166


### jingyaogong/minimind

**一句话概括**：3 块钱、2 小时，从零训出一个 64M 的小语言模型，代码全用 PyTorch 原生手写。

**详细介绍**：覆盖预训练、SFT、LoRA、DPO、PPO/GRPO 到 Agentic RL 的完整链路，还延伸出视觉和多模态版本。卖点是“不依赖 transformers/trl 高层封装”，适合想拆黑盒的人；但 64M 的规模注定只能学流程，别指望效果。

**项目网址**：https://github.com/jingyaogong/minimind

**Star 数量**：68,221


### cursor/plugins

**一句话概括**：Cursor 官方插件规范加一批现成插件，把教学、代码审查、分支审计都做成可安装技能。

**详细介绍**：每个插件是根目录下独立文件夹，带自己的 manifest。Thermos 做深度安全与正确性审计，continual-learning 用高信号要点增量更新 AGENTS.md。价值在于给出插件目录结构参考，但生态尚早，插件质量参差。

**项目网址**：https://github.com/cursor/plugins

**Star 数量**：18,146


### firecrawl/firecrawl

**一句话概括**：把网页变成干净 Markdown 喂给 Agent，本地一个二进制就能跑，还能接 550+ 数据源。

**详细介绍**：三种用法：本地单二进制带 MCP 服务、云端托管、完整自托管。本地版不需要数据库和队列，装起来要 Rust 和 C 编译器。真正差异在 Alexandria 数据源和搜索，但那是云端能力，自托管拿不到。

**项目网址**：https://github.com/firecrawl/firecrawl

**Star 数量**：206,340


### nginx/nginx

**一句话概括**：官方 NGINX 开源仓库，Web 服务器、负载均衡、反向代理、API 网关和内容缓存的老牌全能选手。

**详细介绍**：README 面向新手，讲清模块、配置、运行时和从源码构建的流程。它不需要多介绍，出现在榜单上更像基础设施的日常存在感；真正要留意的是稳定版与主线版的分支策略。

**项目网址**：https://github.com/nginx/nginx

**Star 数量**：32,760


### openvinotoolkit/openvino

**一句话概括**：Intel 的推理优化与部署工具包，把 PyTorch、ONNX、JAX 等模型压到 CPU、GPU 和 NPU 上跑。

**详细介绍**：支持从边缘到云的广泛平台，能直接接 Hugging Face 的 transformers 和 diffusers 模型。定位清晰：不是训练框架，而是部署端的转换与加速层；非 Intel 硬件用户收益有限。

**项目网址**：https://github.com/openvinotoolkit/openvino

**Star 数量**：11,961


### cathrynlavery/diagram-design

**一句话概括**：让 Agent 画 editorial 风格图表，输出单个自包含 HTML+SVG 文件，明确拒绝 Mermaid 味。

**详细介绍**：51 种图表类型，支持从你的网站抓取配色和字体，让每张图都贴合品牌。用自然语言描述即可，Agent 选类型、说计划、写文件。限制是风格取向强，不适合要严格数据保真的正式报表。

**项目网址**：https://github.com/cathrynlavery/diagram-design

**Star 数量**：69,871


### mvanhorn/last30days-skill

**一句话概括**：让 Agent 并行搜 Reddit、X、YouTube、HN 和 Polymarket，按点赞和真金白银排序再综合。

**详细介绍**：零配置即可用 Reddit、HN、Polymarket 和 GitHub，跑一次向导再解锁 X、YouTube、TikTok 等。核心卖点是“用注意力和钱包投票，而非编辑推荐”，但跨平台信号加权方式不透明，结论需自行交叉验证。

**项目网址**：https://github.com/mvanhorn/last30days-skill

**Star 数量**：72,107


**今日总结**：今天的主线不是模型本身，而是给 Agent 配工具箱和操作手册。技能包越堆越多，真正稀缺的是可审计的来源和克制的流程设计。
