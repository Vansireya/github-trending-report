今日 GitHub 狠活：AI 代理开始抢设计师、测试员和逆向工程师的饭碗了

2026 年某月某日 · 技术日报

各位打工人早上好，欢迎收看今天的 GitHub 热榜。今天这份榜单的含金量有点高——高到让人怀疑是不是所有开发者都在偷偷给 AI 代理造工具，好让自己能早点躺平。从端到端测试到 CAD 建模，从逆向工程到"专治 AI 啰嗦"的 ADHD 插件，今天的关键词只有一个：让 Agent 干活，我摸鱼。

话不多说，开始今天的狠活盘点。

1
tester-army/e2e ★ 6,481
TypeScript

下一代 Web 和移动端的端到端测试框架，让你的测试用例不再像考古现场。

端到端测试这件事，做过的人都知道有多痛——Selenium 慢得像在拨号上网，Cypress 偶尔抽风，Playwright 虽然好用但配置起来还是得写一堆样板代码。这个项目号称"下一代"，主打的就是让写 E2E 测试像写单元测试一样顺手。对于每天被 CI 流水线红叉折磨的 QA 和全栈工程师来说，这可能是本周最值得点 star 的项目。

2
mattpocock/skills ★ 278,274
Shell

一位资深工程师把自己 .agents 目录里的 AI 技能包开源了，号称"给真·工程师用的技能"。

Matt Pocock 是 TypeScript 圈的老熟人，这次他把自己日常用的 Agent 技能配置直接开源。所谓"Skills"，就是教 AI 代理怎么按你的规矩干活——怎么写代码、怎么 review、怎么不瞎猜。278K star 这个数字已经说明一切：大家苦"AI 代理乱来"久矣，与其自己从零调教，不如抄作业。

3
earthtojake/text-to-cad ★ 18,048
Python

给你的 AI 代理装上 CAD 超能力，说句话就能生成三维模型。

以前做 CAD 建模，你得在 SolidWorks 或 Fusion 360 里点几百下鼠标。现在这个项目让 Agent 直接理解你的自然语言描述，然后生成 CAD 文件。对硬件创业者、机械工程师、以及所有被"改个尺寸重新画一遍"折磨过的人来说，这简直是降维打击。当然，目前它生成的模型精度能不能直接上机床，还得你自己判断——别真拿它去造飞机。

4
boykopovar/AnyPS5 ★ 6,784
C++

自动把 PS5 游戏可执行文件移植到 Linux 和 Windows 的工具。

索尼独占游戏上 PC 这件事，官方做得慢吞吞，民间大神直接自己动手。这个工具瞄准的是 PS5 的可执行文件，试图自动化移植流程。虽然法律灰色地带明显（懂的都懂），但技术上的探索精神值得肯定。对于想在自己电脑上跑 PS5 游戏又不想等官方移植的玩家来说，这可能是条野路子——风险自负。

5
pbakaus/impeccable ★ 77,772
JavaScript

一套设计语言，专门教 AI 代理怎么做出不丑的界面。

AI 生成 UI 最大的问题是什么？丑。不是那种"有个性"的丑，是那种"字体用了三种、间距全靠猜、配色像打翻调色盘"的丑。这个项目提供了一套设计规范，让 AI 在生成界面时有个"审美准绳"。前端开发者和产品经理应该会很喜欢——毕竟谁也不想再收到"这个按钮再大一点、再小一点、再大一点"的反馈了。

6
thedotmack/claude-mem ★ 97,238
TypeScript

给 AI 代理装上"长期记忆"，跨会话记住它干过什么。

用过 Claude Code 或类似工具的人都知道，每次新开一个会话，AI 就像失忆了一样，之前聊过的上下文全没了。这个项目就是来解决这个问题的——它捕获代理在会话中的操作，用 AI 压缩成记忆，下次会话时再注入相关上下文。支持 Claude Code、Codex、Gemini、Copilot 等一大堆代理。简单说，就是让你的 AI 助手从"金鱼记忆"进化成"大象记忆"。

7
ayghri/i-have-adhd ★ 54,484
Python

一个让 AI 代理别废话、直接给答案的技能插件。

这个项目的名字起得绝了——"我有 ADHD"。它的作用是阻止你的编码代理把答案埋在长篇大论里。你有没有遇到过这种情况：问 AI 一个简单问题，它先给你写 500 字背景介绍，再写 300 字注意事项，最后才在角落里提一句"答案是 X"。这个插件就是治这个的——ADHD 友好输出，要的就是直给。54K star 说明被 AI 啰嗦折磨的人真的很多。

8
morluto/rea ★ 9,959
TypeScript

用 AI 代理逆向工程任何东西，从应用行为到原生二进制。

逆向工程一直是高门槛领域，需要懂汇编、懂调试器、懂各种玄学技巧。这个项目试图用 AI 代理来降低门槛——让它帮你分析应用行为、拆解二进制文件。对安全研究员、漏洞挖掘者和 CTF 选手来说，这可能是个强力助手。当然，逆向工程本身的法律和道德边界，使用者自己得拎清。

9
deepseek-ai/DeepGEMM ★ 8,745
Cuda

DeepSeek 开源的 GPU 上的高效 BLAS 内核库，干净又高效。

这是 DeepSeek 在底层计算库上的开源贡献。BLAS（基础线性代数子程序）是深度学习的基石，DeepGEMM 的目标是在 GPU 上提供干净、高效的实现。对于做模型训练和推理优化的工程师来说，这是实打实的底层工具。虽然 star 数在这份榜单里不算炸裂，但技术含量和长期价值不容小觑——毕竟 DeepSeek 出品，懂的都懂。
