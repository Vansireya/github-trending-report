mksglu/context-mode ★ 30,260
TypeScript

给 AI 编程 Agent 的上下文窗口做"瘦身"，号称减少 98% 的工具输出。

这个痛点太真实了——Agent 跑着跑着上下文就爆了，工具输出动辄几千 token，把宝贵的窗口塞得满满当当。context-mode 的做法是沙箱化工具输出、持久化会话记忆，再通过 MCP + hooks 在 17 个平台上做路由。98% 的削减率如果是真的，那确实香。TypeScript 写的，接入成本应该不高。适合那些被上下文长度折磨到怀疑人生的开发者。

元老级 Agent 框架，主打多智能体蜂群和自主工作流编排。

cursor/plugins ★ 11,991
TypeScript

Cursor 官方的插件规范和官方插件集合。

Cursor 作为 AI 编程编辑器里的当红炸子鸡，终于开始正经搞插件生态了。这个仓库提供插件规范和官方插件，意味着第三方开发者有了标准可循。痛点很直接：之前 Cursor 的扩展生态比较散，没有统一规范，现在官方出手定标准，对生态是好事。1.2 万星不算高，但考虑到 Cursor 用户基数，增长空间还很大。适合想给 Cursor 写插件的开发者关注。

今日总结

Agent 生态已经卷到令人发指的程度：官方下场定标准（Anthropic、Cursor、Android），第三方拼功能（ruflo、ECC），垂直领域做深耕（科学技能库、上下文优化）。星数动辄二三十万，但星数不等于好用——建议挑一两个真正对口你工作流的试试，别被数字冲昏头脑。

至于 VoiceStudio，是今天唯一一个能让你"耳朵怀孕"而不是"脑子爆炸"的项目，且用且珍惜。
