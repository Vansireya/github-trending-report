今日 GitHub 狠活：Agent 全家桶大乱斗，有人 30 万星，有人连简介都懒得写

今天的榜单只有一个主题：Agent 生态。从插件目录到技能库，从上下文优化到语音克隆，各路神仙都在抢着给 AI 装手脚。话不多说，开扒。

anthropics/claude-plugins-official

一句话概括：Anthropic 官方亲自下场的 Claude Code 插件精选目录。

详细介绍：官方认证，童叟无欺。市面上 Claude Code 插件已经多到让人选择困难，这个仓库就是官方帮你筛过一遍的"放心店"。痛点很明确——第三方插件质量参差不齐，装错一个可能比不装还糟。官方目录至少保证了基本盘，省去你踩坑的时间。当然，官方出品不代表每个都适合你，但作为起点，比在 GitHub 上瞎搜靠谱多了。

项目网址：https://github.com/anthropics/claude-plugins-official

Star 数量：40,654

推荐指数：⭐⭐⭐⭐

K-Dense-AI/scientific-agent-skills

一句话概括：把任何 AI Agent 改造成"AI 科学家"的技能库，号称 25 万科学家在用。

详细介绍：177 个开箱即用的验证过的技能，外加 100 多个科学数据库，覆盖生物、化学、医学、药物发现。听着很唬人，但仔细想想——"25 万科学家在用"这个数字，大概是把所有点过 star 的人都算进去了。不过话说回来，如果你真在做科研，这套东西确实能省不少事：不用自己从零搭 prompt，直接套用经过验证的技能模板。兼容 Cursor、Claude Code、Codex 等主流平台，覆盖面够广。

项目网址：https://github.com/K-Dense-AI/scientific-agent-skills

Star 数量：51,561

推荐指数：⭐⭐⭐⭐

affaan-m/ECC

一句话概括：Agent 性能优化系统，给 Claude Code、Codex、Cursor 们打鸡血。

详细介绍：28 万星，今天榜单第二。号称集技能、本能、记忆、安全、研究优先开发于一体。翻译成人话就是：让你的 AI 编程助手更聪明、记性更好、少犯傻。痛点在于，原生 Agent 往往"金鱼记忆"——聊两句就忘了前面说过什么，ECC 想解决的就是这个。不过 28 万星这个数字，建议你冷静看待，毕竟 star 数和实际好用程度之间，有时候隔着一个银河系。

项目网址：https://github.com/affaan-m/ECC

Star 数量：281,573

推荐指数：⭐⭐⭐⭐⭐

HKUDS/CLI-Anything

一句话概括：港大数据智能实验室出品，让所有软件都能被 Agent 原生调用。

详细介绍：名字起得很霸气——"CLI-Anything"，野心是让任何软件都变成 Agent 能操作的命令行工具。思路不新鲜，但港大这个团队执行力一向在线。痛点在于：大量传统软件没有 API，Agent 想用也用不了，CLI-Anything 试图用统一的方式把它们"翻译"给 Agent。配套还有个 CLI-Hub 站点，生态意识不错。能不能成另说，方向是对的。

项目网址：https://github.com/HKUDS/CLI-Anything

Star 数量：53,546

推荐指数：⭐⭐⭐⭐

mksglu/context-mode

一句话概括：给 AI 编程 Agent 的上下文窗口做"瘦身"，号称减少 98% 的工具输出。

详细介绍：这个痛点太真实了——Agent 跑着跑着上下文就爆了，工具输出动辄几千 token，把宝贵的窗口塞得满满当当。context-mode 的做法是沙箱化工具输出、持久化会话记忆，再通过 MCP + hooks 在 17 个平台上做路由。98% 的削减率如果是真的，那确实香。TypeScript 写的，接入成本应该不高。适合那些被上下文长度折磨到怀疑人生的开发者。

项目网址：https://github.com/mksglu/context-mode

Star 数量：30,260

推荐指数：⭐⭐⭐⭐

ruvnet/ruflo

一句话概括：元老级 Agent 框架，主打多智能体蜂群和自主工作流编排。

详细介绍：自称"the original agent harness"，口气不小。功能列表长得像菜单：多玩家蜂群部署、自主工作流协调、对话式 AI 系统、自适应记忆、自学习智能、联邦、向量 RAG 集成……还原生集成 Claude Code、Codex、Hermes 等。7.5 万星说明确实有一批死忠。但功能这么多，学习曲线大概率也不平缓，适合愿意折腾的团队，不适合想开箱即用的个人开发者。

项目网址：https://github.com/ruvnet/ruflo

Star 数量：75,660

推荐指数：⭐⭐⭐⭐

android/skills

一句话概括：Android 官方的技能仓库——连简介都懒得写。

详细介绍：对，你没看错，description 是空的。8 千多星，Kotlin 写的，挂着 android 官方名头。这种"高冷"作风要么是还没想好怎么介绍，要么是觉得"懂的都懂"。从命名推测，应该是给 Android 生态的 Agent 技能集合。建议先收藏观望，等官方把 README 补上再说。毕竟连一句话简介都不给的仓库，你很难指望它文档齐全。

项目网址：https://github.com/android/skills

Star 数量：8,102

推荐指数：⭐⭐⭐

obra/superpowers

一句话概括：一个"确实能用"的 Agent 技能框架和软件开发方法论。

详细介绍：30 万星，今天榜单的星数冠军。简介短得可怜，但"that works"三个字透着自信。Shell 写的，说明它更偏向于流程编排和工程实践，而不是花哨的功能堆砌。痛点在于：市面上 Agent 框架多如牛毛，但真正能落地到日常开发流程里的少之又少。superpowers 主打"方法论"，听起来像是给团队用的，而不只是给个人玩具项目用的。

项目网址：https://github.com/obra/superpowers

Star 数量：300,712

推荐指数：⭐⭐⭐⭐⭐

cursor/plugins

一句话概括：Cursor 官方的插件规范和官方插件集合。

详细介绍：Cursor 作为 AI 编程编辑器里的当红炸子鸡，终于开始正经搞插件生态了。这个仓库提供插件规范和官方插件，意味着第三方开发者有了标准可循。痛点很直接：之前 Cursor 的扩展生态比较散，没有统一规范，现在官方出手定标准，对生态是好事。1.2 万星不算高，但考虑到 Cursor 用户基数，增长空间还很大。适合想给 Cursor 写插件的开发者关注。

项目网址：https://github.com/cursor/plugins

Star 数量：11,991

推荐指数：⭐⭐⭐

debpalash/VoiceStudio

一句话概括：完全本地运行的开源 ElevenLabs 平替，语音克隆、配音、转录一条龙。

详细介绍：今天榜单里唯一一个不卷 Agent 的清流。ElevenLabs 好用但贵，VoiceStudio 直接给你一个本地跑的开源方案：语音克隆、语音设计、视频配音、听写、转录、有声书制作，支持 646 种语言。7 万星说明需求是真的旺盛。完全本地意味着隐私有保障，也不用担心按量计费。当然，本地跑的 quality 能不能追上云端服务，得自己试了才知道，但至少给了你一个不花钱的选择。

项目网址：https://github.com/debpalash/VoiceStudio

Star 数量：71,345

推荐指数：⭐⭐⭐⭐⭐

今日总结

Agent 生态已经卷到令人发指的程度：官方下场定标准（Anthropic、Cursor、Android），第三方拼功能（ruflo、ECC），垂直领域做深耕（科学技能库、上下文优化）。星数动辄二三十万，但星数不等于好用——建议挑一两个真正对口你工作流的试试，别被数字冲昏头脑。

至于 VoiceStudio，是今天唯一一个能让你"耳朵怀孕"而不是"脑子爆炸"的项目，且用且珍惜。
