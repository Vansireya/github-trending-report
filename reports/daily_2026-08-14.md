# 今日 GitHub 狠活：AI绘图、语音输入、以及一个让你查邮箱底裤的玩意儿

各位老铁，又到了每日GitHub宝藏挖掘时间。今天这份榜单堪称“冰火两重天”——一边是NVIDIA、Anthropic这些大厂在搞“基建狂魔”，另一边是各种让你本地跑模型、查邮箱隐私的“野路子”神器。废话不多说，直接上硬菜。

### cathrynlavery/diagram-design

**一句话概括**：给Claude Code用的29种“编辑级”图表模板，告别Mermaid那种“程序员审美”的辣眼图。

**详细介绍**：如果你受够了Mermaid生成的那些歪七扭八、配色堪比PPT灾难现场的图表，这个项目就是你的救星。它提供了29种自包含的HTML+SVG图表设计，纯前端、无依赖、无阴影，主打一个“干净利落”。这玩意儿解决的核心痛点是：AI生成的图表往往技术正确但审美为零。现在，你只需要把这些模板丢给Claude Code，它就能产出可以直接放进杂志或客户报告里的专业图表。说白了，这是给AI装上了一个“设计总监”的脑子。

**项目网址**：https://github.com/cathrynlavery/diagram-design

**Star 数量**：14,605

**推荐指数**：★★★★☆（审美救星，但只对Claude Code用户有奇效）

### semantica-agi/semantica

**一句话概括**：为“负责任AI”打造的图原生基础设施，让AI的“记忆”和“上下文”有据可查。

**详细介绍**：现在的AI动不动就“幻觉”，说瞎话不打草稿，根源在于它的上下文是混沌的。Semantica的思路很暴力：把AI的知识和记忆建立在图结构上，而不是线性文本流。这意味着每一段上下文、每一个决策路径都是可追溯、可验证的节点。对于需要严格合规审查的企业级AI应用来说，这玩意儿就是“免死金牌”。它解决的不是“能不能跑”的问题，而是“跑完怎么交代”的问题。

**项目网址**：https://github.com/semantica-agi/semantica

**Star 数量**：6,688

**推荐指数**：★★★★☆（企业级AI的定心丸，但学习曲线略陡）

**详细介绍**：这玩意儿就是Claude的“技能包商店”。你可以把它理解成给AI装插件——想让它会写代码、会做数据分析、会玩转某个特定API？直接从这个仓库里拉对应的技能模块就行。它解决了AI“什么都会一点，但什么都不精”的尴尬。现在，通过这个官方技能库，你可以像拼乐高一样给Agent组装专业能力。Star数高达16.9万，说明大家对于“让AI变得更专业”这件事，热情空前高涨。

**项目网址**：https://github.com/anthropics/skills

**Star 数量**：169,042

**推荐指数**：★★★★★（官方出品，必属精品，但别指望装了技能就能取代你上班）

### cactus-compute/needle

**一句话概括**：14MB的微型基础模型，让手机、手表、智能家居甚至机器人离线跑AI。

**详细介绍**：大模型虽好，但动辄几百GB的显存需求让移动设备只能干瞪眼。Needle这个项目直接把模型压缩到14MB，相当于一张高清照片的大小。这意味着你的智能门铃能本地识别陌生人了，你的手环能本地分析睡眠数据了，你的扫地机器人能本地规划路径了——而且全部离线，隐私安全拉满。它解决的是“AI下放到端侧”的最后一道坎：体积和功耗。虽然性能肯定不如大模型，但胜在“随时随地，有电就能跑”。

**项目网址**：https://github.com/cactus-compute/needle

**Star 数量**：4,962

**推荐指数**：★★★★☆（物联网开发者的新玩具，但别指望它写诗）

### altic-dev/FluidVoice

**一句话概括**：macOS上最快的本地听写应用，号称“Wispr Flow的本地平替”，且带AI增强。

**详细介绍**：受够了把录音传到云端等半天才出文字的尴尬？FluidVoice直接在本地完成语音转文字，速度飞快，还自带一个“自定义训练的AI增强模型”来提升准确率。它解决的是效率党和隐私党的共同痛点：既要快，又要不出门。目前只支持macOS，Windows和iOS还在排队，Linux“soon”（懂的都懂，这个soon可能比G胖的数3还久）。开发者说点Star能帮大忙，所以各位看着办。

**项目网址**：https://github.com/altic-dev/FluidVoice

**Star 数量**：9,858

**推荐指数**：★★★★☆（效率神器，但只对苹果用户友好）

### unslothai/unsloth

**一句话概括**：本地训练和运行大模型/扩散模型的“傻瓜式”UI，支持Qwen3、DeepSeek-V4、FLUX等一票主流模型。

**详细介绍**：以前想在本地跑个微调，你得敲一堆命令行，配环境配到怀疑人生。Unsloth把这个过程变成了“打开网页，点两下鼠标”的事。它自带一个漂亮的本地UI，让你能像用ChatGPT一样去训练和运行各种开源模型，包括但不限于Qwen、Kimi、Gemma、DeepSeek这些当红炸子鸡。它解决的是“技术门槛”问题，让不懂代码的文科生也能体验一把当“炼丹师”的快感。Star数7万多，说明“本地跑AI”确实是刚需。

**项目网址**：https://github.com/unslothai/unsloth

**Star 数量**：71,065

**推荐指数**：★★★★★（炼丹炉里的微波炉，即热即用）

### macro-inc/macro

**一句话概括**：用Rust写的“超级团队工作台”，把邮件、聊天、文档、任务、Agent、电话和CRM全部@链接在一起。

**详细介绍**：Macro试图干掉你电脑上所有乱七八糟的办公软件。它把邮件、聊天、文档、任务管理、AI助手、电话和客户关系管理全部塞进一个工作区，并且通过“@”符号实现万物互联。比如你在文档里@一个客户，就能直接调出他的历史邮件和通话记录。它解决的是“信息孤岛”问题——不用再在五个Tab之间来回切换找资料了。用Rust写的，性能应该很猛，但目前Star数不高，属于潜力股。

**项目网址**：https://github.com/macro-inc/macro

**Star 数量**：2,608

**推荐指数**：★★★☆☆（野心很大，但生态还没起来，观望为主）

### megadose/holehe

**一句话概括**：检查你的邮箱在哪些网站上注册过，一看一个准。

**详细介绍**：想知道你的邮箱有没有被拿去注册一些奇奇怪怪的网站？Holehe就是干这个的。它通过“忘记密码”功能，批量查询你的邮箱在Twitter、Instagram等数百个平台上的注册情况。这玩意儿简直是隐私自查神器，能让你发现自己到底在网上裸奔了多久。当然，这工具也能用来做“社工”，所以请务必用在合法用途，比如查查你对象的邮箱（开玩笑的，犯法）。

**项目网址**：https://github.com/megadose/holehe

**Star 数量**：12,432

**推荐指数**：★★★★☆（吃瓜神器，但请控制好你的好奇心）

### smicallef/spiderfoot

**一句话概括**：自动化OSINT工具，帮你绘制攻击面地图，做威胁情报分析。

**详细介绍**：如果说Holehe是“查户口”，那SpiderFoot就是“全息扫描”。它能自动收集来自数百个公开来源的情报，帮你摸清一个域名、IP或邮箱的“社交关系网”和潜在漏洞。对于安全工程师来说，这是做红队评估和攻击面管理的神器。它解决的是“信息收集靠手工，效率太低”的痛点。不过，这玩意儿威力巨大，请务必在授权范围内使用，否则后果自负。

**项目网址**：https://github.com/smicallef/spiderfoot
