morluto/rea ★ 211,926
TypeScript

让 AI Agent 帮你逆向工程一切，从 App 行为一路扒到原生二进制。

逆向工程这活儿，以前是少数硬核安全研究员的手艺活，门槛高到劝退。rea 的思路是把 AI Agent 拉进来当苦力——你想搞清楚某个 App 到底在干嘛、某个二进制里藏了什么逻辑，不用自己一行行啃汇编，让 Agent 去干。从应用层行为分析到底层 native binary 逆向，一条龙服务。当然，工具越强责任越大，请各位用在正道上，别拿去干坏事，不然律师函比 Star 涨得还快。

bilawalsidhu/gods-eye-view ★ 55,568
JavaScript

浏览器里的间谍卫星模拟器，但数据是真的——在逼真 3D 地球上做开源空间情报分析。

小时候玩 Google Earth 觉得自己是上帝，现在这个项目直接让你当情报局长。它把真实的开源空间数据叠加在一个照片级 3D 地球上，你可以像看间谍卫星画面一样浏览地球上的实时信息。痛点在哪？以前做地理空间情报分析得装一堆专业软件、搞一堆数据源，现在打开浏览器就行。当然，看完之后你可能会对"隐私"这个词有全新的理解。

debpalash/VoiceStudio ★ 63,653
Python

完全本地运行的开源版 ElevenLabs——声音克隆、语音设计、视频配音、听写、转录、有声书制作，支持 646 种语言。

ElevenLabs 好用是好用，但钱包是真的疼，而且你的声音数据还得传到别人服务器上。VoiceStudio 说：不用了，我自己来。全本地运行，声音克隆、配音、转录、有声书一条龙，646 种语言覆盖到你可能都没听说过的语种。对于做播客、视频配音、有声书的内容创作者来说，这玩意儿就是省钱利器。唯一的问题是：你克隆谁的声音，最好先取得对方同意。

mksglu/context-mode ★ 28,340
TypeScript

给 AI 编程 Agent 做上下文窗口优化——沙箱化工具输出（减少 98%）、持久化会话记忆、跨 17 个平台路由。

用 AI 写代码的人都懂那种痛：聊着聊着上下文窗口就爆了，Agent 开始胡言乱语，之前的记忆全丢了。context-mode 就是来解决这个"AI 金鱼记忆"问题的。它把工具输出丢进沙箱，直接砍掉 98% 的冗余信息，同时把会话记忆持久化保存，还通过 MCP + hooks 在 17 个平台上做路由。简单说，让你的 AI 编程助手从"七秒记忆"进化成"过目不忘"。

cathrynlavery/diagram-design ★ 54,333
HTML

为 Claude Code、Codex、Copilot、Cursor 等 AI 编程工具打造的编辑级图表设计系统，44 种图表类型，纯 HTML + SVG，拒绝 Mermaid 的丑陋。

用 Mermaid 画过图的人都知道，那玩意儿画出来的东西功能是有了，但丑得让人想关掉文档。diagram-design 就是来拯救审美的——44 种图表类型，输出自包含的 HTML + SVG，没有阴影、没有花里胡哨的装饰，就是干净的编辑级设计。而且它直接集成到各大 AI 编程工具里，让 AI 帮你画图的时候终于不用交出"程序员审美"的答卷了。Mermaid slop，退退退。

lyogavin/airllm ★ 38,397
Jupyter Notebook

用单张 4GB 显卡跑 2.8 万亿参数的大模型推理。

这个项目属于"物理定律？不存在的"系列。2.8T 参数的模型，正常来说得堆一整个机房的 GPU 才能跑起来，AirLLM 说：一张 4GB 显存的卡就够了。它的核心思路是分层加载 + 内存优化，把模型拆开一点点喂给 GPU，虽然推理速度肯定不会飞快，但"能跑"和"跑不了"之间隔着一整个数量级的成本差距。对于个人开发者和穷学生来说，这就是把大模型从云端拽到了自己的破笔记本上。

storytold/artcraft ★ 25,971
Rust

为艺术家、设计师和电影人打造的有意创作引擎。

市面上大部分创作工具都在追求"更快更多更自动化"，ArtCraft 反其道而行之，强调"intentional crafting"——有意图的创作。用 Rust 写的，性能不用担心。它想解决的是：当 AI 可以一键生成一切的时候，创作者如何保持对作品的掌控和意图？这个定位很文艺，也很叛逆。适合那些不想被 AI 牵着鼻子走、坚持"我才是创作者"的人。

xtool-org/xtool ★ 9,533
Swift

跨平台的 Xcode 替代品——在 Linux、Windows、macOS 上用 SwiftPM 构建和部署 iOS 应用。

苹果开发者最大的痛之一：想开发 iOS 应用？先买台 Mac。xtool 说：不用了。它让你在 Linux 和 Windows 上也能构建和部署 iOS 应用，用 SwiftPM 管理依赖，直接绕开了 Xcode 的垄断。虽然 9,533 的 Star 数在今天的榜单里显得有点"朴素"，但对于被苹果生态绑架的开发者来说，这个项目的意义远超数字本身。当然，苹果会不会哪天一个系统更新把它堵死，那就是另一个故事了。
