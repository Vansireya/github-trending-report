# Agent 技能生态正在成型

今天榜单上最显眼的是 Agent 技能与插件的基础设施化：Cursor 发布官方插件规范，NVIDIA 推出技能评估框架，Google 则把 Stitch 的设计能力拆成技能包。另一个值得注意的信号是 HKUDS/CLI-Anything 已冲到近 6 万星，试图用 CLI 把任意软件改造成 Agent 可调用的接口。


### cursor/plugins

**一句话概括**：Cursor 官方插件规范与示例合集，每个插件独立目录并带 manifest，相当于给 Agent 扩展能力定了个标准抽屉。

**详细介绍**：仓库里既有教学、持续学习这类通用技能，也有 Thermos 这种做深度安全审计和并行子代理的复杂插件。它更像规范样板而非开箱即用的市场，想直接拿来干活还得自己挑和配。

**项目网址**：https://github.com/cursor/plugins

**Star 数量**：17,302


### HKUDS/CLI-Anything

**一句话概括**：给任意软件套一层 CLI，让 AI Agent 能像人一样敲命令操作 CAD、3D 场景、字幕等工具。

**详细介绍**：思路是把软件能力封装成 Agent 可调用的命令行接口，再通过 CLI-Hub 分发社区构建的 CLI。覆盖面听起来很广，但实际效果取决于每个 CLI 封装的质量，目前更像一个正在快速铺开的生态倡议。

**项目网址**：https://github.com/HKUDS/CLI-Anything

**Star 数量**：59,943


### mvanhorn/last30days-skill

**一句话概括**：一个 Agent 技能，并行搜索 Reddit、X、YouTube、HN、Polymarket 等平台，用点赞和真金白银的赔率而非编辑偏好来排序信息。

**详细介绍**：适合快速摸清某个话题最近 30 天的舆论和资金信号。零配置就能跑 Reddit、HN、Polymarket 和 GitHub，但 X、YouTube、TikTok 等需要跑一次设置向导解锁，且摘要质量依赖各平台数据的可获取性。

**项目网址**：https://github.com/mvanhorn/last30days-skill

**Star 数量**：70,205


### getarcaneapp/arcane

**一句话概括**：用 Go 写的现代 Docker 管理面板，面向自托管场景，把容器和 Compose 的日常操作收进一个界面。

**详细介绍**：README 本身信息偏少，主要指向官方文档和 SBOM。从 topics 看它覆盖 compose、容器管理和自托管，适合不想纯靠命令行管 Docker 的人，但具体功能深度需要翻文档才能判断。

**项目网址**：https://github.com/getarcaneapp/arcane

**Star 数量**：9,902


### NVIDIA/SkillEvaluator

**一句话概括**：给 Agent 技能做质检的多层框架：静态规则、安全扫描、语义重叠检测，再到真实 Agent 运行对比，一条龙卡在合并前。

**详细介绍**：第一层靠 500 多条静态规则和检测模式，不需要 LLM key 就能跑；后两层才引入去重和实时 Agent 评估来量化技能带来的提升。它提供可复用的 CI 模板，适合想把技能质量门禁自动化的团队，但完整评估需要接 NVIDIA Build。

**项目网址**：https://github.com/NVIDIA/SkillEvaluator

**Star 数量**：3,832


### nvm-sh/nvm

**一句话概括**：老牌 Node 版本管理器，POSIX 兼容的 bash 脚本，靠 .nvmrc 和 shell 集成在多个 Node 版本间切换。

**详细介绍**：近 10 万星说明它仍是 Node 多版本场景的默认答案。功能列表很长，从 Docker 安装到离线安装、镜像加速都覆盖，但本质仍是 shell 脚本方案，Windows 原生支持不在其范围内。

**项目网址**：https://github.com/nvm-sh/nvm

**Star 数量**：96,176


### astral-sh/uv

**一句话概括**：Rust 写的 Python 包和项目管理器，号称一个工具替代 pip、pip-tools、pipx、poetry、pyenv 等一串。

**详细介绍**：亮点是 10 到 100 倍于 pip 的速度、通用锁文件、内联依赖脚本和 Cargo 风格 workspace。它已经不只是包安装器，而是在收拢整个 Python 项目工作流，对现有工具链的替代意图非常明显。

**项目网址**：https://github.com/astral-sh/uv

**Star 数量**：92,284


### google-research/paper-orchestra

**一句话概括**：Google Research 的多 Agent 论文写作框架，把想法和实验日志变成带文献综述和图表的 LaTeX 投稿稿。

**详细介绍**：流水线拆成大纲、文献综述、章节写作、内容精炼和绘图几个专职 Agent，覆盖从原始材料到成稿的完整链路。适合探索自动化写作的边界，但“投稿就绪”和实际学术质量之间还有很长的路。

**项目网址**：https://github.com/google-research/paper-orchestra

**Star 数量**：4,475


### google-labs-code/stitch-skills

**一句话概括**：Google Stitch 的 Agent 技能库，按开放标准拆成设计、构建、工具三组插件，可装进 Codex、Claude Code、Cursor 等。

**详细介绍**：安装方式以插件市场为主，Codex 支持 CLI 和 UI 两种路径，Claude Code 和 Cursor 也有对应说明，但 OpenCode 需要手动安装。它把设计工具能力模块化，方便按需组合，不过目前更像配套生态而非独立产品。

**项目网址**：https://github.com/google-labs-code/stitch-skills

**Star 数量**：10,474


### sveltejs/svelte

**一句话概括**：把声明式组件编译成高效 JavaScript 的 UI 框架，靠编译期优化直接外科手术式更新 DOM。

**详细介绍**：近 9 万星的老牌项目，README 保持极简，核心卖点仍是编译时消除运行时开销。在 Agent 技能刷屏的今天，它提醒人前端框架的竞争早已进入稳定期，拼的是生态和长期维护。

**项目网址**：https://github.com/sveltejs/svelte

**Star 数量**：89,666


**今日总结**：今天榜单的主线不是某个爆款应用，而是 Agent 技能从“能跑”走向“可评估、可分发、可组合”的基础设施层。值得留意的是，评估和规范类项目开始与技能本身同台竞争注意力。
