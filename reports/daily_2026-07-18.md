### ### protocolbuffers/protobuf

- **一句话概括**：Google 家的“数据快递协议”，让你的数据在不同语言间无缝传输。
- **详细介绍**：还在用 JSON 传数据？太慢了！Protobuf 是 Google 发明的序列化格式，比 JSON 快得多、体积小得多。它定义好数据结构，然后自动生成各种语言的代码，保证前后端、微服务之间数据格式统一。几乎所有大厂都在用。适合那些被 JSON 解析性能折磨到秃头的后端工程师。
- **项目网址**：https://github.com/protocolbuffers/protobuf
- **Star 数量**：71,541
- **推荐指数**：★★★★★（基础设施级别的项目，学不会？那你别干后端了）

### ### tirth8205/code-review-graph

- **一句话概括**：一个本地优先的代码知识图谱，让 AI 在 Code Review 时只读关键代码，不读无关的屎山。
- **详细介绍**：每次用 AI 做 Code Review，它都要把整个仓库读一遍，费时又费 token。Code Review Graph 能构建一个你代码库的持久化关系图，AI 只会读取与你改动相关的上下文。据说能减少 90% 的上下文加载量！适合那些代码库大到 AI 都读不完的大型项目。
- **项目网址**：https://github.com/tirth8205/code-review-graph
- **Star 数量**：19,767
- **推荐指数**：★★★★★（解决了一个真实痛点，而且 Star 数暴涨，说明大家被 AI 读代码的慢速搞疯了）
