AI 代理的记忆、浏览器与工作台

今天榜单几乎被 AI 代理基础设施占满：给代理补记忆的 claude-mem 冲到第一，用 Zig 重写无头浏览器的 Lightpanda 紧随其后。真正有意思的不是又一个聊天壳，而是大家开始认真修代理的“下半身”——记忆、执行环境、控制面板。

1
thedotmack/claude-mem ★ 109,566
TypeScript

给 Claude Code 等代理做跨会话记忆压缩，自动抓取工具调用观察并生成语义摘要，下次会话再注入。

它解决的是代理每次重连就失忆的老毛病：会话中记录工具使用观察，用 AI 压缩成摘要，未来会话按相关性取回。局限也明显，摘要本身会丢细节，且默认走托管记忆服务，本地观察者需要显式切换。

2
lightpanda-io/browser ★ 40,335
Zig

从零用 Zig 写的无头浏览器，不是 Chromium 分支，主打给 AI 代理和自动化用，比 Chromium 轻一个量级。

README 给出实测：100 个页面峰值内存 123MB 对 2GB，执行 5 秒对 46 秒。代价是它并非完整浏览器，兼容性和页面覆盖需要自己验证；Linux 二进制依赖 glibc，Alpine 这类 musl 发行版直接跑不起来。

3
shiyu-coder/Kronos ★ 45,495
Python

首个开源的金融 K 线基础模型，先把 OHLCV 量化成层级离散 token，再用自回归 Transformer 预训练。

训练数据覆盖 45 个以上全球交易所，论文已被 AAAI 2026 接收，还放出了微调脚本。金融数据高噪声，模型输出只能当参考信号，离实盘决策还有距离；仓库本身也没给交易策略或回测框架。

4
pingdotgg/t3code ★ 38,418
TypeScript

把本机上的编码代理统一收进一个控制面，配 iOS、Android、Web 和 Electron 桌面端。

前提是你已经装好并登录了 Codex、Claude Code、Cursor 等至少一个 CLI，它本身不提供模型。定位是“代理遥控器”而非新代理，适合多设备切换的人；没有描述文件，能力边界得自己读代码确认。

5
milind-soni/OpenMausBot ★ 10,714
TypeScript

开源版 Grok Bot 替代品：侧边栏每个 bot 都是本地跑的 Claude 或 Codex 代理，各有性格、模型和云电脑。

把代理当联系人聊天，能看它干活、审批关键动作，底层是 Docker 加 Electron/Expo 的本地优先架构。项目明确声明与任何加密货币无关，说明此前已被冒名发币；实际体验取决于本机代理配置。

6
public-apis/public-apis ★ 494,808
Python

社区手工维护的免费 API 大全，近 50 万星，按领域罗列可直接调用的公开接口。

老牌清单，价值在长期人工筛选而非自动抓取。但 README 顶部已被 APILayer 的推广内容占据，免费 API 的可用性也随时间漂移，用前最好逐个确认状态。

7
cjpais/Handy ★ 36,697
Rust

完全离线的开源语音转文字桌面应用，按快捷键说话，文字直接落进任意输入框。

用 Whisper 在本机转写，音频不出电脑，支持按住说话和点按切换两种模式，跨平台基于 Tauri。适合注重隐私的日常听写；离线意味着模型体积和首次加载成本要自己承担。

8
Donchitos/Claude-Code-Game-Studios ★ 32,485
Shell

把单次 Claude Code 会话改造成 49 个代理组成的游戏工作室，有总监、部门主管和一线执行的分层。

用角色分工和升级路径逼代理先写设计文档、过 QA、别硬编码魔法数。本质是提示词与工作流编排，产出偏文档和流程约束，游戏做得好不好仍取决于你的决策和代理能力。

9
kornia/kornia ★ 11,857
Python

基于 PyTorch 的可微计算机视觉库，1200 多个算子覆盖相机模型、对极几何、特征匹配和图像增强。

定位正从算子集合转向可微视觉的参考实现，强调显式约定、一致性测试和诚实基准。适合需要 GPU 批量几何运算又不想手写长函数的场景；算子多也意味着学习面广。

今日结论

代理的记忆、执行环境和遥控台正在同时被重做，这比再做一个聊天界面有价值得多。值得盯的是 Lightpanda 这种换底层语言的狠劲，以及 AiSOC 把代理决策记成可审计账本的思路。
