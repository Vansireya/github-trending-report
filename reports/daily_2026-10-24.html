Cloudflare 教 AI 查安全漏洞，紫微斗数排盘引擎上榜

1
cloudflare/security-audit-skill ★ 42,285
JavaScript

给 AI 编程助手装上一套"多阶段安全审计"技能包，让机器自动查漏洞并输出可验证的审计报告。

以前让 AI 帮忙做安全审计，它要么泛泛而谈"注意 SQL 注入哦"，要么一本正经地胡说八道。Cloudflare 这个项目把安全审计拆成多个阶段，要求 AI 产出的每一条发现都能被独立验证、机器可读——说白了就是给 AI 立规矩：别光动嘴，拿证据说话。对安全团队来说，这相当于请了个不知疲倦的初级审计员，虽然还得人复核，但至少初筛效率能起飞。

php/php-src ★ 41,582
C

PHP 解释器本尊，互联网半边天的底层发动机。

这就是 PHP 语言的核心源码仓库。你可能会问：这玩意儿还需要推荐？需要——因为它是"活化石级"的常青树。全球大量网站至今跑在 PHP 上，WordPress、Wikipedia、Facebook 早期都靠它。这个仓库不是让你去学的，是让你去敬畏的：41,582 个 Star 背后是二十多年的持续迭代。语言鄙视链顶端的朋友们，请对这位老同志保持基本尊重。

anthropics/knowledge-work-plugins ★ 32,269
Python

Anthropic 官方开源的插件库，专门给"知识工作者"在 Claude Cowork 里用。

知识工作者的日常是什么？整理文档、提炼纪要、跨文件找信息——全是重复劳动。这个仓库把这类场景做成了可插拔的插件，让你在 Claude 的协作环境里直接调用。Anthropic 亲自下场做插件生态，信号很明确：AI 助手不能只会聊天，得能干活。对天天泡在文档堆里的打工人来说，这算是官方发的"减负工具包"。

4
NVIDIA/OpenShell ★ 18,854
Rust

给自主 AI Agent 准备的"安全沙箱运行时"，让 AI 放开手脚干活又不至于把系统搞崩。

AI Agent 最大的尴尬是：能力越强，闯祸越狠。让它自主执行任务，它可能删错文件、跑飞脚本、泄露数据。OpenShell 就是来解决这个痛点的——提供一个安全、私密的运行时环境，把 Agent 关在笼子里放养。用 Rust 写的，性能和安全都照顾到了。NVIDIA 这步棋下得明白：Agent 要落地，先得让人敢用。

5
Renhuai123/ziwei-doushu ★ 6,918
TypeScript

紫微斗数开源排盘引擎，基于倪海厦《天纪》体系，算法、四化、格局、古籍原文一应俱全。

榜单里最"玄学"的一位，但人家是正经 TypeScript 写的。传统排盘软件要么收费、要么算法黑箱、要么数据残缺。这个项目把完整排盘算法、四化系统、格局知识库和古籍原文全部开源，等于把算命先生的手艺变成了可调用的 API。程序员研究命理、命理师学写代码，两个圈子在这仓库里握手言和。6,918 个 Star 说明：赛博算命，需求真实存在。

Python

OpenBMB/VoxCPM ★ 40,298
Python

VoxCPM2 无分词器 TTS 模型，主打多语言语音生成、创意音色设计和逼真声音克隆。

传统 TTS 依赖分词器，像给声音套了个"标准化模具"，出来的效果总差点意思。VoxCPM2 直接扔掉分词器，让模型端到端生成语音，多语言、音色设计、声音克隆一把抓。对做播客、有声书、游戏配音的开发者来说，这意味着更自然的合成效果和更自由的音色定制。40,298 个 Star 已经说明问题：语音合成赛道，卷得飞起。
