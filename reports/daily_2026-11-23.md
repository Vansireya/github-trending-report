# Agent 技能包开始接管安全、开发与绘图

今天榜单几乎被 Agent 技能包占满：Claude-BugHunter 把 681 份公开漏洞报告压缩成可调用的狩猎技能，superpowers 则试图让编码 Agent 先想清楚再动手。两者都指向同一件事——Agent 的竞争力正从模型能力转向技能编排。


### elementalsouls/Claude-BugHunter

**一句话概括**：把 82 个漏洞狩猎技能、15 个斜杠命令和 681 份披露报告模式打包进 Claude Code，让聊天机器人切换成红队操作员。

**详细介绍**：它按方法论、Web 应用狩猎、身份攻击、基础设施攻击四层组织技能，并强调保持授权范围。适合有明确授权目标的红队或漏洞赏金场景，但技能包本身不替代人工判断，报告模式的可审计性也只覆盖了 433 条。

**项目网址**：https://github.com/elementalsouls/Claude-BugHunter

**Star 数量**：18,192


### obra/superpowers

**一句话概括**：一套让编码 Agent 先追问需求、再拆实现计划的开发方法论，用可组合技能把“上来就写代码”的冲动按住。

**详细介绍**：它从启动编码 Agent 那一刻就介入，先逼出规格说明，再分块展示设计，最后生成连“没品味、没判断力”的初级工程师都能执行的计划。支持 Claude Code、Codex、Cursor 等一长串宿主，但方法论本身是否比模型能力更决定产出质量，仍需实际项目检验。

**项目网址**：https://github.com/obra/superpowers

**Star 数量**：324,310


### HKUDS/CLI-Anything

**一句话概括**：给任意软件套一层 CLI 外壳，让 AI Agent 能像人一样通过命令行操作 CAD、3D 场景和图表工具。

**详细介绍**：项目提供 cli-hub 来浏览和安装社区构建的 CLI，目标是让 Pi、OpenClaw、Cursor、Claude Code 等 Agent 直接调用。思路务实，但每个 CLI 的质量和覆盖度取决于社区贡献，实际可用性参差不齐。

**项目网址**：https://github.com/HKUDS/CLI-Anything

**Star 数量**：62,923


### jingyaogong/minimind

**一句话概括**：用 3 块钱 GPU 租用费和 2 小时，从零训出一个 64M 参数的超小语言模型，并把预训练到 RLHF 的全链路代码摊开给你看。

**详细介绍**：核心算法全部用 PyTorch 原生实现，不依赖高层抽象，覆盖 MoE、LoRA、DPO、PPO/GRPO、Tool Use 和 Agentic RL。适合想理解大模型内部机制的个人开发者，但 64M 的规模注定只能做教学和实验，别指望它替代任何生产模型。

**项目网址**：https://github.com/jingyaogong/minimind

**Star 数量**：68,884


### cursor/plugins

**一句话概括**：Cursor 官方插件规范加一批现成插件，从教学技能映射到“热核级”分支审查，试图把 Agent 工作流标准化。

**详细介绍**：每个插件是根目录下的独立目录，带自己的 plugin.json 清单。Thermos 插件主打深度安全与正确性审计、并行子 Agent 和可选的合并就绪 PR 流程。规范本身值得关注，但插件生态刚起步，实际覆盖的开发环节还有限。

**项目网址**：https://github.com/cursor/plugins

**Star 数量**：18,531


### firecrawl/firecrawl

**一句话概括**：把网站转成干净 Markdown 喂给 Agent，同时通过一个 API 接入 550 多个数据提供方，本地和云端两条路都留着。

**详细介绍**：Firecrawl Local 是单二进制，不需要数据库、队列或容器，装完就能在 localhost 提供 API 并作为 MCP 服务器接入 Agent；需要搜索或更多知识源时再连云端。自托管则要自己扛队列、worker 和数据库，适合对数据流向有要求的团队。

**项目网址**：https://github.com/firecrawl/firecrawl

**Star 数量**：207,192


### nginx/nginx

**一句话概括**：NGINX 官方开源仓库，Web 服务器、负载均衡、反向代理、API 网关和内容缓存的老牌全能选手。

**详细介绍**：README 定位是给新手的结构化入门，覆盖模块、配置、运行时、安装和从源码构建。它出现在趋势榜上更多是基础设施的惯性存在，而非新变化；真正要调优的人还是得翻完整文档。

**项目网址**：https://github.com/nginx/nginx

**Star 数量**：32,919


### openvinotoolkit/openvino

**一句话概括**：Intel 主导的推理优化与部署工具包，把 PyTorch、TensorFlow、ONNX 等模型压到 CPU、GPU 和 NPU 上跑。

**详细介绍**：支持从边缘到云的广泛平台，并能通过 Optimum Intel 直接接入 Hugging Face 上的 transformers 和 diffusers 模型。适合已经在 Intel 硬件上做部署的团队，但跨框架转换的兼容性细节仍需逐模型验证。

**项目网址**：https://github.com/openvinotoolkit/openvino

**Star 数量**：12,126


### cathrynlavery/diagram-design

**一句话概括**：一个 Agent 技能，用一句话让 Claude Code 或 Cursor 画出 52 种自包含 HTML+SVG 图表，明确拒绝 Mermaid 的粗糙感。

**详细介绍**：输出是单个 .html 文件，双击就能看，还能从你的网站抓取配色和字体来匹配品牌。适合需要快速出架构图、象限图或时序图的场景，但“编辑级设计”的审美判断仍依赖技能内置模板，复杂图表可能还是要手动收尾。

**项目网址**：https://github.com/cathrynlavery/diagram-design

**Star 数量**：70,435


### mvanhorn/last30days-skill

**一句话概括**：让 Agent 并行搜索 Reddit、X、YouTube、HN 和 Polymarket，用点赞、喜欢和真金白银的赔率给话题打分，而不是编辑偏好。

**详细介绍**：零配置即可跑通 Reddit、HN、Polymarket 和 GitHub，跑一次向导再解锁 X、YouTube、TikTok 等源。适合快速摸清一个话题过去 30 天的真实热度，但多源聚合的摘要质量取决于各平台数据的可获取性和噪声水平。

**项目网址**：https://github.com/mvanhorn/last30days-skill

**Star 数量**：72,891


**今日总结**：今天最值得看的是技能包的分层思路：Claude-BugHunter 把领域知识拆成可审计的技能，superpowers 把开发流程拆成可组合的步骤。Agent 的下一步竞争，大概率不在模型参数，而在这些技能包的组织方式。
