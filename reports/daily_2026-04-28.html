今日 GitHub 狠活：AI 打工人的花式摸鱼指南

今天这期狠活，全是帮你省心省力的骚操作——从白嫖 Claude 到自动挖代码知识图谱，从金融交易 AI 到黑客工具箱，总有一款能让你感叹“原来还能这样玩”。

mattpocock/skills

一句话概括：一个 TypeScript 老司机开的私房课，教你真正的“工程师技能”，直接从他本地 .claude 目录里扒出来的实战经验。

详细介绍：别被名字骗了，这不是什么无聊的“软技能”清单。这是 Matt Pocock（知名 TypeScript 博主）把他日常用 Claude Code 干活时的最佳实践、提示词模板、工作流配置，一股脑打包成了一份可复用的技能包。如果你还在为“AI 写出的代码总得改”而头疼，这玩意儿就是你的救星——它教你如何让 AI 从一开始就写出符合你风格、符合工程规范的东西，而不是一堆需要你擦屁股的垃圾。说白了，就是一份“如何调教 AI 帮你写代码”的终极秘籍。

项目网址：https://github.com/mattpocock/skills
Star 数量：30,766
推荐指数：★★★★★（对于想提升 AI 协作效率的开发者来说，这是必读圣经）

abhigyanpatwari/GitNexus

一句话概括：一个完全跑在浏览器里的代码知识图谱生成器，丢个 GitHub 仓库或 ZIP 文件进去，就能自动生成交互式知识图谱+内置 Graph RAG 智能问答。

详细介绍：想象一下，你接手一个屎山项目，代码几百万行，文档比你的前任还敷衍。GitNexus 就是你的救星——它把你的代码库变成一张可视化的“关系网”，谁调用了谁、哪个模块依赖哪个模块，一目了然。更骚的是，它内置了一个 Graph RAG（图检索增强生成）智能体，你可以直接问它“这个函数在哪里被调用了？”或者“为什么这个模块会报错？”，它会根据知识图谱给出精准答案。零服务器部署，纯前端，隐私安全，简直是代码考古学家的神器。

项目网址：https://github.com/abhigyanpatwari/GitNexus
Star 数量：31,638
推荐指数：★★★★★（代码重构、项目交接、新人入职，有这个省一半时间）

ComposioHQ/awesome-codex-skills

一句话概括：一个精选的 Codex 技能清单，帮你用 Claude Codex 自动化各种工作流，无论是 CLI 还是 API 都适用。

详细介绍：Claude Codex 很强，但很多人不知道怎么把它用出花来。这个项目就是一本“Codex 技能食谱”——从自动生成 commit 消息、自动部署、到自动修复 lint 错误、自动写单元测试，应有尽有。每个 skill 都是经过实战验证的，直接复制粘贴就能用。对于已经入了 Codex 坑的人来说，这就是你的“外挂库”；对于还没入坑的人，看完你会立刻想试试。

项目网址：https://github.com/ComposioHQ/awesome-codex-skills
Star 数量：2,886
推荐指数：★★★★☆（数量不多但质量极高，适合 Codex 重度用户）

Alishahryar1/free-claude-code

一句话概括：一个让你在终端、VSCode 扩展甚至 Discord 里免费使用 Claude Code 的“白嫖神器”。

详细介绍：Claude Code 是个好东西，但官方收费不便宜。这个项目就像个“破解版”——它让你绕过付费墙，在终端、VSCode 或者 Discord 里直接调用 Claude Code 的功能，而且完全免费。原理是用了类似 openclaw 的逆向工程，把 Claude 的 API 包装成了可本地调用的服务。对于学生党、个人开发者或者想先试试水再决定是否付费的人来说，这简直是天上掉馅饼。不过友情提示：白嫖有风险，且用且珍惜。

项目网址：https://github.com/Alishahryar1/free-claude-code
Star 数量：16,234
推荐指数：★★★★☆（实用，但稳定性未知，适合尝鲜）

gastownhall/beads

一句话概括：给你的 AI 编程助手装上“记忆芯片”，让它能记住上下文并智能决策。

详细介绍：现在的 AI 助手最大的痛点是什么？记性差！你跟它聊着聊着，它就忘了你十分钟前说过的需求。Beads 就是来解决这个问题的——它像一个“记忆升级包”，让你的 AI 编程助手（比如 Claude Code）能持久化地记住对话历史、项目上下文、甚至你个人的偏好。这样一来，你就不用每次都要重新解释一遍“我是谁，我在哪，我要做什么”。对于需要长期维护的项目或者复杂的多轮对话场景，这玩意儿简直是刚需。

项目网址：https://github.com/gastownhall/beads
Star 数量：22,233
推荐指数：★★★★★（解决 AI 助手的核心痛点，强烈推荐）

penpot/penpot

一句话概括：Figma 的开源平替，专为设计和开发协作而生，让你不再被 Adobe 收割。

详细介绍：如果你受够了 Figma 的收费套路，或者觉得 Sketch 只能在 Mac 上用太憋屈，Penpot 就是你的救星。它是一个完全开源、基于 Web 的设计工具，支持矢量设计、原型制作、组件库管理，而且原生支持 SVG 和 CSS，开发人员可以直接把设计稿的 CSS 代码复制出来用，不用再手动量像素。最骚的是，它支持多人实时协作，团队可以像 Google Docs 一样一起改设计稿。对于预算有限的中小团队或者开源项目来说，这简直是降维打击。

项目网址：https://github.com/penpot/penpot
Star 数量：46,666
推荐指数：★★★★★（开源设计工具的天花板，值得每个团队试试）

davila7/claude-code-templates

一句话概括：一个 CLI 工具，帮你配置和监控 Claude Code 的运行状态。

详细介绍：Claude Code 用起来爽，但配置起来烦——各种环境变量、API key、模型参数，每次都要手动调。这个工具就是来帮你解决这个痛点的：它提供了一个命令行界面，让你可以一键配置 Claude Code 的环境、设置常用的模板（比如代码审查模板、文档生成模板），还能实时监控它的运行日志和 token 消耗。对于需要频繁切换不同 Claude Code 配置的开发者来说，这能省下大量重复劳动。

项目网址：https://github.com/davila7/claude-code-templates
Star 数量：25,813
推荐指数：★★★★☆（实用工具，但依赖 Claude Code 生态）

microsoft/VibeVoice

一句话概括：微软开源的前沿语音 AI 模型，让你用声音和 AI 聊天，而不是打字。

详细介绍：微软这次终于不藏着掖着了，直接把前沿的语音 AI 模型开源了。VibeVoice 能实现低延迟、高自然度的语音交互——你说话它能实时理解并回复，而且语气、语调、情感都拿捏得死死的。想象一下，你对着电脑说“帮我写一封邮件给老板，语气要委婉但坚定”，它就能直接生成并朗读出来。对于语音助手、无障碍工具、或者单纯想解放双手的开发者来说，这是个宝藏。

项目网址：https://github.com/microsoft/VibeVoice
Star 数量：43,198
推荐指数：★★★★★（微软出品，质量保证，语音交互的未来）

Z4nzu/hackingtool

详细介绍：别被名字吓到，这其实是个合法的安全研究工具合集。它把常用的黑客工具（比如 nmap、sqlmap、hydra、Metasploit 等）整合到了一个统一的界面里，你不需要记住每个工具的命令行参数，只需要选个菜单就能执行。对于安全研究员、渗透测试工程师、或者网络安全爱好者来说，这能极大地提高工作效率。当然，你要是拿它干坏事，后果自负。

项目网址：https://github.com/Z4nzu/hackingtool
Star 数量：67,192
推荐指数：★★★★★（安全从业者的瑞士军刀，但请合法使用）
