今日 GitHub 狠活：用WiFi看穿墙壁，AI编程助手卷出新高度

大家好，我是你们的毒舌技术博主。今天这期 GitHub 热门项目，可以说是神仙打架、妖孽横行。有把WiFi信号变成透视眼的，有给AI编程助手开外挂的，还有教你从零手撕AI的硬核教程。废话不多说，直接开整。

anthropics/claude-plugins-official

🎯 一句话概括: Claude 官方插件市场，但全是 Anthropic 自己精挑细选的“亲儿子”。
💡 详细介绍: 你还在为 Claude 没有好用的插件而发愁？Anthropic 直接下场，给你整了一个官方认证的插件目录。这些插件都是经过 Anthropic 团队手把手调教过的，质量有保障，不会出现那种装了就让你 AI 助手当场智障的野鸡插件。解决了“插件太多不知道哪个靠谱”的痛点，毕竟官方背书比路边随便捡的强。
🔗 项目网址: https://github.com/anthropics/claude-plugins-official
✨ Star 数量: 25,063
⭐ 推荐指数: ★★★★☆（4星，官方出品，但插件数量还不够多，期待更多好货）

colbymchenry/codegraph

🎯 一句话概括: 给 AI 编程助手装一个本地知识图谱，让它们少问废话、多干活。
💡 详细介绍: 你是不是也觉得 Claude、Cursor 这些 AI 助手老是问一些弱智问题？比如“这个函数是干什么的？”明明代码就在眼前。CodeGraph 直接在本地把你整个代码库建一个知识图谱，AI 助手想查什么直接在图里搜，不用再去读一堆 token 浪费算力。简单说，就是给 AI 助手配了个“速查手册”，让它少翻书、多写代码。
🔗 项目网址: https://github.com/colbymchenry/codegraph
✨ Star 数量: 16,707
⭐ 推荐指数: ★★★★★（5星，解决核心痛点，效率提升肉眼可见）

ruvnet/RuView

🎯 一句话概括: 用 WiFi 信号看穿墙壁，监控你的心跳和位置，还不装摄像头。
💡 详细介绍: 这玩意儿简直是科幻电影走进现实。RuView 通过分析你家 WiFi 信号的波动，就能实时感知房间里有没有人、人在哪，甚至还能监测你的心跳和呼吸。不需要任何摄像头，完全零隐私入侵（理论上）。解决了“不想被摄像头盯着但又想智能监控”的矛盾，适合那些对隐私极度敏感但又想玩智能家居的极客。不过，小心别用它来抓老公/老婆出轨，虽然技术上可行，但道德上…你自己看着办。
🔗 项目网址: https://github.com/ruvnet/RuView
✨ Star 数量: 64,078
⭐ 推荐指数: ★★★★★（5星，技术硬核，脑洞大开，但实际部署可能需要一点动手能力）

rohitg00/ai-engineering-from-scratch

🎯 一句话概括: 从零开始手撕 AI，学完就能自己造轮子。
💡 详细介绍: 市面上那些 AI 教程，要么太浅（只会调包），要么太深（数学公式劝退）。这个项目就是那个“刚刚好”的教程。它教你从最底层的原理开始，一步步用 Python 实现各种 AI 模型。没有黑盒，没有“魔法”，只有实打实的代码和逻辑。解决了“学了 AI 但不会用”的尴尬，让你真正理解 AI 是怎么工作的，而不是只会 Ctrl+C/V。
🔗 项目网址: https://github.com/rohitg00/ai-engineering-from-scratch
✨ Star 数量: 12,013
⭐ 推荐指数: ★★★★☆（4星，适合想深入学习的同学，但需要一定编程基础）

ChromeDevTools/chrome-devtools-mcp

🎯 一句话概括: 让 AI 编程助手直接操控 Chrome 开发者工具，调试网页像喝水一样简单。
💡 详细介绍: 想象一下，你对着 AI 说“帮我把这个页面的 CSS 改一下”，然后它真的打开 DevTools，找到对应的元素，修改样式，还能实时预览。这个项目就是干这个的。它把 Chrome DevTools 的能力开放给 AI 编程助手（比如 Claude、Codex），让 AI 可以像人类开发者一样调试网页。解决了“AI 只能写代码但不能调试”的痛点，以后前端开发可能真的只需要动动嘴了。
🔗 项目网址: https://github.com/ChromeDevTools/chrome-devtools-mcp
✨ Star 数量: 41,003
⭐ 推荐指数: ★★★★★（5星，官方出品，实用到爆炸，前端开发者必看）

dotnet/skills

🎯 一句话概括: 微软官方出的 .NET 技能包，专门给 AI 编程助手开小灶。
💡 详细介绍: 微软终于坐不住了，给 AI 编程助手们出了一套 .NET 和 C# 的官方技能。这些技能包包含了各种常见的 .NET 开发场景，比如 ASP.NET Core 配置、Entity Framework 使用、Azure 集成等等。AI 助手装上这些技能包，就能更准确地理解 .NET 代码，减少瞎编乱造的概率。解决了“AI 写 .NET 代码经常跑偏”的痛点，毕竟官方喂的数据，比网上那些二手资料靠谱多了。
🔗 项目网址: https://github.com/dotnet/skills
✨ Star 数量: 2,548
⭐ 推荐指数: ★★★☆☆（3星，刚起步，但潜力巨大，.NET 开发者可以关注）

🎯 一句话概括: 把任何代码变成可交互的知识图谱，让你像逛公园一样理解代码。
