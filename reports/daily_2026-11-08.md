# Agent Skills 生态成形，浏览器与安全审计先行

今天榜单被“Agent Skills”刷屏：Anthropic、Google、Cloudflare 和 Matt Pocock 同时把技能包摆上台面，说明让 Agent 按固定流程干活正在从演示走向工程化。最值得看的是 vercel-labs/agent-browser 用 Rust CLI 把浏览器拆成可快照、可点击的原子命令，以及 Cloudflare 把漏洞挖掘流程拆成六阶段审计技能。


### vercel-labs/agent-browser

**一句话概括**：给 AI Agent 用的浏览器 CLI，把页面读成带 @e1 引用的紧凑文本，再逐条执行点击。

**详细介绍**：Agent 通过 snapshot 拿到元素引用，执行动作后重新快照确认结果，浏览器在命令间保持打开。局限是引用只对快照时刻有效，DOM 一变就得重拍，点击失败会直接报错而不是假装成功。

**项目网址**：https://github.com/vercel-labs/agent-browser

**Star 数量**：46,923


### cloudflare/security-audit-skill

**一句话概括**：把编码 Agent 变成安全审计员，六阶段流程从侦察、覆盖式猎查到独立验证，产出机器可读的 findings.json。

**详细介绍**：每个候选漏洞交给全新验证 Agent 尝试证伪，再用独立 Agent 复核记录，最后按 schema 输出 confirmed、needs_validation 和 rejected。适合单仓库起步，但多阶段隔离 Agent 的编排成本不低。

**项目网址**：https://github.com/cloudflare/security-audit-skill

**Star 数量**：65,897


### google/skills

**一句话概括**：Google 官方 Agent Skills 合集，覆盖 Cloud 入门、IAM 认证、解决方案架构和多智能体安全。

**详细介绍**：通过 npx 选择技能和目标 Agent 安装，支持项目级或全局范围，也能更新和清理旧技能。目前更像技能目录，具体每个技能的执行深度需要逐个翻看。

**项目网址**：https://github.com/google/skills

**Star 数量**：23,471


### mattpocock/skills

**一句话概括**：Matt Pocock 从自己 .agents 目录掏出来的日常工程技能，主打小而可组合，不替你做主。

**详细介绍**：明确反对 GSD、BMAD、Spec-Kit 那种接管流程的做法，技能可以手动改、随意拆。安装方式按 Agent 分插件和复制文件两种，选错会装两遍。

**项目网址**：https://github.com/mattpocock/skills

**Star 数量**：317,829


### anthropics/skills

**一句话概括**：Anthropic 官方技能示例库，每个技能一个文件夹加 SKILL.md，从艺术音乐到测试 Web 应用都有。

**详细介绍**：技能是动态加载的指令、脚本和资源包，教 Claude 按固定方式完成专项任务。仓库定位是示范和灵感来源，不是开箱即用的生产工具集。

**项目网址**：https://github.com/anthropics/skills

**Star 数量**：188,878


### meta/astryx

**一句话概括**：Meta 内部用了八年的设计系统开源，150+ 组件、品牌主题和 CLI 打包，人和 AI 共用一套工具。

**详细介绍**：基于 React 19+ 和 StyleX，导入预构建 CSS 即可用，不需要额外构建插件。开放内部结构，组件可组合，也能 swizzle 把源码 eject 出来自己改。目前是 Beta。

**项目网址**：https://github.com/meta/astryx

**Star 数量**：14,658


### prometheus/prometheus

**一句话概括**：老牌监控系统与时间序列数据库，多维数据模型加 PromQL，单节点自治不依赖分布式存储。

**详细介绍**：通过 HTTP 拉取指标，批量任务可走网关推送，服务发现或静态配置找目标。适合需要灵活查询和告警的场景，但长期存储和高可用要额外组件补。

**项目网址**：https://github.com/prometheus/prometheus

**Star 数量**：67,472

### milind-soni/OpenMausBot

**一句话概括**：开源的 Grok Bot 替代品，聊天应用里每个联系人都是一个本地跑 Claude 或 Codex 的真 Agent。

**详细介绍**：每个 bot 有自己的性格、模型、云电脑和已连接应用，可以像联系人一样对话、看它干活、审批关键操作。本地优先、自带 Agent，但明确与 xAI、Meta、OpenAI 无关联。

**项目网址**：https://github.com/milind-soni/OpenMausBot

**Star 数量**：17,155


### astral-sh/ruff

**一句话概括**：Rust 写的 Python linter 和格式化器，比 Flake8 和 Black 快 10 到 100 倍，内置 900+ 规则。

**详细介绍**：一个工具替代 Flake8 加几十个插件、Black、isort 等，支持 pyproject.toml、自动修复和编辑器集成。适合想统一工具链又不想牺牲速度的 Python 项目。

**项目网址**：https://github.com/astral-sh/ruff

**Star 数量**：51,006
