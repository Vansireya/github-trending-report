7. github/gh-stack

🎯 一句话概括: GitHub 官方的“堆叠式 PR”命令行工具，专治大型代码审查难题。
💡 详细介绍: 在大型项目中，提交一个巨大的 PR 往往会让 reviewer 看得想死。Stacked PR 的玩法是把一个大改动拆分成多个小 PR，按顺序堆叠起来，逐个审查和合并。`gh-stack` 就是干这个的。它帮你自动化管理这些 PR 的依赖关系，让你能轻松地创建、更新和合并一整套堆叠的 PR。对于维护大型项目的团队来说，这能极大提升代码审查效率。
🔗 项目网址: https://github.com/github/gh-stack
✨ Star 数量: 827
⭐ 推荐指数: ★★★☆☆（工具是好工具，但比较小众，适合特定工作流，所以星少。）
