Agent 技能包与工具链集中爆发

今天榜单几乎被 Agent 技能包和配套工具占据，从漏洞挖掘到开发方法论再到图表生成，都在把 Claude Code 这类编码代理往专业工作流里推。最值得看的是 Claude-BugHunter 和 superpowers：前者把 681 份公开漏洞报告拆成可调用的技能，后者试图给代理立一套完整的软件开发规矩。

1
elementalsouls/Claude-BugHunter ★ 23,353
Python

把 85 个漏洞挖掘技能和 681 份公开报告模式打包进 Claude Code，让代理按红队流程干活。

安装后代理会按五阶段方法论、VRT 映射和平台 CVE 链来推进，而不是随机试 payload。局限在于它依赖 Claude Code 的技能系统，且 README 强调“保持范围”，实际效果仍取决于使用者对授权边界的把控。

2
obra/superpowers ★ 326,810
Shell

一套给编码代理用的完整软件开发方法论，先逼你讲清需求再动手写代码。

它从启动代理那一刻就介入：先追问真实目标，把规格拆成可读的小块让你确认，再生成连“没品味、没判断力”的初级工程师都能执行的计划。支持 Claude Code、Cursor、Codex 等一长串宿主，但方法论本身是否奏效，取决于你愿不愿意被代理反复打断。

3
HKUDS/CLI-Anything ★ 65,854
Python

给各种软件生成 CLI 封装，让 AI 代理通过命令行操作 CAD、3D 场景等工具。

核心思路是“今天的软件服务人，明天的用户是代理”，通过 cli-hub 安装社区构建的 CLI，代理就能调用预览、轨迹循环来产出真实工件。目前生态靠社区 PR 扩充，覆盖面广但质量参差，适合愿意尝鲜的代理工作流玩家。

4
jingyaogong/minimind ★ 71,194
Python

用 3 块钱 GPU 租用成本和 2 小时，从零训出一个 64M 参数的超小语言模型。

项目把预训练、SFT、LoRA、RLHF、Agentic RL 等全链路代码用原生 PyTorch 从零实现，不依赖高层抽象，适合想亲手拆开大模型黑盒的人。注意“2 小时”指单张 3090 跑完 SFT 一个 epoch，完整复现仍需按教程逐步来。

5
cursor/plugins ★ 19,600
TypeScript

Cursor 官方插件规范与首批插件，把教学、持续学习、分支审查等流程做成可安装单元。

每个插件是根目录下的独立文件夹，带自己的 plugin.json 清单。比如 thermos 做深度安全与正确性审计，continual-learning 把对话记录增量写进 AGENTS.md。目前插件数量不多，但规范本身值得关注，它可能成为 Cursor 生态的扩展标准。

6
firecrawl/firecrawl ★ 210,281
TypeScript

把网站转成干净 markdown 的知识基础设施，支持本地单二进制、云服务和自托管三种跑法。

本地模式不需要数据库、队列或容器，装完就能给代理当 MCP 服务器用；云服务额外提供搜索和 550+ 数据源。真正省事的是它把抓取、爬取、映射统一成一个 API，但自托管全栈仍需自己管队列和数据库。

7
nginx/nginx ★ 33,415
C

NGINX 官方开源仓库，Web 服务器、负载均衡、反向代理和内容缓存的老牌底座。

README 面向新手梳理了模块、配置、运行时和从源码构建的路径，也覆盖 TLS、限流、缓存等常见场景。它本身不新，但官方仓库集中放代码和文档入口，对需要查模块指令或自己编译的人来说省了翻散落资料的时间。

8
openvinotoolkit/openvino ★ 12,699
C++

英特尔主导的推理优化工具包，把 PyTorch、ONNX 等模型压到 CPU、GPU 和 NPU 上跑。

支持从 Hugging Face 直接拉 transformers 和 diffusers 模型，经 Optimum Intel 转换后部署，覆盖视觉、语音、生成式 AI 等任务。平台兼容性从边缘到云，但硬件加速优势主要集中在英特尔自家芯片上。

9
cathrynlavery/diagram-design ★ 73,269
HTML

给编码代理用的图表设计技能，输出单文件 HTML+SVG，覆盖 52 种图表类型。

你用自然语言描述架构图或象限图，代理选类型、说计划，然后写一个双击就能打开的 .html 文件。它明确反对 Mermaid 的默认审美，强调无阴影、可匹配品牌色。适合需要快速出干净示意图的人，但复杂交互图表不是它的目标。
