# Agent 技能包与工具链集中爆发

今天榜单几乎被 Agent 技能包和配套工具占满，从安全审计到开发方法论都在往 Claude Code 这类宿主里塞。最扎眼的是 obra/superpowers 和 elementalsouls/Claude-BugHunter，前者把完整开发流程拆成可组合技能，后者直接打包 85 个漏洞狩猎技能和 681 条披露报告模式。


### elementalsouls/Claude-BugHunter

**一句话概括**：给 Claude Code 装上一整套漏洞狩猎技能包，85 个技能、16 个斜杠命令，外加 681 条已披露报告模式。

**详细介绍**：它把方法论、Web 应用狩猎、企业身份与基础设施攻击矩阵分层堆叠，并强调保持授权范围。适合授权红队和 Bug Bounty 场景，但技能数量庞大，实际效果取决于使用者能否正确编排和验证。

**项目网址**：https://github.com/elementalsouls/Claude-BugHunter

**Star 数量**：24,951


### obra/superpowers

**一句话概括**：一套让编码 Agent 先追问需求、再拆规格、最后按计划写代码的完整开发方法论。

**详细介绍**：它不急着让 Agent 写代码，而是先逼出规格、分块确认设计，再生成连“没品味的初级工程师”都能执行的实现计划。适合想约束 Agent 随意发挥的团队，但流程偏重，小任务可能显得繁琐。

**项目网址**：https://github.com/obra/superpowers

**Star 数量**：327,670


### HKUDS/CLI-Anything

**一句话概括**：试图把任何软件都包装成 Agent 可调用的 CLI，让 AI 通过命令行操作 CAD、3D 场景等真实工具。

**详细介绍**：项目提供 CLI-Hub 来浏览和安装社区构建的 CLI，并展示 Agent 用生成 CLI 产出 CAD 构建、3D 场景、字幕等制品的演示。核心限制在于每个软件的 CLI 封装质量和覆盖范围参差不齐。

**项目网址**：https://github.com/HKUDS/CLI-Anything

**Star 数量**：66,521


### jingyaogong/minimind

**一句话概括**：用 3 块钱 GPU 租用成本和 2 小时，从零训出一个 64M 的超小语言模型。

**详细介绍**：项目把预训练、SFT、LoRA、DPO、PPO/GRPO 等全链路代码用原生 PyTorch 从零实现，不依赖高层抽象，还扩展到视觉和多模态变体。适合想亲手拆开 LLM 黑盒的人，但 64M 规模离实用产品很远。

**项目网址**：https://github.com/jingyaogong/minimind

**Star 数量**：71,830


### cursor/plugins

**一句话概括**：Cursor 官方插件规范与首批官方插件集合，每个插件都是带 manifest 的独立目录。

**详细介绍**：仓库里能看到教学、持续学习、团队工具包、安全审计等插件，其中 Thermos 主打深度安全与正确性审查。它更像是 Cursor 插件生态的样板间，实际价值取决于后续社区插件是否跟进。

**项目网址**：https://github.com/cursor/plugins

**Star 数量**：19,837


### firecrawl/firecrawl

**一句话概括**：把网站抓成干净 Markdown 的知识基础设施，现在还能以单二进制在本地跑并充当 MCP 服务器。

**详细介绍**：Firecrawl Local 不需要数据库、队列或容器，适合给 Agent 喂网页内容；云端版则额外提供搜索和 550+ 数据提供商。自托管全栈需要自己维护队列、worker 和数据库，运维成本不低。

**项目网址**：https://github.com/firecrawl/firecrawl

**Star 数量**：211,128


### nginx/nginx

**一句话概括**：NGINX 官方开源仓库，Web 服务器、负载均衡、反向代理和内容缓存的老牌底座。

**详细介绍**：README 面向新手梳理了模块、配置、运行时和安装流程，也覆盖 TLS、限流、缓存等常见场景。它出现在趋势榜上更多是基础设施工位的日常存在，而非新变化。

**项目网址**：https://github.com/nginx/nginx

**Star 数量**：33,557


### openvinotoolkit/openvino

**一句话概括**：Intel 主导的推理优化与部署工具包，支持从 PyTorch、TensorFlow、ONNX 到 Hugging Face 模型的转换部署。

**详细介绍**：它覆盖 CPU、Intel GPU 和 NPU，强调边缘到云的广泛平台兼容。实际选型时要注意硬件绑定较深，非 Intel 加速器上的收益有限。

**项目网址**：https://github.com/openvinotoolkit/openvino

**Star 数量**：12,848


### cathrynlavery/diagram-design

**一句话概括**：一个让 Agent 把架构图、象限图、时序图直接画成自包含 HTML+SVG 文件的技能，52 种图型，拒绝 Mermaid 糊图。

**详细介绍**：用户用自然语言描述需求，Agent 选图型、说明计划并输出单个 HTML 文件，还能抓取品牌色和字体。它明确反对阴影和 Mermaid 的粗糙感，适合对视觉有要求的文档场景。

**项目网址**：https://github.com/cathrynlavery/diagram-design

**Star 数量**：74,026


### mvanhorn/last30days-skill

**一句话概括**：让 Agent 跨 Reddit、X、YouTube、HN、Polymarket 和网页搜索近 30 天话题，再按点赞和真金白银排序合成摘要。

**详细介绍**：零配置即可跑通 Reddit、HN、Polymarket 和 GitHub，设置向导再解锁 X、YouTube、TikTok 等来源。它用社区投票和预测市场赔率替代编辑判断，但来源覆盖和排序权重会直接影响结论偏向。

**项目网址**：https://github.com/mvanhorn/last30days-skill

**Star 数量**：75,921


**今日总结**：今天最值得看的是 Agent 技能包开始从“提示词合集”走向带方法论、带审计痕迹的工程化封装；但技能越多，越考验宿主和用户的编排能力，别把数量当质量。
