### 8. codegraph
- **一句话概括：** 给 Claude Code 等工具准备的“代码地图”，省 token、省时间。
- **详细介绍：** 你每次让 Claude 分析一个大型代码库，它都要花很多 token 去“读”文件。这个项目帮你提前把代码库的依赖关系、函数调用链等元数据整理成一个知识图谱，然后让 Claude 直接查“地图”而不是“读原文”。结果就是：token 消耗骤降，工具调用次数减少，速度飞起，而且完全本地运行，保护隐私。
- **项目网址：** https://github.com/colbymchenry/codegraph
- **Star 数量：** 22,463
- **推荐指数：** ⭐⭐⭐⭐⭐（大项目开发者的省 token 神器）
