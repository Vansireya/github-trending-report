今日 GitHub 狠活：AI 代理开始自己造工具，人类只剩点赞的份

今日榜单堪称「Agent 全家桶」——从逆向工程到代码审查，从 PS5 移植到 3D 重建，AI 代理们正在把工程师的饭碗端走，还顺手洗了个碗。下面请欣赏各位选手的表演。

1
morluto/rea ★ 50,311
TypeScript

让 AI 代理帮你逆向工程任何东西，从 App 行为一路扒到原生二进制。

以前逆向工程是硬核老哥的专利，得会看汇编、玩 IDA、熬夜掉头发。现在 rea 直接派代理上场，你负责喝咖啡，它负责把二进制拆得明明白白。TypeScript 写的，意味着前端仔也能假装自己是安全研究员了。痛点？痛点就是「我看不懂这破 App 在干嘛」，现在代理替你看懂，还顺便写好了报告。

2
boykopovar/AnyPS5 ★ 22,860
C++

把 PS5 可执行文件自动移植到 Linux 和 Windows 的工具。

索尼看了想打人。这个工具号称能自动把 PS5 的程序搬到 PC 上跑，C++ 写的，性能不用担心。当然，实际能不能跑起来《战神》是另一回事，但梦想还是要有的，万一呢？痛点很明确：PC 玩家眼馋独占，PS5 玩家眼馋 mod，现在大家可以在法律边缘互相试探了。

3
mattpocock/skills ★ 282,950
Shell

真·工程师的技能包，直接从作者的 .agents 目录里掏出来的。

Matt Pocock（TypeScript 圈知名布道者）把自己 Agent 目录里的技能全开源了。Shell 写的，轻量到不能再轻量。这玩意儿的痛点在于：别人家的 Agent 是智障，你家的 Agent 是智障plus，因为没喂技能。现在好了，大佬把「真·工程师技能」打包送你，装上之后你的 Agent 至少能装得像个人了。28 万星？这数字离谱到像是被刷的，但谁让它是 Matt 呢。

4
cathrynlavery/diagram-design ★ 48,062
HTML

给 Claude Code、Codex、Copilot 等一众 AI 编程助手用的编辑级图表设计，44 种图表类型，纯 HTML+SVG。

受够了 Mermaid 那种「能看但丑」的流程图了吗？作者直接开喷「No Mermaid slop」，然后甩出 44 种自包含的 HTML+SVG 图表，无阴影、无废话、颜值在线。痛点就是：AI 生成的图表常年丑得让人想关掉窗口，现在终于有个懂设计的来管管了。支持 Claude Code、Codex、Copilot、Factory Droid、Pi——基本把市面上的 Agent 全伺候了一遍。

5
alibaba/open-code-review ★ 45,390
Go

阿里大规模实战检验过的代码审查工具，确定性流水线 + LLM Agent 混合架构。

阿里把这个工具在自家规模上跑过了，Go 写的，快且稳。混合架构的意思是：该用规则的地方用规则（NPE、线程安全、XSS、SQL 注入都有内置规则集），该用 LLM 的地方用 LLM，精准到行级评论。痛点？痛点就是纯 LLM 审查经常胡说八道，纯规则审查又太死板，阿里说「我全都要」。兼容 OpenAI 和 Anthropic，不绑死一家。

6
anthropics/knowledge-work-plugins ★ 28,344
Python

Anthropic 官方开源的插件仓库，主要给知识工作者在 Claude Cowork 里用。

Anthropic 亲自下场做插件了，Python 写的，目标人群是「知识工作者」——翻译成人话就是：不写代码但天天跟文档、表格、PPT 打架的人。痛点在于：Claude 虽然聪明，但没插件就像没装 App 的手机，功能有限。现在官方给你一套插件，让你的 Claude 从「聊天机器人」升级成「办公搭子」。

7
BerriAI/litellm ★ 60,729
Python

号称最快最轻的 AI 网关，Rust 核心 + Python SDK，一个接口调用 100+ LLM API。

这项目是老熟人了，但这次升级了 Rust 核心，速度起飞。痛点极其真实：你想用 OpenAI 的格式调 Anthropic，用 Anthropic 的格式调 Bedrock，还要管成本、限流、负载均衡、日志……以前得自己写一坨胶水代码，现在 litellm 一把梭。支持 Bedrock、Azure、OpenAI、Anthropic、VertexAI、vLLM、Nvidia NIM——基本上你能叫出名字的它都支持。

8
addyosmani/agent-skills ★ 104,084
JavaScript

给 AI 编程代理用的生产级工程技能包。

Addy Osmani（Google Chrome 团队大佬）出手了，JavaScript 写的。和上面 Matt 那个类似，但定位更偏向「生产级」——意思是这些技能不是玩具，是真能上战场的。痛点：你的 AI Agent 写个 demo 还行，一上生产就拉胯，因为它不懂工程规范、不懂边界情况、不懂性能优化。Addy 说「我来教它」。10 万星，大佬的影响力可见一斑。

9
storytold/artcraft ★ 11,878
Rust

为艺术家、设计师和电影人打造的有意为之的创作引擎。

Rust 写的，定位很文艺——「intentional crafting engine」。翻译一下：不是那种「一键生成 AI 垃圾图」的工具，而是让你有意识地、精细地控制创作过程。痛点在于：现在的 AI 创作工具要么太自动化（你只是个按按钮的），要么太底层（你得会写 shader）。ArtCraft 想在中间找个平衡点。1 万多星，不算爆款，但受众精准。
